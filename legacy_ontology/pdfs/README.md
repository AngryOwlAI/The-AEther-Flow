# Legacy Ontology PDF Snapshot

This folder contains copied PDF derivatives from `ontology/pdfs/` as of
2026-06-18.

## Authority Boundary

These PDFs are human-reading derivatives of the copied TeX snapshot in
`legacy_ontology/tex/`. They are registered so wiki notes and CSV inventories
can point to them, but they are not independent scientific authority.

Regenerate live ontology PDFs from `ontology/tex/` when the current ontology
changes. Do not use this folder as the active PDF output lane for current
ontology work.
