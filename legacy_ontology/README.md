# Legacy Ontology Snapshot

This folder preserves the ontology package as it existed on 2026-06-18 before
future ontology extension work. It is a tracked comparison snapshot, not the
live canonical ontology lane.

## Folder Structure

- `tex/` contains copied TeX source files from `ontology/tex/`.
- `pdfs/` contains copied PDF derivatives from `ontology/pdfs/`.
- `aether-and-aether-flow.md` is the copied ontology-adjacent explanatory note.
- `aether_flow_interpretation-lemen.md` is the copied authored Markdown note.

## Authority Boundary

Use `ontology/` for the current ontology and benchmark package. Files in
`legacy_ontology/` are registered as archival noncanonical snapshot material so
agents can compare later ontology extensions against the prior package.

The snapshot does not promote a new physics claim, prove a first-principles GR
derivation, or authorize canonical ontology changes by itself. If the live
ontology expands later, modify `ontology/` through the governed research-control
path and keep this folder as the legacy reference unless a new explicit
snapshot task supersedes it.
