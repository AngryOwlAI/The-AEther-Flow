# Legacy Ontology TeX Snapshot

This folder contains copied TeX files from `ontology/tex/` as of 2026-06-18.
The copied files are retained for comparison with future ontology extensions.

## What Belongs Here

- The frozen legacy TeX snapshot created by the bounded project-system task.
- Snapshot-local documentation that explains the archival boundary.

## What Does Not Belong Here

- New canonical ontology edits.
- Future derivation packets or task-local AgentJob artifacts.
- Generated PDFs; those belong under `legacy_ontology/pdfs/`.

## Authority Boundary

The live ontology source lane remains `ontology/tex/`. The TeX files here are
registered as `legacy_ontology_source_snapshot` rows with archival
noncanonical authority. They can support comparison and provenance checks, but
they do not replace the live ontology or promote any derivation claim.
