Two Operating Lanes

Physics Continuation

Use for derivation work, candidate construction, refutation, audit, theoretical packet selection, or controlled scientific handoff through .codex/skills/continue-research/SKILL.md.

Boundary: no claim promotion, benchmark promotion, ontology adoption, or Gate Chair decision without the required gates.

Project-System Improvement

Use for documentation drift, validator work, role or schema maintenance, memory tooling, workflow clarification, or public explainer packets through .codex/skills/improve-project-system/SKILL.md.

Boundary: no physics status change or canonical science-source edit.

Memory Is Navigation

Use

Use memory preflight to find prior decisions, source object IDs, and likely paths.

Verify

Inspect the source file or registry row before using the memory hit for routing, claims, or project-control changes.

Do Not Promote

Do not treat wiki notes, semantic extracts, Obsidian mirrors, or .local caches as authority.

One Bounded AgentJob

The AgentJob binds allowed reads, allowed writes, generated paths, forbidden paths, source classes, validators, expected outputs, and claim boundary. Its role binding says whether the job uses a registered role, a task overlay, or a one-job provisional role.

Prevents Drift

A documentation repair cannot silently become a schema change.

Prevents Overclaim

A physics construction cannot silently become benchmark promotion.

Safe And Unsafe Summaries

Safe

AEther-Flow routes physics continuation and project-system improvement through one bounded AgentJob, source inspection, role constraints, checks, completion evidence, and human gates.

Unsafe

The workflow proves physics autonomously, memory overrides tracked sources, validators promote claims, generated pages are authority, or a role template grants current write permission.
