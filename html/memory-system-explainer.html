Phase 5A Reference Catalog

Memory, Registries, Wiki, And Retrieval Surfaces

Memory in AEther-Flow is a navigation system. It helps you find registered sources and registry rows; it does not replace them. Generated notes, semantic extracts, Obsidian mirrors, SQLite lookup, and .local caches remain non-authority support layers.

Use memory to navigate. Run status and targeted lookup or search before routing.
Use registries to bind provenance. Inspect object IDs, source paths, hashes, and generated outputs.
Use sources to conclude. Canonical source inspection remains required after a memory hit.

Memory Preflight Query Workflow

A memory preflight receipt is evidence that retrieval was used carefully. Its logical endpoint is source inspection.

1

Status

Run query_memory.py status --json and record freshness status.

2

Lookup

Run a targeted lookup or search for the source, page, task, or object ID.

3

Object IDs

Record returned object IDs and any warnings from retrieval layers.

4

Source

Open the canonical source path named by the memory hit.

5

Registry

Inspect the source registry row and source hash.

6

Act

Route, edit, cite, or summarize only after source and registry inspection.

Receipt boundary: Obsidian, generated wiki notes, semantic extracts, SQLite lookup, and .local paths can appear in the receipt as navigation evidence. They do not become authority.

Stale Local Retrieval Troubleshooting

freshness_status is WARN

A retrieval layer may lag source inputs. Inspect tracked sources directly.

Vault note missing

The local Obsidian mirror has not been generated. Refresh; do not hand-edit generated notes.

Raw mirror stale

The raw local copy is older than its tracked source. Regenerate the local retrieval layer.

SQLite index older than inputs

Search may miss newer rows. Refresh before relying on lookup for navigation.

Wiki note disagrees with source

The derivative is stale or wrong. Fix the source or registry row if needed, then bootstrap.

Validate-only passes after source edits

Validate-only checks current state. Use bootstrap when generated derivatives need refresh.
