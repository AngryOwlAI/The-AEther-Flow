# Local Prompts

This folder contains reusable prompt text for local Codex workflows.

## What Belongs Here

- Prompt drafts for project recaps, reviews, visual plans, slide generation,
  web diagrams, and explanatory project summaries.
- Prompt files that help a human or agent begin a local workflow without
  changing project authority.

## What Does Not Belong Here

- Role contracts, skill contracts, schemas, or validators.
- Canonical scientific claims.
- Generated HTML, generated wiki notes, or task completions.

## Authority Boundary

Prompts are support material. They can help start a workflow, but they do not
override `AGENTS.md`, registered role contracts, task allowlists, validators,
or source registries. When prompt wording conflicts with tracked project
control, tracked project control wins.
