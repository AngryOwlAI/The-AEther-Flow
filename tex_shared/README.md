# Shared TeX Fragments

This folder contains shared TeX fragments used by source documents.

## What Belongs Here

- Reusable reference lists.
- Shared explanatory TeX fragments included by ontology or manuscript sources.
- Small source fragments that are intended to be included from registered TeX
  files.

## What Does Not Belong Here

- Standalone generated PDFs.
- Task-local draft artifacts.
- Project-control Markdown or YAML.
- Scratch TeX builds.

## Authority Boundary

Shared fragments support registered TeX sources. Their scientific authority
comes through the registered TeX files that include them and the registry rows
that define claim status. Editing a shared fragment can affect multiple TeX
sources, so changes require the same care as other science-adjacent source
edits.
