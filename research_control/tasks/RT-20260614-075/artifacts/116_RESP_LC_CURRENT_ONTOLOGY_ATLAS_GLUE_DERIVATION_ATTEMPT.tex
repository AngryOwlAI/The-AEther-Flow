\begin{definition}[Current-ontology derivability]

\begin{lemma}[Substrate skeleton underdetermines discriminator profiles]
The current canonical ontology does not determine \(\Prof\).
\end{lemma}

\begin{proof}
The current ontology names \(\Sub\), \(\Phi_{\lambda}\), observer-accessible
slice placeholders, and exact-GR effective structures. None of these current
canonical sources specifies a source-token type for overlap discriminators, a
rule assigning profile values to finite source branches, or an invariant that
separates candidate transitions without reference to the supplied finite
witness. Choosing profiles by target-chart resemblance or by benchmark
success would import forbidden target or benchmark authority. Choosing
profiles by the prior finite packet would treat draft/control source-extension
data as adopted source authority. Therefore \(\Prof\) is not derived from the
current ontology.
\end{proof}

\begin{lemma}[Substrate skeleton underdetermines selector preorder]
The current canonical ontology does not determine \(\Sel\).
\end{lemma}

\begin{proof}
A selector preorder requires a source-side comparison relation over candidate
transition tokens. The current ontology supplies no canonical cost functional,
ordering invariant, tie-breaker, or uniqueness theorem for such candidates.
The exact-GR benchmark supplies an observer-level effective metric after
adoption, not a substrate-side preorder over source overlap candidates.
Therefore a unique source-minimal selector cannot be derived from the current
canonical ontology.
\end{proof}

\begin{lemma}[Inverse and cocycle checks are not automatic]
The current canonical ontology does not determine \(\mathsf{Inv}\) or
\(\mathsf{Cocyc}\) for \(\Wfin\).
\end{lemma}

\begin{proof}
Inverse and cocycle checks for source transitions require a category-like or
groupoid-like source law for transition tokens. The current ontology contains
schematic substrate and slice language, but it does not define a source
transition category, composition law, inverse operation, or triple-overlap
compatibility theorem for the repaired atlas-glue datum. The ordinary smooth
atlas behavior available in GR cannot be used as a source-side proof, because
that would reverse the derivation direction by importing target geometry.
Therefore the inverse and cocycle checks remain supplied finite data rather
than current-ontology consequences.
\end{proof}

\begin{lemma}[Finite-variation robustness is not derived]
The current canonical ontology does not determine arbitrary finite-variation
robustness for \(\Wfin\).
\end{lemma}

\begin{proof}
Finite-variation robustness requires an admissible-variation class plus a
proof that discriminator separation, selector uniqueness, inverse
compatibility, and cocycle compatibility survive every allowed perturbation.
The current ontology has no canonical variation class for source-token
profiles or selector preorders. Since discriminator collapse, selector ties,
inverse deletion, and cocycle perturbation are coherent finite changes unless
a source law excludes them, arbitrary robustness is not derivable from the
current canonical ontology.
\end{proof}
