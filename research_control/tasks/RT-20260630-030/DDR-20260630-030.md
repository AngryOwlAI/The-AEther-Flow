# Director Decision Record: DDR-20260630-030

## Decision

Select `memory-system-maintainer@0.2.0` for one bounded P6-T04
proof-to-source traceability registry packet.

## Basis

`handoff-0381` requires one bounded P6-T04 packet to create a traceability
mechanism connecting support-only formalization checks to canonical source
artifacts while preserving `proof_authority=false`.

The packet is registry and validator tooling. It does not define a new
physics theorem, edit canonical ontology, adopt a source law, adopt
`MetricData(E)`, expand `g_eff`, derive matter coupling, import stress-energy
semantics, derive Einstein equations, promote benchmark status, or claim a
completed derivation. Memory-System Maintainer is the narrowest role fit
because the output is a source-first manifest and validation receipt.

## Scope

Allowed:

- Add a controlled traceability manifest under `research_control/design/`.
- Add a validator that checks source paths, hashes, boundary statements,
  formal-object mappings, and support-only status.
- Add focused tests for the validator and fail-closed cases.
- Emit a task-local validation receipt.
- Update control registries, program state, handoff, documentation-impact, and
  generated derivatives.

Blocked:

- canonical ontology edit
- canonical-ontology candidate status
- source-law adoption
- source-extension data adoption beyond exact scoped gate result
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- detector semantics
- matter action
- Einstein equations
- benchmark promotion
- completed derivation
- support-only formalization as proof authority
- registry metadata or validator output as proof authority
- future source-extension impossibility
- global theory rejection
- P7 role-contract implementation in this packet

## Result

The selected packet completes P6-T04 as traceability-only project-control
tooling with `proof_authority=false`. The next legal continue-research packet
is P7-T01 external red-team role contract design.
