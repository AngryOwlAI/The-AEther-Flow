# DDR-20260808-002 — Immutable terminal V21 baseline package

## Decision

Execute exactly one V22 P0-T02 `AgentJob` under a task-scoped Process
Integrity Auditor overlay. The job must read the terminal V21 tree at commit
`233e5dd7024fc068032d0afe86d85dc25e2246e9`, not mutable working-tree science,
and must package exact bytes plus traceable release-control metadata.

## Authority surfaces inspected

The repository instructions, `continue-research` contract, Director and role
contracts, AgentJob and execution-role schemas, live memory preflight, the
registered V21 plan row and canonical source, the unregistered V22 draft,
terminal V21 goal and Git receipts, `handoff-0967`, P0-T02 text, final P16
science and system scorecards, Distance-to-GR ledger, Gates A–E, selector and
Lean proof packets, P5/P6 negative evidence, P7 postulate evidence, P8/P9
obstruction and benchmark records, and P13/P15 environment and source-bundle
receipts were inspected.

## Role-Fit Matrix

| Role | Fit | Reason |
| --- | --- | --- |
| `process-integrity-auditor@0.1.0` | selected | Owns exact commit and hash closure, derivative traceability, reproduction evidence, and release-authority containment. |
| `documentation-curator@2.0.0` | not selected | Release prose is a bounded overlay constraint rather than a separate publication-surface task. |
| `project-control-maintainer@0.2.0` | not selected | V22 registration and backlog materialization remain P0-T03. |
| `validator-engineer@0.2.0` | not selected | No shared validator, policy, schema, or test behavior changes. |

Process integrity is primary because the acceptance burden is exact commit,
tree, source hash, derivative provenance, archive closure, reproduction, and
authority containment. The overlay additionally requires documentation-grade
release notes and a freeze policy. It does not grant the Documentation
Curator's broader publication surface or allow any direct HTML, PDF, wiki,
canonical science, ontology, benchmark, Gate, shared validator, policy,
schema, or test edit.

## Release boundary

The package may prepare the proposed tag
`v21-scientific-baseline-233e5dd7`, but it must verify that no such tag exists
and must not create one. It must not publish, push, contact reviewers, submit,
or describe internal same-context validation as external review or
independent replication.

## Required calibrated status

Release text must preserve Gate B, Gate D, and Gate E as `NOT_READY`; six
benchmarks as inconclusive, zero passed, and zero independently replicated;
and first-principles GR derivation as open and not completed. Gate A remains a
narrow research-architecture adoption, while Gate C remains a protected
source-matter package adopted by postulate—not a source derivation.

## Acceptance and next route

Acceptance requires complete terminal-registry source closure, exact
source-to-derivative traceability, safe deterministic archive closure, and
five selected clean-source reproduction profiles with exact failures
disclosed if any. On PASS, one handoff may select only V22 P0-T03. The actual
tag and public release remain separately human-gated and are not prerequisites
for P0-T03.
