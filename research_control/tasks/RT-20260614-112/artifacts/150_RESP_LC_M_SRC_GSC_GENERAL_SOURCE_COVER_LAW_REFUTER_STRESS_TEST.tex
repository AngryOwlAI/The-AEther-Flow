\section{Fail-Closed Stress Tests}

\begin{stress}[Unsupported extension]
If a source-cover extension record lacks source-local separation, source chart
support, transition tokens, inverse certificates, cocycle certificates,
soldering certificates, or admissible source-variation records, then
\(\AdmExt\) is not true. The non-bottom branch of \(\CoverExt\) is therefore
not reached.
\end{stress}

\begin{stress}[Selector nonuniqueness]
If two transition-token candidates are tied under the supplied source data and
no explicit source equivalence resolves the tie, the packet has no authorized
tie breaker. File order, registry order, validation status, role identity,
handoff authority, generated derivatives, benchmark resemblance, and target
coordinate resemblance are forbidden. The branch returns \(\Bot\).
\end{stress}

\begin{stress}[Inverse-token degeneration]
If a selected transition token lacks a source inverse certificate, or if the
available inverse certificates are nonunique without source equivalence, the
non-bottom certificate family is absent and the branch returns \(\Bot\).
\end{stress}

\begin{stress}[Cocycle-token degeneration]
If triple-overlap token composition fails, the packet may not import a target
smooth-atlas cocycle to repair it. The branch returns \(\Bot\).
\end{stress}

\begin{stress}[Soldering nonuniqueness]
If \(\RespLC\) readout-token attachment is nonunique without explicit source
equivalence, \(\SolderSrc\) is not a non-bottom source certificate. Proper
time, detector semantics, target metric behavior, or benchmark resemblance
cannot repair the branch.
\end{stress}

\begin{lemma}[GenCover fail-closed stress survival]
The unsupported-extension, selector-nonuniqueness, inverse-token,
cocycle-token, and soldering-nonuniqueness cases do not refute
\(\GenCover\) as written. They refute non-fail-closed variants that would
repair missing source data with target or process authority.
\end{lemma}

\begin{proof}
Each named defect violates a required non-bottom premise of either
\(\AdmExt\), \(\NonBottom\), or \(\Cert\). The law package explicitly routes
forbidden target or process premises to \(\BottomSrc\). Therefore these
defects prevent a non-bottom candidate rather than forcing a hidden import.
This proves fail-closed behavior only. It does not prove that non-bottom
certificates exist for arbitrary source-cover extension records.
\end{proof}
