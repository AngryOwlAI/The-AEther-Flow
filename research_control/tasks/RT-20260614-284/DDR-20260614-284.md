# Director Decision Record: DDR-20260614-284

## Decision

Select `process-integrity-auditor@0.1.0` for one bounded P1-T01
active-state authority invariant packet.

## Basis

`handoff-0316` requires a P1 repair packet before final P8 validation. The v11
P1-T01 plan asks for an active-state source-of-truth invariant, a path choice
for `research_control/current_frontier.md`, exact drift failure conditions, and
a completion receipt naming the selected policy.

The live state is uniquely determined: `research_control/program_state.yaml`
names `RT-20260614-283` and `handoff-0316`, while
`research_control/current_frontier.md` still describes `RT-20260614-184` and
`handoff-0218`. This task is a control-design packet only; it does not repair
the stale snapshot.

## Scope

Allowed:

- Create a task-local active-state authority invariant artifact.
- Select the current-frontier policy.
- State exact drift failure conditions.
- Route the next bounded packet to P1-T02 synchronization.
- Update control registries, task records, documentation-impact receipt,
  `program_state.yaml`, generated dependency graph artifacts, and `handoff-0317`.

Blocked:

- editing `research_control/current_frontier.md` in this packet
- adding `render_current_frontier.py` in this packet
- adding the validator guard in this packet
- canonical ontology edit
- source-law adoption
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- matter action
- detector semantics
- Einstein equations
- benchmark promotion
- completed derivation

- Distance-to-GR ledger change

## Path Selection

Path A, generated snapshot, is selected as the target policy. The repository
already has deterministic state readers and validator infrastructure, so a
future `render_current_frontier.py` command is feasible without changing
physics sources. Until that renderer exists, P1-T02 may perform the immediate
one-time synchronization under this invariant, and P1-T03 must add a drift
guard before P8-T02 final validation.
