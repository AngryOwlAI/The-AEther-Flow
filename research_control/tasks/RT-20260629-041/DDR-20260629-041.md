# Director Decision Record: DDR-20260629-041

## Decision

Execute P2-T05 as one bounded Documentation Curator task overlay.

The job updates the existing GR Derivation Roadmap publication stack with a
frontier theorem inventory summary. The update is limited to the reviewed page
stack, its publication brief/source spec, its GitHub-facing Markdown and
tracked HTML derivative, the publication brief registry row, and normal
continue-research receipts.

## Basis

`handoff-0335` routes exactly one P2-T05 packet: render an inventory summary
for reader surfaces without authority drift. The P2-T03 inventory is already
populated and P2-T04 validator coverage is in place. The GR Derivation Roadmap
page is the smallest fitting existing reader surface because it already
explains Distance-to-GR burdens, source-extension qualifiers, current-frontier
cautions, and benchmark-promotion blocks.

This is publication and documentation work. It has no physics derivation
milestone and cannot promote theorem, ontology, metric, matter-coupling,
Einstein-equation, benchmark, or Gate Chair claims.

## Scope

Allowed:

- add `research_control/design/frontier_theorem_inventory.md` to the GR
  Derivation Roadmap source basis;
- summarize the 15 inventory items by review category;
- state that the inventory source governs and generated reader surfaces are
  noncanonical;
- state explicitly that GR has not been derived and scoped source-extension
  evidence is not physical adoption;
- update the HTML derivative from the updated source spec in the same bounded
  transaction;
- run publication-process, memory, documentation-impact, and research-control
  validators;
- create normal task, role, AgentJob, completion, documentation-impact,
  claim-boundary, state, and handoff receipts.

Blocked:

- editing physics TeX sources;
- editing `registries/DISTANCE_TO_GR_LEDGER.csv`;
- changing inventory scientific meaning;
- treating the inventory or reader summary as proof authority;
- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
- unscoped `g_eff` adoption or `g_eff` scope expansion;
- coupling-law adoption;
- matter-coupling derivation or adoption;
- stress-energy semantics;
- stress-energy tensor;
- matter action;
- detector semantics;
- Einstein equations;
- exact-GR benchmark promotion;
- benchmark Gate Chair closure;
- completed derivation.
