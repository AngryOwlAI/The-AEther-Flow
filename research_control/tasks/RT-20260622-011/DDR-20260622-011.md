# DDR-20260622-011: Phase 6 Bridge Checkpoint Documentation Phase 3 Synchronized Publication Packet

## Decision

Route one bounded Documentation Curator AgentJob to execute the synchronized
publication packet recommended by `RT-20260622-010`.

The packet updates exactly two selected public explainer stacks:

- `project-system-improvement`
- `validator-operator-workflow`

The authorized stack surfaces are the publication briefs, the
`registries/PUBLICATION_BRIEF_REGISTRY.csv` rows, the source specs, the
GitHub-facing Markdown derivatives, the tracked standalone HTML derivatives,
the page-specific review artifact, and desktop/mobile screenshot evidence.

The update may explain existing Phase 6 bridge checkpoint governance:
project-improvement sidecars remain separate from normal research handoffs,
`/improve-project-system` consumes sidecars as project-system inputs, and
checkpoint plus `--check-diff` sidecar acceptance is exact-path and
source-bridge based. It must not imply a global sidecar directory allowlist,
sidecar adoption, live sidecar creation, validator behavior change, checkpoint
behavior change, or physics claim promotion.

## Selected Role

- Role: `documentation-curator`
- Version: `2.0.0`
- AgentJob: `AJ-RT-20260622-011-001`
- Execution overlay:
  `documentation-curator@2.0.0--RT-20260622-011`

## Rationale

The Phase 2 audit found that strict publication validation treats the public
stack as a synchronized unit. Updating source materials in only a publication
brief or source spec would make the corpus invalid until the registry row,
GitHub-facing Markdown, and tracked HTML caught up. A single synchronized
Documentation Curator packet is therefore the narrowest valid operation.

## Authority Boundary

Allowed:

- Update the two selected publication briefs.
- Update the two selected `PUBLICATION_BRIEF_REGISTRY.csv` rows.
- Update the two selected Markdown source specs.
- Update the paired GitHub-facing Markdown derivatives.
- Update the paired tracked HTML derivatives.
- Capture page-specific desktop/mobile screenshots.
- Record before/after review evidence.
- Refresh generated memory, wiki, registry, and folder-map derivatives through
  the approved bootstrap path.
- Refresh validator-required historical memory-preflight source hashes when
  those hashes point at source files changed by this packet.

Forbidden:

- Creating live project-improvement sidecars.
- Replacing normal research handoffs.
- Creating a sidecar registry.
- Changing validators, resolver behavior, checkpoint behavior, role contracts,
  skill contracts, schemas, or tests.
- Hand-editing generated wiki notes or generated registry metadata sidecars.
- Editing canonical physics, ontology, benchmark, or Gate Chair authority
  sources.
- Promoting physics claims, adopting ontology, or claiming completed
  derivation.
