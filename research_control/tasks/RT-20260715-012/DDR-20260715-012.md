## Scope-alarm review

The plan names four source files. `tests/test_validation_orchestration.py` is
directly required by the plan's Make-plan test obligation. The first full
acceptance then exposed that three historically mutable registered Markdown
objects did not include the newly edited project-memory skill, tests README,
and contributing guide. The smallest compatibility repair adds only those
three object IDs to the established preflight fixture and verifies them in the
existing behavioral test, requiring
`scripts/research_control/validate_research_control.py` and
`tests/test_research_control.py`. This seven-source boundary is therefore
larger than the planned four-source documentation surface but is evidence-led,
adds no dependency or public schema, and preserves the same validation rule.

`CONTRIBUTING.md` is not currently included in bootstrap Markdown discovery,
so its registered source hash required a canonical registry-row refresh before
synchronization could converge. That observation is recorded in the receipt;
this packet does not change discovery behavior or create an unproven recurring
project-improvement signal.
