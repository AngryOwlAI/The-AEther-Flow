# DDR-20260618-007: Documentation Curator Publication Process

## Decision

Route one bounded project-system AgentJob to implement the publication-process
PRD in `implementations_plans/documentation_curator_publication_process_prd.md`
as a new active Documentation Curator process.

## Rationale

The PRD changes the active documentation role, skill contracts, registries,
validators, bootstrap wiring, source specs, generated Markdown, generated
HTML, and pilot-review receipts. It also explicitly requires removing the
previous active implementation rather than reusing it. This is therefore a
project-control-maintainer overlay, not ordinary Documentation Curator page
editing.

## Claim Boundary

This decision authorizes project-system documentation publication machinery
only. It does not authorize ontology edits, exact-GR benchmark promotion,
Gate Chair verdicts, science draft execution, physics claim promotion,
generated derivative authority, external runtime dependency, or corpus-wide
publication migration without explicit user approval.

## Selected Role

`project-control-maintainer@0.1.0--RT-20260618-007` executes the bounded
implementation. The reusable documentation behavior after completion is
`documentation-curator@2.0.0`.
