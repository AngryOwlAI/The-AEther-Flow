does not turn \(\Prof(r)\) into a target-derived object. It sets
\(\Ready(r)=0\) and blocks audit-readiness or adoption routing.

\begin{proof}
\(\Prof(r)\) is defined from source support, source pattern, source
probe-token, source certificate, retained \(\RRE\) syntax, and no-target
certificate data. The scoped evidence fields are routing preconditions, not
profile components. Their deletion therefore changes route status but cannot
manufacture matter semantics or target physics.
\end{proof}

\begin{lemma}[\(\RRE\) non-collapse under profile stress]
Let \(r_0,r_1\in\AdmPMS(E)\) agree except for distinct retained
\(\RRE\) syntax. A source-profile equivalence \(r_0\EqProf r_1\) cannot be
proved by identifying their \(\RRE\) records unless an explicit source-side
transport certificate identifies them.
\end{lemma}

\begin{proof}
The definition of \(\SepProf\) treats retained \(\RRE\) nonidentification as a
source-side separation witness. The P4-T03 audit also blocks reading retained
\(\RRE\) syntax as detector response or matter semantics. Therefore a collapse
without source transport is an obstruction.
\end{proof}

\begin{lemma}[No process receipt can change profile truth]
Changing registry metadata, validator results, handoff wording, role identity,
approval state, generated derivatives, commit state, file order, or local
cache state cannot change \(\Prof(r)\), \(\lambdaProf(r)\), \(\EqProf\), or
\(\SepProf\) unless the mathematical source record changes.
\end{lemma}

\begin{proof}
The candidate's definitions do not mention process receipts as data. The audit
classifies process authority as non-mathematical. Thus process surfaces may
document route and provenance but cannot prove profile status.
\end{proof}
