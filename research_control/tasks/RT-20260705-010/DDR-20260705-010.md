## Rationale

The Process Integrity Auditor role fits because P6-T03 is an integration and
process-boundary decision. The packet does not author new science-source TeX,
modify executable code, or install validator behavior. Its main risk is
overreading support-only tooling as proof authority; the selected role is
therefore constrained to route selection and claim-boundary preservation.

The selected route keeps the P6-T02 executable spec task-local and optional
for advisory reuse. Standing CI-equivalent validation is deferred until P7-T01
defines the minimum physics payload schema and a later validator packet
defines a production validation contract.
