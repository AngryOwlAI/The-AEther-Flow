\section{An arbitrarily small fixed-rank wall crossing}

Over $\Q$, let
\[
 A(t)=\begin{bmatrix}1&0&-1\\0&1&t\end{bmatrix}
      =[e_1,e_2,(-1,t)].
\]
Every $A(t)$ has rank two and every column is nonzero.

\begin{theorem}[Zero unconditional branch-stability radius]
For $t>0$, $A(t)$ is strictly feasible.  At $t=0$ it has a positive
dependence on columns one and three.  For $t<0$ it has a positive dependence
on all three columns.  Consequently the total branch changes along rational
sequences converging to the same rank-two configuration.
\end{theorem}

\begin{proof}
For $t=1/n>0$, take $k=(1,n+1)$.  Its evaluations are
\[
 k(e_1)=1,\qquad k(e_2)=n+1,\qquad
 k(-e_1+t e_2)=-1+(n+1)/n=1/n>0.
\]
At $t=0$, the coefficients $(1,0,1)$ yield zero.  For
$t=-1/n<0$, the strictly positive coefficients $(1,1/n,1)$ yield
\[
 e_1+\frac1n e_2+(-e_1-\frac1n e_2)=0.
\]
The changed third columns at $t=\pm1/n$ differ by $2/n$, which tends to zero.
\end{proof}

The exact tame path records the wall and the adjacent cells.  It does not
derive that a realized source path must stay in one cell.  Thus local
constancy away from walls is true, while unconditional finite-variation
robustness is not supplied.

\section{Source reorientation is not selected}

For any finite rank $r$, write
\[
 A_r^+=[e_1\ \cdots\ e_r\ \mathbf{1}_r],\qquad
 A_r^-=[e_1\ \cdots\ e_r\ -\mathbf{1}_r].
\]
These configurations have the same rank and differ by reorienting one labeled
source vector.

\begin{theorem}[All-rank reorientation branch flip]
$A_r^+$ is strictly feasible, whereas $A_r^-$ is obstructed by a
support-minimal positive circuit of size $r+1$.
\end{theorem}

\begin{proof}
The covector $k=\mathbf{1}_r$ is positive on every column of $A_r^+$.
For $A_r^-$, the all-one coefficient vector gives
$\sum_i e_i-\mathbf{1}_r=0$.  Removing any basis column or the last column
destroys that dependence, so its support is minimal.
\end{proof}

This theorem recovers the sharp arbitrary-rank controls of RT016.  Its Refuter
content is different: $\Bridge$ classifies both orientations but contains no
independent source law choosing one.  Treating orientation as supplied data is
well typed; treating the output as an orientation derivation is not.

\section{Finite refinement has one-way stability}

Let $A_0=[e_1,e_2]$.  The covector $(1,1)$ proves strict feasibility.  Refine
the sector set by adjoining $A_3=-e_1-e_2$.  Rank and all old labeled sectors
remain, but
\[
 e_1+e_2+(-e_1-e_2)=0
\]
is a positive circuit.

\begin{proposition}[Refinement persistence asymmetry]
An existing positive circuit persists under every further column refinement,
but strict feasibility can be destroyed by one finite refinement.
\end{proposition}

\begin{proof}
Extend the old circuit coefficient vector by zeros on newly adjoined columns;
it remains a nonzero nonnegative dependence.  The displayed base and refined
pair proves that feasibility lacks the converse monotonicity.
\end{proof}

Refinement maps therefore provide correct bookkeeping without establishing a
source principle that licenses only branch-preserving refinements.  Finite
sector labels also do not establish exhaustive P7 coverage.
