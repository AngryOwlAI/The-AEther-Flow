\subsection{Audit theorem}

Let \(A,A'\) be sets with equivalence relations induced by quotient maps
\(\chi:A\to K\) and \(\chi':A'\to K'\). For an arbitrary function
\(G:A\to A'\), relation preservation is equivalent to the existence of a
unique set map \(\bar G:K\to K'\) satisfying
\[
  \chi'G=\bar G\chi .
\]
Under this factorization, relation reflection is equivalent to injectivity of
\(\bar G\). This is a theorem in \(\mathbf{Set}\).

If \(A,A'\) are vector spaces, \(B\subseteq A\), \(B'\subseteq A'\) are
subspaces, and \(G\) is linear, then preservation is equivalent to
\[
  G(B)\subseteq B'.
\]
The induced quotient map is then linear, and reflection is equivalent to
\[
  G^{-1}(B')=B.
\]

For a linear chain map \(F:E\to E'\), the chain identities give boundary
preservation, so \(H_1(F)\) is defined and
\[
 \operatorname{RelRefl}(F_1|_{A_E})
 \iff \ker H_1(F)=0
 \iff (F_1|_{A_E})^{-1}(B_{E'})=B_E.
\]
Thus a chain isomorphism is sufficient but not necessary for reflection.

\subsection{Categorical interpretation guard}

The general factorization theorem does not make \(\bar G\) linear. Take
\(A=K=\mathbb F_2\), \(B=0\), and \(G(z)=z+1\). Equality is preserved and
reflected, and the unique induced set map exists, but \(G(0)\ne0\), so it is
not linear. V3 uses ``map'' in the arbitrary-function theorem and separately
marks the linear and chain-map specializations. The guard is therefore
nonblocking.
