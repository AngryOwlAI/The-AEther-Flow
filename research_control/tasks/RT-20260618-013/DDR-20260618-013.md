# DDR-20260618-013: Phase 2A GR Derivation Roadmap

## Decision

Route one bounded Documentation Curator AgentJob to implement Phase 2A of
`research_control/design/documentation_curator_corpus_migration_plan.md`.

## Rationale

The user explicitly approved the next logical step after Phase 1B. The
migration plan defines Phase 2A as one page family:
`gr-derivation-roadmap-explainer`. This packet is within the normal
one-or-two page limit and addresses a public-risk ambiguity: readers need to
understand the derivation burden chain without treating draft/control work,
validator pass state, generated pages, or local retrieval layers as physics
authority.

Phase 2B, `claim-gates-explainer`, is not included in this AgentJob because it
is a separate recommended packet with a different reader job.

## Claim Boundary

This decision authorizes a publication brief, source spec, GitHub-facing
Markdown, tracked HTML derivative, screenshot QA, review evidence, registry
updates, and generated memory/wiki refresh for Phase 2A only. It does not
authorize canonical ontology edits, benchmark promotion, Gate Chair verdicts,
science draft execution, first-principles derivation claims, physics claim
promotion, `M_src` adoption, `g_eff` claims, matter-coupling claims,
Einstein-equation claims, generated-output authority, Phase 2B migration, or
corpus-wide migration.
