# DDR-20260629-001: README Project Website Front-Door Update

## Current Objective

Integrate the human-authored root README update that adds the project website as
an under-development informational surface and removes the untracked local
`Step-by-step-Comments/` directory from the displayed project map.

The linked path in the user note named `.agents/roles/README.md`, but the live
Git diff showed only the root `README.md` modified. `.agents/roles/README.md`
was inspected and had no Git diff.

## Role-Fit Matrix

| Candidate role | Decision | Reason |
| --- | --- | --- |
| Documentation Curator | Accepted | The change is explanatory/front-door Markdown and generated-source synchronization. |
| Project-Control Maintainer | Rejected | No control contract, validator, route, permission, checkpoint, or role semantics are changed. |
| Physics roles | Rejected | No physics source, ontology status, benchmark status, Gate Chair decision, or derivational claim is changed. |

## Decision

Create and execute one bounded Documentation Curator AgentJob:
`AJ-RT-20260629-001-001`.

The job may:

- normalize the root README wording for the project website note;
- preserve the under-development disclaimer;
- keep the displayed project map scoped to tracked project surfaces;
- refresh generated wiki, registry, and local retrieval metadata through the
  approved bootstrap path; and
- write the documentation-impact and completion receipts.

The job may not:

- edit `.agents/roles/README.md` because it has no live diff;
- change role contracts or agent authority;
- edit physics sources;
- promote ontology, benchmark, Gate Chair, or derivational claims; or
- hand-edit generated wiki notes or generated registry sidecars.
