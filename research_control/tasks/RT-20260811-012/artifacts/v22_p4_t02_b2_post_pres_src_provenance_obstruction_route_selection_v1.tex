\section{Exact selector-level mathematics}

\begin{theorem}[Factorization on the image]
Let \(U:E\to R\) and \(F:E\to Y\) be maps.  There is a unique map
\(\overline F:\operatorname{im}U\to Y\) satisfying
\(F=\overline F\circ U\) if and only if \(F\) is constant on every nonempty
fibre of \(U\).  If \(U\) is surjective, this is the unique factorization on
all of \(R\).  Without surjectivity, values outside \(\operatorname{im}U\)
remain unconstrained.
\end{theorem}

\begin{proof}
If \(F\) is fibre-constant, set \(\overline F(U(e))=F(e)\).  Fibre constancy
makes the definition well-defined, and every point of the image has a
preimage, giving uniqueness there.  Conversely any factorization assigns the
same value to elements with the same \(U\)-image.  Surjectivity identifies
the image with \(R\); without it, extensions off the image can vary.
\end{proof}

This theorem corrects two possible overreads.  Fibre constancy is not by
itself physical irrelevance, and a factorization known on the image is not a
unique total map unless surjectivity or additional extension data are proved.

\begin{proposition}[Affine translation control]
No nonempty finite subset of affine \(\R^4\) is invariant under every
translation.  In particular, the translation action selects no invariant
point.
\end{proposition}

\begin{proof}
If a finite nonempty set \(A\) were invariant under every translation, choose
\(a\in A\) and a nonzero vector \(v\).  Invariance would put
\(a+n v\in A\) for every integer \(n\), an infinite subset, contradiction.
\end{proof}

This is a control for the declared affine \(\R^4\) translation action only.
It is not a theorem about manifolds carrying additional source fields and is
not a no-go for future source extensions.

\begin{theorem}[Bounded grammar termination and relative completeness]
Let a typed grammar have finitely many terminals, finitely many constructors
of finite arity, and a fixed finite maximum depth \(d\).  Then the set of
well-typed terms of depth at most \(d\) is finite.  Exhaustive constructor
enumeration terminates and is complete relative to that grammar and depth.
\end{theorem}

\begin{proof}
The depth-zero terminal set is finite.  Inductively, applying finitely many
finite-arity constructors to the finite prior-depth set produces finitely many
new terms.  A finite union remains finite.  The same structural induction
shows that every term licensed by the grammar at each depth is enumerated.
\end{proof}

The executable control uses three terminals, one unary constructor, one
commutative binary constructor, and cumulative counts \(3,12,93\) through
depth two.  These counts validate the enumerator only.  Completeness remains
relative to the declared terminals, constructors, equations, depth, reduct
class, and \(\EqSrc\) coverage.
