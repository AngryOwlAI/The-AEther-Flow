# DDR-20260620-009: Missing Source-Law Inventory Phase 0

## Decision

Route one bounded project-system AgentJob to implement Phase 0 from
`implementations_plans/missing_source_law_inventory_artifact_registry_implementation_plan.md`.

## Rationale

Phase 0 is an evidence audit and schema decision. It determines how the
missing-source-law inventory should enter tracked project control without
creating a second router or a batch packet generator.

The selected implementation shape is Option A with a constrained registry
interpretation:

- create a tracked YAML control artifact at
  `research_control/missing_laws/missing_source_law_inventory.yaml`;
- create a Markdown companion at
  `research_control/missing_laws/missing_source_law_inventory.md`;
- keep `/continue-research` as the only selector and executor;
- register or discover the Markdown companion through existing Markdown source
  machinery in Phase 2 if needed;
- do not create `registries/MISSING_SOURCE_LAW_INVENTORY_REGISTRY.csv` in the
  first rollout.

Inspection shows current bootstrap source registries cover Markdown, TeX, PDF,
and HTML sources. They do not currently provide first-class YAML source
registration. That is sufficient to defer dedicated registry machinery because
the inventory can be consumed by stable tracked path and reviewed through the
Markdown companion.
