# DDR-20260622-009: Phase 6 Bridge Checkpoint Documentation Phase 1 README Update

## Decision

Route one bounded Project-Control Maintainer AgentJob to implement Phase 1 of
the Phase 6 bridge checkpoint governance documentation update.

Phase 1 authorizes one narrow root `README.md` front-door update. The update
may describe the already-implemented project-improvement sidecar bridge,
normal research handoff authority, `/improve-project-system` consumption, and
conditional checkpoint plus `--check-diff` allowlisting. Because the README is
a registered memory source, the task also authorizes the exact historical
`memory_preflight` source-hash refreshes required by
`validate_research_control.py` after the README hash changes.

The task does not authorize validator changes, resolver changes, checkpoint
changes, schema changes, role changes, skill-contract changes, sidecar
creation, sidecar registry changes, publication brief edits, source-spec
edits, GitHub-facing Markdown edits, tracked HTML edits, or physics claim
changes.

## Selected Role

- Role: `project-control-maintainer`
- Version: `0.2.0`
- AgentJob: `AJ-RT-20260622-009-001`
- Execution overlay:
  `project-control-maintainer@0.2.0--RT-20260622-009`

## Rationale

The target README section is control-marked workflow documentation. The change
clarifies existing checkpoint and research-improvement bridge behavior for
operators without changing the machinery. Project-Control Maintainer v0.2.0 is
the narrowest role because it explicitly maintains control-marked mixed
document sections and must preserve separation between regular research
handoffs and project-improvement sidecars.

## Authority Boundary

Allowed:

- Edit only the root `README.md` front-door workflow text.
- Describe project-improvement sidecars as bridge artifacts.
- State that normal research handoffs remain `/continue-research` authority.
- State that sidecars are consumed by `/improve-project-system`.
- State the conditional sidecar checkpoint and `--check-diff` allowlist rule.
- Update task-local control records and required registry rows.
- Refresh only validator-named historical `memory_preflight` `MD-README`
  source hashes.
- Regenerate memory, wiki, registry, and folder-map derivatives through the
  approved bootstrap path.

Forbidden:

- Changing validator, resolver, checkpoint, role, skill, or schema behavior.
- Creating live project-improvement sidecars.
- Creating sidecar registry rows.
- Editing publication briefs, source specs, GitHub-facing Markdown, or tracked
  HTML.
- Hand-editing generated wiki notes or generated registry sidecars.
- Editing canonical physics, ontology, benchmark, or Gate Chair authority
  sources.

## Expected Output

The durable source output is the root `README.md` front-door update under
`## Project-system improvement workflow`.
