# Director Decision Record DDR-20260618-003

## Decision

Route `RT-20260618-003` to one bounded task-overlay
`memory-system-maintainer@0.1.0` AgentJob,
`AJ-RT-20260618-003-001`.

The user requested a legacy ontology folder containing the current ontology
files while keeping `ontology/` available as the live mutable ontology lane.
Because the request also requires wiki PDF Markdown and CSV process updates,
the execution role is Memory-System Maintainer with narrow documentation
support.

## Claim Boundary

Allowed:

- create `legacy_ontology/` with `tex/` and `pdfs/` subfolders;
- copy the current ontology TeX PDF and Markdown package into that lane;
- register legacy TeX rows with `TEX-LEGACY-ONTOLOGY-*` object IDs;
- register legacy PDF rows with `PDF-LEGACY-ONTOLOGY-*` object IDs;
- register legacy Markdown rows as archival noncanonical snapshots;
- refresh generated wiki notes CSV registries Obsidian metadata and folder map
  through bootstrap; and
- update explanatory documentation for the live versus legacy ontology
  boundary.

Forbidden:

- canonical ontology TeX edit;
- live ontology extension or adoption;
- benchmark promotion;
- Gate Chair verdict;
- science draft execution;
- completed-derivation claim;
- treating the legacy snapshot as active canonical ontology authority; and
- generated wiki or PDF hand edits outside the bootstrap/copy path.
