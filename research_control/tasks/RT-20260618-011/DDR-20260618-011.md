# DDR-20260618-011: Phase 1A Public Physics Status

## Decision

Route one bounded Documentation Curator AgentJob to implement Phase 1A of
`research_control/design/documentation_curator_corpus_migration_plan.md`.

## Rationale

The user explicitly approved moving from Phase 0 to Phase 1. The migration
plan defines the first normal packet as two public pages:
`exact-gr-benchmark-boundary-explainer` and
`aether-flow-physics-program-explainer`. That packet size is within the normal
one-or-two-page limit and addresses the highest public-risk ambiguity: exact-GR
benchmark adoption is not a completed first-principles substrate derivation.

Phase 1B, `aether-flow-ontology-explainer`, is not included in this AgentJob
because it is a separate recommended packet with a different source emphasis.

## Claim Boundary

This decision authorizes publication briefs, source specs, GitHub-facing
Markdown, tracked HTML derivatives, screenshot QA, review evidence, registry
updates, and generated memory/wiki refresh for Phase 1A only. It does not
authorize canonical ontology edits, benchmark promotion, Gate Chair verdicts,
science draft execution, first-principles derivation claims, physics claim
promotion, generated-output authority, Phase 1B migration, or corpus-wide
migration.
