# Director Decision Record: DDR-20260629-042

## Decision

Execute P3-T01 as one bounded `theoretical-continuation-selector@0.1.0`
task overlay and fold P3-T02 control-state declaration into the same
transaction.

## Basis

`handoff-0336` requires one deliberate post-v12 theoretical selector before
new physics continuation. The v12 plan recommends source-extension
minimization/compression unless the live state has advanced. Live tracked
state has not advanced beyond the P2 reader-summary packet. The frontier
inventory and Distance-to-GR ledger show that several scoped source-extension
objects or preconditions are useful for routing, but they remain bounded by
no source-law adoption, no `MetricData(E)` adoption, no `g_eff` scope
expansion, no matter-coupling derivation or adoption, no stress-energy
semantics, no Einstein equations, no benchmark promotion, and no completed
derivation.

P4-T01 is the smallest constructive next step because it extracts the
dependency graph before any matter-semantics or proof-support work is asked to
build on the stack. This is not generic continuation: it has a declared
milestone, an exact burden, a single next packet, and a route consequence.

## Milestone And Burden

Target derivation milestone: `matter_coupling`.

Milestone burden: extract and classify the source-extension dependency stack
used by `Resp_lc`, `M_src`, scoped `g_eff`, and matter-coupling precondition
evidence before any matter-semantics, proof-assistant, Einstein-equation, or
benchmark route treats that stack as a stable physical basis.
