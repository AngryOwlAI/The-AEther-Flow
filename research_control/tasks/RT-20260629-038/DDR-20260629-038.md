# Director Decision Record: DDR-20260629-038

## Decision

Select Option A. The canonical frontier theorem inventory source location is:

`research_control/design/frontier_theorem_inventory.md`

It is registered as Markdown control material. P2-T02 creates the source
location with an empty inventory section. P2-T03 must populate the inventory
items.

## Basis

`handoff-0332` routes exactly one P2-T02 packet: decide where the populated
frontier theorem inventory should live and how it should be registered.

The P2-T01 schema states that the inventory is a compact source-backed control
surface and not independent scientific authority. The planned P2-T03 inventory
will summarize existing source artifacts, accepted scoped objects, obstructions,
frozen routes, and missing theorem burdens. It is not authorized to create new
canonical theorem propositions or definitions.

Therefore Option A is correct. Option B would be appropriate only if the
inventory itself stated new science-bearing theorem propositions, definitions,
or mathematical claims with canonical physics authority.
