\section{Target Claim and Stress Scope}

Let
\[
 \Fsrc=\{A_0,A_1,A_2,A_3\},\qquad
 G=\mathbb Z/4\mathbb Z,\qquad H=\{0,2\},
\]
with base profile \(s(A_i)=i\). The candidate defines
\[
 \Sel_s(A,B)=\Pass
 \quad\Longleftrightarrow\quad
 q(s(A))=q(s(B)),
\]
where \(q:G\to G/H\). Its base classes are
\(\{A_0,A_2\}\) and \(\{A_1,A_3\}\).

The stress attacks only the overread that this exact finite construction,
without another source law, supplies a uniquely selected current-ontology
EqSrc relation, an independently justified physical variation class, or
physical covariance. The internal quotient arithmetic and conditional
exact-v3 lifting remain legitimate model claims under their displayed
assumptions.

\section{Profile-Reassignment Nonuniqueness}

\begin{theorem}[Three-partition orbit]
Among the \(24\) bijections \(s:\Fsrc\to\mathbb Z_4\), the quotient selector
realizes exactly the three two-plus-two partitions of \(\Fsrc\), with eight
profiles per partition.
\end{theorem}

\begin{proof}
The quotient \(q\circ s\) assigns two objects to each coset. Choosing one
two-element fiber gives \(\binom42=6\) choices; identifying a fiber with its
complement leaves three unordered partitions. For a fixed partition, either
block can be the even coset and each block has two internal assignments, so
\(2\cdot2\cdot2=8\) profiles realize it.
\end{proof}

For example,
\[
 s=(0,1,2,3)
 \quad\hbox{selects}\quad
 \{\{A_0,A_2\},\{A_1,A_3\}\},
\]
whereas
\[
 s'=(0,2,1,3)
 \quad\hbox{selects}\quad
 \{\{A_0,A_1\},\{A_2,A_3\}\}.
\]
Both profiles use the same bare objects, group, and subgroup. The current
ontology inspected for this packet supplies no rule selecting one table.

\section{Active Symmetry Versus Decorated Transport}

\begin{theorem}[Fixed-selector stabilizer]
The stabilizer of the base two-plus-two partition inside \(S_4\) has eight
elements, and its orbit has three elements.
\end{theorem}

\begin{proof}
A preserving permutation may swap the two elements within each block and may
swap the two blocks. This gives
\((S_2\times S_2)\rtimes S_2\), of order \(2\cdot2\cdot2=8\).
Orbit--stabilizer gives \(24/8=3\), agreeing with the three partitions above.
\end{proof}

If a permutation \(\varphi\) transports both objects and the full profile,
then \(s^\varphi=s\circ\varphi^{-1}\) and
\[
 \Sel_{s^\varphi}(\varphi A,\varphi B)=\Sel_s(A,B).
\]
This identity holds for all \(24\) permutations because the selector-bearing
decoration is transported with the presentation. By contrast, only the eight
stabilizer permutations preserve the fixed undecorated relation. The
transposition exchanging \(A_1\) and \(A_2\) moves the base partition to a
different orbit element.

Therefore decorated transport equivariance is not an active symmetry of the
fixed bare-source relation. It establishes neither uniqueness, observer
independence, empirical invariance, nor physical covariance.

\section{Variation Fragility and the Admissibility Dichotomy}

For \(r:\Fsrc\to G\), let \(s_r=s+r\). The prior audit proved that the full
additive relation stabilizer is
\[
 \operatorname{Stab}_{\mathrm{add}}(\Sel_s)
 =\{r:q(r(A))\ \hbox{is constant in }A\},
\]
which has \(32\) elements. The declared
\(\Vary=H^{\Fsrc}\) has \(16\) elements and is the zero-coset half.

\begin{proposition}[Admissibility--invariance dichotomy]
For any proposed variation class \(\mathcal A\subseteq G^{\Fsrc}\), the
selector is invariant under every member of \(\mathcal A\) if and only if
\[
 \mathcal A\subseteq
 \operatorname{Stab}_{\mathrm{add}}(\Sel_s).
\]
Consequently, any class containing one relation-changing shift fails the
claimed robustness.
\end{proposition}

\begin{proof}
The equivalence is the definition of the full stabilizer. The prior exact
stabilizer theorem identifies that set with the constant quotient-coset
shifts. Any element outside it changes at least one pair decision.
\end{proof}

Of the \(256\) additive shifts, \(224\) change the relation. Restricting to
shifts for which \(s_r\) remains bijective still leaves \(16\) changing
profiles. The explicit profile reassignment above corresponds to
\[
 r=s'-s=(0,1,3,0)\pmod4
\]
and changes the partition while preserving bijectivity.

This does not show that the declared \(\Vary\) is mathematically invalid. It
shows that calling a selector-preserving class ``physically admissible'' is
not an independent robustness argument unless another source law selects that
class without using preservation of the desired answer as its criterion.
Current ontology does not derive such a law in the inspected scope.

\section{Scoped Obstruction}

\begin{quote}

that uniquely selects the primitive profile and a physically admissible
variation class for this candidate.
\end{quote}

The finite countermodel is the pair \((s,s')\) above together with the
injectivity-preserving shift \(r=(0,1,3,0)\). The same bare source set and group
data produce different nondegenerate relations. This blocks using the exact
candidate alone as a current-ontology-derived or physically necessary EqSrc
selector.

The obstruction is local. It does not refute the candidate as proposal-only
source-extension data, prove that no distinct symmetry-breaking source law can
exist, reject the global ontology, or prove future source-extension
impossibility.
