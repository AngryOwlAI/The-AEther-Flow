\begin{abstract}
This draft/control Refuter artifact stress-tests the local
\(\EqIso\) datum from task \texttt{RT-20260613-026}, after the
smuggling audit in task \texttt{RT-20260613-027}. The stress test retains
the local result only for the manifest-bound source-relabeling orbit:
bijective relabeling preserves token class, proxy mapping, annotation
content, influence-edge incidence, and local adjudicator shape. The result
does not survive as general \(\EqSrc\). Nontrivial source-object
variation, invariant weakening, expanded negative controls, influence
perturbation, and quotient-use pressure return \(\Block\) or require a new
source-equivalence datum. Therefore \(\EqSrc\), \(\RetainH\), \(\GenH\),
candidate reconstruction, canonical ontology edit, benchmark promotion,
Gate Chair review, and completed-derivation language remain blocked.
\end{abstract}

\section{Scope}

This artifact is the role output for task \texttt{RT-20260614-002}. It
attacks only the local datum
\[
    \mathcal{E}_{0}^{\mathrm{iso}} =
    (\Obj,\Inv,\Cmp,\Annot,\Influence)
\]
and its audited status as a source-relabeling witness. It does not attempt
semantic \(\NoTargetH\), canonical \(\NoTargetSyn\) adoption, global
\(\EqSrc\), \(\RetainH\), \(\GenH\), or candidate construction.

\section{Adversarial Screens}

\begin{screen}[Five stress dimensions]
The Refuter applies five local screens:
\begin{enumerate}
    \item \textbf{Nontrivial source-object variation}: replace the
    relabeled copy with source objects that alter annotations, proxies,
    influence incidence, object-family membership, or comparison scope.
    \item \textbf{Equivalence-relation pressure}: test whether the local
    judgment supplies reflexivity, symmetry, transitivity, and quotient
    behavior beyond the relabeling orbit.
    \item \textbf{Expanded negative controls}: ask whether the comparison
    blocks annotation weakening, unmapped proxies, omitted influence
    coverage, new target-success proxies, and altered manifest use.
    \item \textbf{Invariant weakening}: remove one required source-side
    invariant and test whether the positive result becomes label agreement
    rather than source structure.
    \item \textbf{Quotient or downstream use}: test whether the local
    relation can support \(\RetainH\), \(\GenH\), candidate selection, or
    benchmark-facing construction.
\end{enumerate}
\end{screen}

\section{Nontrivial Source-Object Variation}

\begin{variant}[Relabeling orbit]
Let \(X_{0}\) be the registered base object and let \(X_{1}\) be the
structure-preserving relabeling from \texttt{RT-20260613-026}. For this
pair alone, the positive judgment remains local:
\[
    \Cmp(X_{0},X_{1};\Inv)=\EqIso(X_{0},X_{1}).
\]
This is a relabeling-orbit result, not a family-level source-equivalence
result.
\end{variant}

\begin{variant}[Object-family variation]
Let \(Y\) be a source object that changes any one of the following:
annotation content, proxy-class coverage, influence-edge incidence,
manifest-use limit, or comparison-rule scope. The current datum supplies
no source-only witness ledger proving
\[
    \Cmp(X_{0},Y;\Inv)=\EqSrc(X_{0},Y).
\]
The correct result is \(\Block\) or a requirement for a new registered
datum, not promotion from \(\EqIso\) to \(\EqSrc\).
\end{variant}

\begin{finding}[Generalization fails at the object-domain boundary]
The object domain in \texttt{RT-20260613-026} contains one positive
relabeling pair and two negative controls. It does not contain a
nontrivial source-object family with declared source-only invariants,
witness pairs, and comparison receipts. The stress test therefore blocks
family-level use.
\end{finding}

\section{Equivalence-Relation Pressure}

\begin{finding}[Reflexivity and symmetry are local at most]
The identity map on \(X_{0}\) and the inverse relabeling between
\(X_{0}\) and \(X_{1}\) are compatible with the local relabeling orbit.
This supports only the expected behavior of a syntactic isomorphism
relation on the declared pair. It does not supply an equivalence relation
over generated ledgers or candidate families.
\end{finding}

\begin{finding}[Transitivity is underdetermined outside relabeling copies]
A third relabeled copy \(X_{2}\), if explicitly registered with the same
source invariants, would test transitivity inside the relabeling orbit.
No such registered object is present in the current datum, and no
non-relabeling source object is equipped with a comparison ledger.
Therefore transitivity outside the relabeling orbit remains unproved.
\end{finding}

\begin{finding}[Quotient behavior is missing]
The current datum does not define quotient classes, representative
selection, invariant descent, or preservation of blocker edges under
quotienting. Any downstream use that treats \(\EqIso\) as a quotient-ready
\(\EqSrc\) relation must return \(\Block\).
\end{finding}

\section{Expanded Negative Controls}

\begin{variant}[Annotation weakening]
If path, object identifier, hash, timing, rule scope, dependency,
exclusion, proxy classification, influence-edge content, or manifest-use
limits are removed, the comparison no longer has checkable source basis.
The result is \(\Block\).
\end{variant}

\begin{variant}[Proxy and influence perturbation]
If a proxy class is omitted, a new target-success proxy is added, an
influence edge is deleted, or a new influence edge is required by a proof
step outside the manifest, the current datum does not extend. The result
is \(\Block\) or a superseding-manifest requirement.
\end{variant}

\begin{finding}[Negative-control retention is local]
The two registered negative controls demonstrate that the comparison can
block annotation weakening and unmapped proxy use. They do not demonstrate
complete negative-control retention across source-object families,
relation classes, quotient classes, or generator outputs.
\end{finding}

\section{Invariant Weakening}

\begin{variant}[Dropping required invariants]
Let \(\InvWeak\) be obtained from \(\Inv\) by dropping token-class
incidence, forbidden-channel orientation, proxy-class coverage,
annotation content, influence-edge incidence, no-closed-world discipline,
or local adjudicator shape. Under \(\InvWeak\), a positive comparison may
be selected by notation similarity, authority status, validation passage,
or untracked target-proxy behavior. The weakened comparison is therefore
not admissible evidence for \(\EqSrc\).
\end{variant}

\begin{finding}[The positive result is invariant-heavy by necessity]
The local pass depends on preserving every declared invariant. That
dependence is a guard, not a defect, but it prevents treating the result as
a robust or minimal source-equivalence principle.
\end{finding}

\section{Downstream-Use Pressure}

\begin{finding}[Retain and generator burdens are untouched]
\(\RetainH\) would require adverse-output retention or preservation
conditions after source-equivalence decisions. \(\GenH\) would require a
source-side generator with validated output conditions. The local
\(\EqIso\) datum supplies neither burden.
\end{finding}

\begin{finding}[Candidate construction remains premature]
Candidate reconstruction would need source-equivalence, retention, and
generator evidence that is not provided by a relabeling witness. The
Refuter therefore blocks candidate use, canonical ontology edit, benchmark
promotion, Gate Chair review, and completed-derivation language.
\end{finding}

\section{Stress Verdict}

\begin{verdict}[Local relabeling result retained]
The local \(\EqIso\) datum survives only as source-relabeling
draft/control evidence for the manifest-bound pair \((X_{0},X_{1})\) and
the exact invariants declared in \texttt{RT-20260613-026}.
\end{verdict}

\begin{verdict}[General EqSrc remains blocked]
The datum does not survive generalization pressure as \(\EqSrc\).
Nontrivial source-object variation, relation-property requirements,
expanded negative-control retention, invariant weakening, and quotient or
downstream-use demands all produce \(\Block\), underdetermination, or a
requirement for a new registered source-equivalence datum.
\end{verdict}

\begin{verdict}[No downstream discharge follows]
This stress result does not prove semantic \(\NoTargetH\), does not
canonically adopt \(\NoTargetSyn\), does not discharge \(\EqSrc\),
\(\RetainH\), or \(\GenH\), and does not authorize candidate
reconstruction, canonical ontology edit, benchmark promotion, Gate Chair
review, or completed-derivation language.
\end{verdict}
