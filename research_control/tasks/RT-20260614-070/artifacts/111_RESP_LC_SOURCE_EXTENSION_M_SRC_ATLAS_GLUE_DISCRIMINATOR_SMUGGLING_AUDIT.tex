\section{Audit Lemmas}

\begin{lemma}[No-target-discriminator import as written]
Under the written source-symbol reading of \(\AtlasGlueDisc\), repaired
transition selection uses source carriers, source readout syntax,
response-label syntax, source discriminator profiles, source compatibility
relations, source candidate partial bijections, and source selector preorders.
It does not use target topology, target smooth atlas data, target coordinate
transitions, metric scale, proper time, empirical calibration, benchmark
behavior, validation receipts, generated derivatives, or role labels.
\end{lemma}

\begin{proof}
The profile maps have domain \(U_i\) and codomain source-token sets
\(D_i^+\). Refined compatibility is defined from overlap membership,
readout/response-label compatibility, and discriminator-profile compatibility.
Candidate transitions are partial bijections between source carriers. The
selector chooses only by a supplied source preorder and returns \(\bot\) when
unique source-minimal selection is absent. No step calls target open sets,
target coordinate maps, differentiability, metric tensors, interval scale,
proper-time functionals, empirical calibration, benchmark solutions,
validation receipts, generated notes, or role labels. Therefore the written
primitive avoids target-discriminator import under the stated dependency
reading.
\end{proof}

\begin{lemma}[Discriminator-authority guard]
The \(\AtlasGlueDisc\) primitive remains source-pure only if discriminator
profiles, discriminator compatibility, candidate filters, and selector
preorders are explicit source-side data. If those data are inferred from
target geometry, benchmark behavior, validator success, registry status, role
authority, generated derivatives, or the bare label ``source-side'', the
primitive fails this audit.
\end{lemma}

\begin{proof}
The conditional theorem in \texttt{RT-20260614-069} proves uniqueness only
relative to supplied data \((\mathcal A^+,\mathcal D^+)\). It does not derive
\(\Disc\), \(\Prof_i\), \(\equiv_{ij}^{\Delta}\), \(\Cand_{ij}\), or
\(\preceq_{ij}^{\Delta}\) from the current canonical ontology or old retained
source tuple. Replacing explicit source data with process authority changes
the dependency basis. Replacing them with target or benchmark structure
imports the forbidden structure. Therefore source-purity requires explicit
source-side inputs, and absence must route to \(\bot\), not to authority-based
selection.
\end{proof}

\begin{lemma}[Finite-variation guard]
Strict discriminator-preserving finite variation does not imply arbitrary
finite-variation robustness.
\end{lemma}

\begin{proof}
The strict stability result preserves discriminator values, refined
compatibility, candidate membership, and selector preorder. A variation that
merges \(h_0\) and \(h_1\), removes discriminator tokens, adds uncontrolled
duplicate-compatible tokens, or changes \(\preceq_{ij}^{\Delta}\) can destroy
unique source-minimal selection and force \(\Sel_{ij}(\Cand_{ij})=\bot\).
Thus the positive stability result is narrower than the project-level
finite-variation burden.
\end{proof}
