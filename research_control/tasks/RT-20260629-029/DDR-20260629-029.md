# Director Decision Record: DDR-20260629-029

## Decision

Select `process-integrity-auditor@0.1.0` for one bounded v12 P0-T01
implementation-plan intake packet.

## Basis

`research_control/program_state.yaml` names `RT-20260614-290` and
`handoff-0323`. The latest handoff says no v11 implementation-plan task
remains and that ordinary continuation must resume under a new tracked
objective. The v12 plan exists at
`implementations_plans/recommendations_implementation_plan_continue_task-v12.md`,
but it is ignored by the repository-wide `implementations_plans/*` rule and is
not known to Git.

The packet is process-control intake. It tracks the v12 implementation plan as
implementation guidance only and records the starting point for the later P0
baseline snapshot. It does not change the Distance-to-GR ledger, science
artifacts, canonical ontology, benchmark status, or Gate Chair authority.

- Add a single-file `.gitignore` exception for the v12 implementation plan.
- Track `implementations_plans/recommendations_implementation_plan_continue_task-v12.md`.
- Create the P0-T01 task packet, role overlay, AgentJob, completion receipt,
  documentation-impact receipt, claim-boundary row, and handoff.
- Update `program_state.yaml`, the current-frontier snapshot, generated memory
  metadata, and control registries as required by validation and checkpoint.

Blocked:

- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
- unscoped `g_eff` adoption;
- `g_eff` scope expansion;
- coupling-law adoption;
- matter-coupling derivation or adoption;
- stress-energy semantics;
- stress-energy tensor;
- matter action;
- detector semantics;
- Einstein equations;
- exact-GR benchmark promotion;
- benchmark Gate Chair closure;
- completed derivation;
- treating implementation-plan tracking, baseline snapshots, handoffs,
  generated graph, checker output, metrics, validator output, registry
  metadata, memory layers, approval, local cache, or commit status as
  scientific proof.
