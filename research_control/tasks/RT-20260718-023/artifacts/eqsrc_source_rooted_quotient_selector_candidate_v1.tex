\section{Construction Question and Inputs}

RT-20260718-022 showed that exact v3 admits an abstract nonidentity witness but
does not select its primitive cross-fiber decisions or declare an admissible
finite-variation class. The present bounded question is whether one can add
explicit proposal-only source data that:
\begin{enumerate}[leftmargin=*]
  \item selects a relation strictly between equality and the universal
  relation;
  \item instantiates every rank-0 through rank-2 input of exact v3 without a
  target or workflow leaf;
  \item makes the accepted identity, inverse, and composition clauses hold;
  and
  \item has a nontrivial finite-variation class under which the selector is
  provably invariant.
\end{enumerate}

The construction is an existence witness for this bounded question. It does
not establish why nature or current ontology should select its finite profile
or subgroup.

\section{Source-Rooted Finite Datum}

\begin{definition}[Proposal-only source profile datum]

 \mathcal F_{\mathrm{src}}=\{A_0,A_1,A_2,A_3\},\qquad

\]
Each \(A_i\) carries a declared primitive source token \(\tau_i\). Declare
\[
 s:\mathcal F_{\mathrm{src}}\longrightarrow G,\qquad s(A_i)=i\pmod 4.

The data \((\tau_i,G,H,s)\) are new proposal-only source-extension leaves.

Let \(q:G\to G/H\) be the quotient map. Define the endpoint selector

 \Sel(A,B)=\Pass
 \quad\Longleftrightarrow\quad
 q(s(A))=q(s(B))

 s(B)-s(A)\in H.
\]
Every node in this definition tree is either one of the displayed source
leaves or finite group arithmetic on those leaves.

\section{Closure and Exact-v3 Candidate Law}

\begin{proposition}[Endpoint selector closure]
The selector is reflexive, symmetric, and transitive.
\end{proposition}

\begin{proof}
Reflexivity follows from \(0\in H\). If \(s(B)-s(A)\in H\), closure of the
subgroup under inverses gives \(s(A)-s(B)\in H\). If
\(s(B)-s(A)\in H\) and \(s(C)-s(B)\in H\), closure under addition gives
\[
 s(C)-s(A)=\bigl(s(C)-s(B)\bigr)+\bigl(s(B)-s(A)\bigr)\in H.
\]
\end{proof}

\begin{proposition}[Bounded exact-v3 model]
Under the displayed v3 provenance equation schemes, the finite datum
satisfies every candidate-law clause of \(\Law\).
\end{proposition}

\begin{proof}
Accepted identity, inverse, and composition totality follow from endpoint
selector closure. Singleton ledger and proxy fibers make their unit, inverse,
composition, associativity, and congruence equations automatic. The v3
provenance congruence supplies the corresponding typed equations for the
provenance component. The singleton negative outcome is invariant under all
certificate congruences. Hence certificate congruence, acceptance invariance,
unit compatibility, inverse compatibility, associativity compatibility, and
component coherence hold. All carriers, maps, trees, and witnesses have been
displayed, so no fail-closed branch is triggered.
\end{proof}

\section{Nontrivial Admissible Finite-Variation Class}

\begin{definition}[Objectwise subgroup-valued variations]
Let \(\Vary\) contain every finite profile variation
\[
 s_h(A)=s(A)+h_A,\qquad h_A\in H
 \quad(A\in\mathcal F_{\mathrm{src}}),
\]
with \(G\), \(H\), the endpoint tokens, and all exact-v3 constructors held
fixed. The class includes the identity variation and nonidentity variations;
for example, \(h_{A_0}=2\) and \(h_A=0\) for \(A\neq A_0\).
\end{definition}

Because \(|H|=2\) and there are four source objects, \(\Vary=H^{\mathcal F}\)
contains the identity and \(15\) nonidentity variations. This is an explicit
nontrivial finite-variation class. Calling it
``admissible'' is part of the candidate definition, not a conclusion of
current ontology or empirical evidence.

\section{Selector Stability Certificate}

\begin{proposition}[Stability under \(\Vary\)]
For every \(s_h\in\Vary\) and every \(A,B\),
\[
 s_h(B)-s_h(A)\in H
 \quad\Longleftrightarrow\quad
 s(B)-s(A)\in H.
\]
Consequently all ledger decisions, acceptance values, and induced relation
classes are invariant under \(\Vary\).
\end{proposition}

\begin{proof}
The varied difference is
\[
 s_h(B)-s_h(A)
 =s(B)-s(A)+(h_B-h_A).
\]
Because \(h_A,h_B\in H\), their difference lies in \(H\). Adding an element
of \(H\) preserves membership in the subgroup coset \(H\). The equivalence
follows in both directions by adding the inverse element. The ledger decision
is exactly this membership test and the other acceptance components are
constant \(\Pass\), so acceptance and the induced relation are unchanged.
\end{proof}

The theorem preserves the quotient profile \(q\circ s\), not necessarily the
fine profile \(s\). An allowed objectwise shift can destroy injectivity of
\(s\) while leaving every selector value unchanged.

\section{Transport Naturality}

For a bijection \(\varphi:\mathcal F_{\mathrm{src}}\to\mathcal F'_{\mathrm{src}}\),
transport the profile by
\(s^\varphi=s\circ\varphi^{-1}\) and reindex the endpoint ledger, proxy, and
provenance data along \(\varphi\). Then
\[
 \Sel^\varphi(\varphi A,\varphi B)=\Sel(A,B).
\]
For any group automorphism \(\alpha:G\to G\) with
\(\alpha(H)=H\), use \(s^\alpha=\alpha\circ s\). Since
\[
 s^\alpha(B)-s^\alpha(A)
 =\alpha\bigl(s(B)-s(A)\bigr),
\]
membership in \(H\) is preserved. Thus the selector is equivariant under
source-object relabeling and under the subgroup-preserving automorphisms of
\(\mathbb Z_4\). This is mathematical transport naturality only; it is not a
claim of physical covariance or empirical invariance.

\section{Qualified Sharpness Outside the Declared Class}

The stability theorem does not extend to arbitrary objectwise \(G\)-valued
shifts. Initially \(A_0\sim A_2\) because \(2-0\in H\). Use the
injectivity-preserving shift
\[
 r(A_0)=1,\qquad r(A_1)=3,\qquad r(A_2)=r(A_3)=0,
\]
which changes the profile from \((0,1,2,3)\) to \((1,0,2,3)\).
Now \(A_0\sim A_2\) changes from \(\Pass\) to \(\Block\), while
\(A_1\sim A_2\) changes from \(\Block\) to \(\Pass\). This
countervariation recovers the selector sensitivity isolated by
RT-20260718-022 and shows that independently varying quotient components can
change the relation.

The qualification is important: \(H\)-valued shifts are sufficient but not
maximal. The full additive stabilizer is the class of \(r:\mathcal F\to G\)
for which all \(r(A)\) lie in one common coset of \(H\); equivalently,
\(q(r(A))\) is constant in \(A\). A uniform shift by \(1\notin H\) therefore
also preserves the selector. Nothing here proves that \(\Vary\), or the
larger stabilizer, is physically preferred.
