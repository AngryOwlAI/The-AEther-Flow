# Director Decision Record: DDR-20260614-280

## Decision

Select `memory-system-maintainer@0.2.0` for one bounded P7-T02 extractor
implementation packet.

## Basis

`handoff-0312` requires one P7-T02 memory-system-maintainer packet to implement
the deterministic dependency graph extractor and generated graph artifacts.
The P7-T02 plan requires a script that reads tracked registries, completions,
handoffs, and current state; creates nodes and edges for tasks, jobs,
artifacts, ledger burdens, named physics objects, payload manifests, Gate Chair
verdicts, and blocked claims; emits generated graph artifacts; and marks the
graph as navigational support only.

The selected role is appropriate because the packet changes memory-system and
registry-support tooling without changing scientific authority.

## Scope

Allowed:

- Create `scripts/research_control/render_dependency_graph.py`.
- Generate `output/research_dependency_graph.json`.
- Generate `wiki/indexes/research_dependency_graph.md`.
- Generate `output/research_dependency_graph.dot`.
- Add focused tests for frontier coverage, edge integrity, deterministic
  rendering, and output formats.
- Update control registries, task records, documentation-impact receipt,
  `program_state.yaml`, and `handoff-0313`.

Blocked:

- freshness validator integration for P7-T03
- canonical ontology edit
- source-law adoption
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- matter action
- detector semantics
- Einstein equations
- benchmark promotion
- completed derivation
- treating graph data as physics evidence or control authority
- Distance-to-GR ledger change
- Gate Chair verdict or protected evidence-status change

## Role-Fit Matrix

| Candidate role | Decision | Reason |
| --- | --- | --- |
| Memory-System Maintainer | Selected | P7-T02 implements generated memory/navigation tooling from tracked sources. |
| Project-Control Maintainer | Not selected | P7-T01 already defined the control schema. |

| Documentation Curator | Not selected | The generated Markdown is a graph index, not explanatory documentation. |
| Physics roles | Not selected | The packet has no physics milestone and no scientific payload. |

## Result

The selected packet implements the graph extractor, emits the three generated
graph artifacts, and routes the next bounded packet to P7-T03 freshness
validation.
