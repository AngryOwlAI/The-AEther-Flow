\section{New audit mathematics}

\subsection{Common holonomy has two exact codimension scopes}

\begin{theorem}[Common-holonomy classification]
For a connected one-cycle source groupoid, a positive one-dimensional
representation is classified up to positive object cochains by its positive
cycle holonomy.  Three sector representations descend to one common positive
character if and only if their three log holonomies lie on
\[
 \Delta=\{(h,h,h):h\in\R\}\subset\R^3.
\]
Thus descent to some common character has codimension two in the independent
three-sector log-holonomy space.  If the RT010 character class is held fixed as
a fourth coordinate, the three equations
$[\log\rho_s]=[\log\chi]$ have codimension three in the resulting
four-dimensional class space.
\end{theorem}

\begin{proof}
Multiplying a representation by an object coboundary contributes one factor at
each path endpoint; those factors cancel around a closed cycle.  Cycle
holonomy is therefore invariant.  If every sector is intertwined with one
character, their holonomies must agree.  Conversely, fix a base object and a
path from it to every object.  Equal cycle holonomy makes the ratio between a
sector representation and the proposed common character path independent, so
the ratios define a positive object cochain and hence an intertwiner.
\end{proof}

RT010 lies on $\Delta$ because every $\rho_s$ is defined as a cochain twist of
the same $\chi$.  No target quantity is used to select that diagonal.  Still,
the diagonal is the desired common-descent property itself.  The correct audit
classification is therefore ``transparent high-cost new source-law premise,''
not ``derived common response law.''

\begin{proposition}[Arbitrarily small holonomy countermodel]
Let $\omega$ be the additive edge cochain with $\omega(e_{01})=1$ and zero on
the other two oriented generators.  For $\epsilon\ne0$, replace only the
$R$-sector law by
\[
 \rho_R^{\epsilon}(\gamma)=\rho_R(\gamma)
 \exp\!\bigl(\epsilon\omega(\gamma)\bigr).
\]
This remains a positive source representation, but its cycle-holonomy ratio to
$\chi$ is $\exp(\epsilon)$.  No positive object cochain intertwines it with the
fixed $\chi$.  The generator-log perturbation can be arbitrarily small.
\end{proposition}

This target-free countermodel lies outside the fixed RT010 universal-character
axiom.  It proves nongenericity and selects a robustness test; it does not
retroactively turn the disclosed fixed law into a hidden import.

\subsection{Anchors choose representatives; they do not create descent}

\begin{proposition}[Pointed anchor and forgetful obstruction]
Assume the common-holonomy condition.  Without sector anchors, the positive
intertwiner family is a torsor for one constant $c_s\in\Rp$ per sector.  After
quotienting one common diagonal scale, three sectors retain $(\Rp)^2$ relative
moduli.  The anchors $a_s(0)=1$ select one representative in the fixed framed
candidate.  If the sector holonomies differ, no choice of anchors produces a
common character.
\end{proposition}

\begin{proof}
The ratio of any two intertwiners between the same one-dimensional connected
representations is a positive constant, independently for every sector.  A
common frame change removes only the diagonal constant.  Evaluating each
intertwiner at the pointed base object forces its constant to one.  Holonomy is
unchanged by object cochains, so an anchor cannot repair unequal holonomies.
\end{proof}

The anchors are therefore lawful only as declared structure in a pointed,
framed source-law proposal.  They are not a physical normalization,
calibration, current-ontology fact, or invariant selector after forgetting the
pointing and frames.

\subsection{The variation witness belongs to an open typed family}

\begin{lemma}[Relative openness of nonvacuity]
Fix $d\ne0$.  In the relative parameter space defined by $Bd=0$ and $m(d)=0$,
the conditions
\[
 \operatorname{rank}B=2,\qquad
 \operatorname{rank}\!\begin{pmatrix}B\\m\end{pmatrix}=3
\]
are open.  They imply
$\dim(\ker B/\operatorname{span}\{d\})=1$ and that $m$ induces a nonzero
functional on that quotient.
\end{lemma}

\begin{proof}
Each rank condition is the nonvanishing of at least one minor.  Such
nonvanishing persists in an open neighborhood.  The first rank condition gives
$\dim\ker B=2$; since $d\in\ker B$, the quotient has dimension one.  The stacked
rank condition says that $m$ is not in the row span of $B$, equivalently that
$m$ does not vanish on all of $\ker B$.
\end{proof}

For the fixed witness the stacked rank is three and $m(v)=2$.  The exact audit
model also checks source-typed rational perturbations at
$\epsilon=-1/10,0,1/10$ for which $B_\epsilon d=0$, both ranks persist, and
nonvacuity remains.  Hence the balance-law feature is not an isolated numerical
accident.  This does not protect the common-holonomy diagonal against
independent sector-law perturbations.
