\section{Stress Lemma}

\begin{lemma}[Fail-closed stress survival of \(\MetricRespTok\)]

\texttt{RT-20260614-144} hidden-import audit boundary, every named Refuter
stress branch either remains a source-side proof obligation, returns
\(\BottomSrc\), or returns a named \(\OBGEFF\) obstruction. No branch yields
adopted \(\MetricRespTok\), non-bottom \(\MetricData(E)\), or \(\geff\).

\begin{proof}
MRT1 requires a source-only domain and forgetful conservativity. MRT2 through
MRT5 require source-side token families, response relations, and transition
covariance rather than target metric, target atlas, target transition,
Lorentzian-signature, or proper-time structure. MRT6 through MRT8 require
nondegeneracy, finite-variation compatibility, selector discipline, and bottom
behavior. Each failure of these requirements is explicitly a bottom or
obstruction branch. The audit excludes benchmark and process authority as
mathematical premises. Therefore the stress branches cannot promote missing,
nonunique, or contaminated data into non-bottom \(\MetricData(E)\). They can
only preserve the candidate as fail-closed proposal-only source-extension data
pending protected authority.
\end{proof}

\section{Selector-Tie Countermodel}

\begin{countermodel}[Response-token tie]
Let a source package \(E\) admit two source-internal orientation tokens
\(t_{\Sigma}^{(1)}\) and \(t_{\Sigma}^{(2)}\) satisfying the same available
source constraints, and suppose no adopted source selector distinguishes them.
Likewise let two scale tokens \(t_{\Lambda}^{(1)}\) and
\(t_{\Lambda}^{(2)}\) satisfy the same available normalization constraints.
Then the proposal-only candidate cannot choose a unique non-bottom
\(\MetricData(E)\) component without importing an additional selector.
\end{countermodel}

\begin{proof}
If the candidate chooses one tied token by file order, role identity,
validation status, handoff order, approval status, target metric signature, or
proper-time calibration, it violates the claim boundary. If it chooses neither,
MRT2 or MRT3 is not discharged. Therefore the only lawful outcome under the
written candidate is \(\BottomSrc\) or a named nonuniqueness or
underdetermination branch. This is a local stress case for the candidate; it
does not prove that no future source-side selector can exist.
\end{proof}
