# Director Decision Record DDR-20260618-001

## Decision

Route `RT-20260618-001` to one bounded task-overlay
`memory-system-maintainer@0.1.0` AgentJob,
`AJ-RT-20260618-001-001`.

The user requested implementation of the complete folder README coverage plan
as a Documentation Curator-style documentation task. Current classifier and
resolver evidence show that the implementation also changes memory bootstrap
registration behavior. The selected execution role is therefore
Memory-System Maintainer with narrow task-overlay constraints: add the planned
explanatory folder READMEs, register only those explicit README paths, test the
new discovery behavior, and regenerate derived memory/wiki surfaces.

## Basis

The live repository had only three tracked README files outside generated
surfaces: root `README.md`, `research_control/README.md`, and
`research_control/approvals/README.md`. High-density source-side folders lacked
local orientation files for roles, schemas, skills, registries, Markdown
sources, ontology boundaries, research-control subfolders, scripts, tests,
assets, and shared TeX fragments.

The folder README plan is regular documentation. It is not a GitHub-facing
Markdown rebuild, an HTML explainer task, a generated wiki hand edit, a
physics-source edit, or a control-contract rewrite.

## Claim Boundary

Allowed:

- add explanatory folder READMEs for the planned Tier 1 and Tier 2 targets;
- mark those README files as explanatory;
- update bootstrap Markdown discovery with an explicit folder README allowlist;
- classify the folder READMEs as `folder_readme_documentation` with
  `explanatory_noncanonical` authority;
- add focused test coverage for folder README discovery metadata;
- refresh registries and generated wiki/memory outputs through bootstrap; and
- record documentation impact and validation receipts.

Forbidden:

- canonical ontology TeX edit;
- benchmark promotion;
- Gate Chair verdict;
- science draft edit;
- role contract, schema contract, skill contract, validator requirement,
  routing behavior, permission, stop-condition, or checkpoint-gate change;
- `github-facing/` documentation rebuild;
- tracked HTML edit;
- generated wiki hand edit;
- treating folder READMEs as scientific authority; and
- physics claim promotion.
