\begin{lemma}[Middle-site source automorphism]
The map \(\sigma:S_{\diamond}\to S_{\diamond}\) defined by
\[
\sigma(a)=a,\qquad \sigma(d)=d,\qquad \sigma(b)=c,\qquad \sigma(c)=b
\]
is a source automorphism of \(\Diamond\).
\end{lemma}

\begin{proof}
The primitive edge set is preserved. The edge \(a\to b\) maps to \(a\to c\),
the edge \(a\to c\) maps to \(a\to b\), the edge \(b\to d\) maps to \(c\to d\),
and the edge \(c\to d\) maps to \(b\to d\). Therefore the primitive edge
relation and its strict transitive closure are preserved. The map is bijective
and uses only source-site relabeling, so it is a source automorphism.
\end{proof}
