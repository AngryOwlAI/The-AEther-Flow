# Director Decision Record: DDR-20260614-274

## Decision

Select `validator-engineer@0.2.0` for one bounded P5-T05
non-authoritative checker integration packet.

## Basis

`handoff-0306` requires one P5-T05 packet to decide and, if appropriate,
implement non-authoritative validator or metrics integration for support-only
checker output. The v11 plan permits a metrics count for checker reports if it
remains operational. The existing `report_physics_progress_metrics.py` already
separates operational validation metrics from scientific progress metrics and
maintains a metric-separation guard.

The selected role is project-system validation/tooling. This packet has no
physics milestone and cannot promote checker output to proof authority.

## Scope

Allowed:

- Add deterministic operational metrics for support-only checker reports.
- Treat malformed checker report JSON as tooling metric data, not physics
  failure.
- Add focused tests proving checker report metrics stay out of
  `scientific_progress_metrics`.
- Update control registries, task records, documentation-impact receipt,
  `program_state.yaml`, and `handoff-0307`.

Blocked:

- canonical ontology edit
- source-law adoption
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- matter action
- detector semantics
- Einstein equations
- benchmark promotion
- completed derivation
- checker proof authority
- Gate Chair verdict or protected evidence-status change
- treating checker pass or checker failure as a physics theorem

## Role-Fit Matrix

| Candidate role | Decision | Reason |
| --- | --- | --- |
| Validator Engineer | Selected | P5-T05 is deterministic validation/metrics tooling integration. |
| Project-Control Maintainer | Not selected | The existing metrics script and tests are the direct implementation surface. |
| Documentation Curator | Not selected | No public explanatory surface or canonical source documentation changed. |
| Gate Chair | Not selected | The packet cannot decide evidence status or adoption. |
| Physics roles | Not selected | The packet has no physics milestone and no scientific payload. |

## Result

The selected packet integrates support-only checker report counts into
operational validation metrics only, adds regression tests, and routes the next
legal continue-research step to P6-T01 payload-density metrics design.
