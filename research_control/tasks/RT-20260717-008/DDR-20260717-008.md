`tests/test_research_control_metrics.py`, but P8-T01 established that file as a
discovery shim and retained the ten test definitions in
`tests/test_research_control.py`. This decision therefore authorizes only those
metrics test definitions in the monolith. The shim, shard ownership, test IDs,
frozen inventory, small temporary-repository fixtures, and dashboard source
remain unchanged.

The production API must be an explicit immutable value, not a module-global
cache. It may serialize and materialize fresh report dictionaries from one
frozen snapshot, but it must not reuse a snapshot across changed repository
state. Completion-file read counts and snapshot build counts are operational
instrumentation only and must not alter the canonical report JSON or Markdown
bytes.

not become physics proof, scientific authority, an ordinary-research state
change, a validation bypass, or authorization for `P8-T05`.
