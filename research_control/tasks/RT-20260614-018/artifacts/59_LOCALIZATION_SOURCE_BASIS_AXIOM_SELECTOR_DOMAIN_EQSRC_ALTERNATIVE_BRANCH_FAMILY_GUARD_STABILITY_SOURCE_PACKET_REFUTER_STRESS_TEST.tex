\begin{abstract}
This draft/control artifact stress-tests the audited alternative
branch-family guard-stability source packet from tasks
\texttt{RT-20260614-016} and \texttt{RT-20260614-017}. The local
positive result survives only inside the declared finite source family
\(\ObjTri=\{T_{1},T_{2},T_{3}\}\), where comparison preserves source
branch labels \(L,R,Q\), branch-local annotation totals, proxy guards,
forbidden-channel guards, blocker records, influence coverage, boundary
anchors, and branch-preserving quotient descent. Global permutation of
source labels is harmless only under full source-ledger transport.
Alternative branch-family expansion, label weakening, annotation-mass
perturbation, guard deletion, blocker erasure, influence deletion,
quotient representative variation, boundary-anchor perturbation,
general relation-property extension, and downstream use remain blocked.
General \(\EqSrc\), \(\RetainH\), \(\GenH\), candidate reconstruction,
canonical ontology edit, benchmark promotion, Gate Chair review, and
completed-derivation language remain blocked.
\end{abstract}

\section{Scope}

This artifact is the role output for task \texttt{RT-20260614-018}. It

and refutation sequence.

\section{Stress Method}

\begin{stressscreen}[Ten pressure channels]
The Refuter applies ten channels:
\begin{enumerate}
    \item alternative branch-family variation, including four-branch
    arity, branch deletion, cross-branch merge nodes, and nondeclared
    source shapes;
    \item branch-label permutation and weakening, including full
    source-ledger permutations, partial relabeling, label collapse, and
    target-semantic relabeling;
    \item annotation-mass perturbation, where atoms are deleted,
    rescaled, merged across branches, or selected by downstream success;
    \item proxy-guard deletion or relaxation;
    \item forbidden-channel guard deletion or relaxation;
    \item blocker erasure, where negative records are quotiented into
    positive witness status;
    \item influence deletion, where branch coverage or contraction
    evidence is removed;
    \item quotient representative variation, where representatives are
    chosen by target or candidate behavior;
    \item boundary-anchor perturbation, where \(i,o\) move, split, or
    become observer-like endpoints; and
    \item relation-property and downstream-use pressure, where local
    \(\EqTri\) is treated as general \(\EqSrc\), \(\RetainH\),
    \(\GenH\), candidate-ready evidence, or promotion authority.
\end{enumerate}
\end{stressscreen}

\section{Local Retention Screen}

\begin{stressfinding}[The declared three-branch receipt survives]
Inside the declared positive family
\[
    \ObjTri=\{T_{1},T_{2},T_{3}\},
\]
each object admits the reviewed admissible branch-preserving contraction
to \(T_{1}\). The contraction fixes boundary anchors \(i,o\), sends each
internal carrier on branch \(X\in\{L,R,Q\}\) to the corresponding base
carrier of \(T_{1}\), preserves branch-local annotation totals
\(A_{L},A_{R},A_{Q}\), preserves mapped proxy guards and
forbidden-channel guards, preserves blocker records, and maps influence
chains to the corresponding base influence edges. Therefore the audited
local statement
\[
    \CmpTri(T_i,T_j;\InvTri)=\EqTri(T_i,T_j)
    \quad\text{for } i,j\in\{1,2,3\}
\]
is retained as declared-family draft/control evidence.
\end{stressfinding}

\begin{controlrule}[No family erasure]
The retained result is valid only while the object domain remains the
declared finite family \(T_{1},T_{2},T_{3}\) and the full invariant
ledger remains active. Removing that domain clause changes the
comparison rule and invalidates the local pass.
\end{controlrule}

\section{Branch-Family and Label Pressure}

\begin{stressfinding}[Full source-ledger permutation is harmless]
Let \(\sigma:\{L,R,Q\}\to\{L,R,Q\}\) be a global permutation. If every
object in \(\ObjTri\) is relabeled by \(\sigma\) while preserving the
same branch-local annotation masses, proxy guards, forbidden-channel
guards, blocker records, influence coverage, admissible contractions,
and boundary anchors, then the packet changes only by source-tag
renaming. No target metric, target proper time, target locality,
observer protocol, benchmark rank, or candidate-performance selector is
introduced. The local comparison therefore remains a
bookkeeping-equivalent draft/control receipt.
\end{stressfinding}

\begin{counterpressure}[Alternative family expansion is not admitted]
Consider a four-branch object with labels \(L,R,Q,S\), a branch-deleted
object using only \(L,R\), or a cross-branch merge object whose internal
branches meet at a carrier before \(o\). The current packet contains no
invariant ledger for added branch arity, branch deletion, merge-node
admissibility, cross-branch blocker propagation, or comparison against
\(T_{1}\). These objects are outside the declared family, and their use
returns \(\Block\).
\end{counterpressure}

\begin{counterpressure}[Partial relabeling or label weakening blocks]
If only one object is relabeled, if one branch is renamed without
transporting annotation, guards, blockers, influence, contractions, and
boundary anchors, or if \(L,R,Q\) are collapsed into fewer classes, the
operation no longer preserves the source ledger. If a label is chosen
because downstream behavior improves or is read as a target locality,
observer, benchmark-rank, or candidate-performance category, the stress
result is \(\Block\).
\end{counterpressure}

\section{Annotation, Guard, Blocker, and Influence Pressure}

\begin{counterpressure}[Annotation perturbation blocks broader use]
The local pass depends on exact conservation of \(A_{L},A_{R},A_{Q}\).
Deleting annotation atoms, merging masses across branches, rescaling
masses, or weighting them by target or candidate success breaks the
source-bookkeeping interpretation. Such perturbations return
\(\Block\) unless a later source-only ledger proves the changed
annotation rule independently of target behavior.
\end{counterpressure}

\begin{counterpressure}[Guard deletion reopens target-channel risk]
Mapped proxy guards and forbidden-channel guards are part of the
positive comparison. Deleting or relaxing either guard can hide an
unmapped proxy or admitted target channel inside an otherwise positive
comparison. Therefore proxy-guard deletion and forbidden-channel guard
deletion return \(\Block\).
\end{counterpressure}

\begin{counterpressure}[Blocker erasure blocks the quotient]
Blocker records are negative source evidence, not surplus decoration.
If quotient descent erases a blocker record or converts a blocker into a
positive witness, the comparison launders adverse evidence through the
quotient. The result is \(\Block\).
\end{counterpressure}

\begin{counterpressure}[Influence deletion blocks coverage]
The audited packet requires influence coverage to contract by branch to
the corresponding base influence edges. Deleting influence edges,
collapsing them across branch labels, or preserving only carrier order
without influence receipts leaves the local comparison underdetermined.
The result is \(\Block\) outside the declared full-ledger case.
\end{counterpressure}

\section{Quotient, Boundary, Relation, and Downstream Pressure}

\begin{counterpressure}[Representative variation is local only]
The permitted quotient is the branch-preserving contraction
\(p_{k}:T_{k}\to T_{1}\) after every invariant in \(\InvTri\) is
preserved. A quotient that merges branch labels, chooses
representatives because target behavior improves, erases blocker or
influence records, or admits a positive comparison from contraction
alone returns \(\Block\).
\end{counterpressure}

\begin{counterpressure}[Boundary perturbation blocks the pass]
The boundary anchors \(i,o\) are fixed source carriers in the audited
packet. Moving either anchor, splitting an endpoint, identifying an
endpoint with a target observer protocol, or choosing an endpoint
because a target comparison improves changes the source boundary
ledger. The current packet has no proof of boundary-anchor invariance
under those perturbations. These cases return \(\Block\).
\end{counterpressure}

\begin{counterpressure}[Relation properties are declared-family local]
Reflexivity, symmetry, and transitivity are documented only inside
\(\ObjTri\), where every positive object contracts to \(T_{1}\) while
preserving the same ledger. They are not proven for added branch
families, branch-deleted objects, label-collapsed objects,
annotation-perturbed objects, guard-deleted objects,
blocker-erased objects, influence-deleted objects, altered quotients, or
perturbed boundaries. General \(\EqSrc\) remains unproved.
\end{counterpressure}

\begin{counterpressure}[Downstream use fails the boundary test]
No step in the audited local packet supplies \(\RetainH\), \(\GenH\),
candidate reconstruction, benchmark promotion, or Gate Chair authority.
Treating local \(\EqTri\) as support for those downstream claims would
import an unproved extension. The Refuter result is therefore
\(\Block\) for downstream use until a separate source-family packet
proves the required bridge and passes smuggling audit and stress
testing.
\end{counterpressure}

\section{Verdicts}

\begin{verdict}[Local three-branch retention]
The audited alternative branch-family packet survives this stress test
only as local declared-family evidence:
\[
    \EqTri\big|_{\{T_{1},T_{2},T_{3}\}} \Rightarrow \Pass
    \quad\text{draft/control only.}
\]
This means the positive three-branch family remains useful as a narrow
source-side witness family, not as a general \(\EqSrc\) theorem.
\end{verdict}

\begin{verdict}[Generalization block]
The same packet fails to support alternative branch-family expansion,
label weakening, annotation-mass perturbation, guard deletion, blocker
erasure, influence deletion, quotient representative variation,
boundary-anchor perturbation, broader relation-property extension, or
downstream use. Those attempted extensions return \(\Block\) under the
present authority record.
\end{verdict}

\begin{verdict}[No promotion]
This stress test does not discharge general \(\EqSrc\), \(\RetainH\),
or \(\GenH\). It does not prove semantic \(\NoTargetH\), does not
canonically adopt \(\NoTargetSyn\), does not authorize candidate
reconstruction, does not edit canonical ontology, does not promote
benchmark status, does not request Gate Chair review, and does not
permit completed-derivation language.
\end{verdict}
