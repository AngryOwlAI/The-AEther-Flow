# Director Decision Record: DDR-20260704-014

## Decision

Execute one bounded `documentation-curator@2.0.0` task overlay for v15 P18-T02.

The selected route creates a control Markdown manuscript outline for the AI
research-agent methodology paper. It may describe governance, routing,
validation, memory, and audit mechanisms. It must not claim autonomous
scientific authority, physics proof authority, Gate Chair authority, benchmark
authority, or completed derivation.

## Basis

`handoff-0559` routes next to P18-T02. The v15 plan requires an AI methodology
manuscript outline covering Director-led routing, role contracts, AgentJob
boundedness, claim gates, adversarial review, ledgers, memory, generated-output
boundaries, negative-result preservation, route-orbit detection, limitations,
and human accountability.

The repository has an empty `manuscripts/tex/` directory but no registered
active TeX manuscript source for this v15 lane. Consistent with the already
validated P18-T01 packet, the P18-T02 artifact is therefore a control Markdown
outline under the current task artifact directory.
