\section{Stress Lemmas}

\begin{lemma}[Nonempty and admissibility stress survival]
Under the declared source witnesses \(x_S^+\), \(\BErec\) has non-bottom
output exactly when source-token membership, source-state membership, source
admissibility, source transition non-bottomness, scoped source-extension
compatibility, and \(N_E^\sharp\) all hold. If any condition is replaced by
target metric, detector, benchmark, stress-energy, matter-action, adoption, or
process-authority repair, the branch fails closed.
\end{lemma}

\begin{proof}
The definition of \(\BErec\) is conjunctive. The first branch requires only
the listed source-side conditions and returns a bridge-token record. Every
listed repair class is outside the declared source domain or explicitly
forbidden by the no-target-import certificate. Therefore admissible source
witness states produce non-bottom bridge tokens, while forbidden repairs fall
to \(\BottomSrc\) or a named \(\OBMCB\) label.
\end{proof}

\begin{lemma}[Transition and sector-uniformity stress survival]
\(\BErec\) survives transition-coherence and sector-uniformity stress only as
a finite/local source bridge-token map over declared source transports and the
two-sector family \(\{S_0,S_1\}\). It does not become universal matter-sector
coverage.
\end{lemma}

\begin{proof}
The transition component is \(\Trans_E^\sharp\), which acts on declared source
transport data. The source family is finite/local. No branch quantifies over
all matter sectors, all stress-energy tensors, all matter actions, all
detectors, or all target metric backgrounds. Thus coherent source transport
and the shared branch form survive only at finite/local source scope.
\end{proof}

\begin{lemma}[Perturbation and boundary stress survival]
Finite/local perturbations that preserve the declared source predicates
preserve the pass or bottom classification of \(\BErec\). Perturbations that
require target metric repair, detector repair, benchmark repair, source-law
adoption, coupling-law adoption, matter-coupling adoption, or process
authority fail closed.
\end{lemma}

\begin{proof}
The bridge relation is defined by explicit source predicates and an explicit
bottom branch. Perturbing within those source predicates preserves branch
classification. Perturbing outside those predicates negates at least one
non-bottom condition or violates the no-target-import certificate. The bottom
branch is therefore selected.
\end{proof}
