# Director Decision Record: DDR-20260629-037

## Decision

Select `project-control-maintainer@0.2.0` for one bounded v12 P2-T01
frontier theorem inventory schema design packet.

## Basis

`research_control/program_state.yaml` names `RT-20260629-036` and
`handoff-0331`. The latest handoff routes exactly one P2-T01 packet: design a
canonical frontier theorem inventory schema.

The P2-T01 implementation-plan text suggests `ontology-formalizer@0.2.0` if
theorem semantics are included, otherwise `project-control-maintainer@0.2.0`.
This packet defines field names, source-authority rules, item classes, and
validator-forward constraints. It does not assert new theorem statements,
formalize a new primitive, or alter any physics source. Therefore the selected
role is `project-control-maintainer@0.2.0` with bounded inspection of current
Gate Chair and Refuter artifacts.

## Scope

Allowed:

- Create `research_control/design/frontier_theorem_inventory_schema_v1.md`.
- Define required inventory fields, recommended item classes, source-authority
  types, overread-guard rules, representability checks, and validator-forward
  requirements.
- Register the schema as a Markdown control source and regenerate retrieval
  derivatives.
- Create the P2-T01 task packet, role overlay, AgentJob, completion receipt,
  documentation-impact receipt, claim-boundary row, and handoff.
- Update `program_state.yaml`, the current-frontier snapshot, generated memory
  metadata, generated dependency graph, and control registries as required by
  validation and checkpoint.

Blocked:

- populating the full frontier theorem inventory;
- editing `registries/DISTANCE_TO_GR_LEDGER.csv`;
- editing TeX physics sources;
- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
- unscoped `g_eff` adoption;
- `g_eff` scope expansion;
- coupling-law adoption;
- matter-coupling derivation or adoption;
- stress-energy semantics;
- stress-energy tensor;
- matter action;
- detector semantics;
- Einstein equations;
- exact-GR benchmark promotion;
- benchmark Gate Chair closure;
- completed derivation;
- treating the schema, implementation plan, handoff, generated wiki note,
  semantic extract, Obsidian note, local cache, validator output, graph,
  checker, or commit as scientific proof.

## Role-Fit Matrix

| Candidate role | Fit judgment | Reason |
| --- | --- | --- |
| `project-control-maintainer@0.2.0` | selected | The output is a schema and authority contract, not a new scientific formalization. |
| `ontology-formalizer@0.2.0` | not selected | The schema names theorem-like categories but does not state or prove theorem content. Selecting a physics role would imply a derivation milestone and mathematical payload that this packet does not create. |
| `validator-engineer@0.2.0` | acceptable but later | P2-T04 is the validator packet. P2-T01 only designs validator-forward requirements. |

## Result

The selected AgentJob produced the P2-T01 schema artifact. The schema
distinguishes theorem, definition, witness, obstruction, gate decision, source
extension evidence, accepted scoped objects, frozen negative routes, and
missing theorems. It can represent `Resp_lc`, `M_src`, `g_eff`,
matter-coupling precondition evidence, the finite toy frozen negative, and the
open Einstein-equation burden while preserving explicit non-conclusions.
