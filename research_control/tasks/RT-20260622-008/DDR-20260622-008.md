# DDR-20260622-008: Phase 6 Bridge Checkpoint Documentation Phase 0 Audit

## Decision

Route one bounded Documentation Curator AgentJob to implement Phase 0 of
`implementations_plans/phase6_bridge_checkpoint_documentation_update_plan.md`.

Phase 0 is an evidence-lock and page-impact audit. It does not authorize
README edits, publication brief edits, source-spec edits, GitHub-facing
Markdown edits, tracked HTML edits, validator changes, resolver changes,
checkpoint changes, sidecar creation, role-contract changes, schema changes,
or physics claim changes.

## Rationale

The requested plan is a documentation synchronization plan. The first phase
requires inspection, source-basis selection, and page-stack impact decisions,
not implementation of the later README and public-page rewrites.

The Documentation Curator is the correct role because the output selects
reader-facing documentation surfaces and preserves the publication-brief and
source-spec pipeline. The task overlay restricts the role to a task-local
audit artifact plus control receipts.
