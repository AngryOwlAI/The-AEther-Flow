# Director Decision Record: DDR-20260629-031

## Decision

Select `memory-system-maintainer@0.2.0` for one bounded v12 P0-T03
memory/bootstrap discoverability packet.

## Basis

`research_control/program_state.yaml` names `RT-20260629-030` and
`handoff-0325`. The latest handoff routes exactly one P0-T03 packet before P1
work: ensure the v12 implementation plan and P0-T02 baseline snapshot are
discoverable through source-first memory.

The pre-transaction targeted memory query for
`recommendations_implementation_plan_continue_task-v12` returned no canonical
plan source row. The required correction is registry and retrieval hygiene:
register source rows for the v12 implementation plan and the P0-T02 baseline
summary, then regenerate derived wiki, semantic, file-object, relationship, and
vault metadata through the standard bootstrap.

## Scope

Allowed:

- Add source-first Markdown registry rows for:
  - `MD-RECOMMENDATIONS-IMPLEMENTATION-PLAN-CONTINUE-TASK-V12`;
  - `MD-V12-P0-BASELINE-SUMMARY`.
- Generate retrieval derivatives using `bootstrap_memory_system.py`.
- Create the P0-T03 task packet, role overlay, AgentJob, completion receipt,
  documentation-impact receipt, claim-boundary row, and handoff.
- Update `program_state.yaml`, the current-frontier snapshot, generated memory
  metadata, generated dependency graph, and control registries as required by
  validation and checkpoint.

Blocked:

- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
- unscoped `g_eff` adoption;
- `g_eff` scope expansion;
- coupling-law adoption;
- matter-coupling derivation or adoption;
- stress-energy semantics;
- stress-energy tensor;
- matter action;
- detector semantics;
- Einstein equations;
- exact-GR benchmark promotion;
- benchmark Gate Chair closure;
- completed derivation;
- treating implementation-plan source rows, baseline summaries, memory layers,
  generated wiki notes, semantic extracts, Obsidian notes, file-object rows,
  relationship rows, `.local` caches, validator output, checker output, or
  commit status as scientific proof.
