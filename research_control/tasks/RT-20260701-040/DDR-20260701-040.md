# DDR-20260701-040: P3 Claim-Language Remediation

## Decision

Route one bounded `documentation-curator@2.0.0` AgentJob for v14 `P3-T04`
claim-language remediation.

## Rationale

The active handoff requires remediation of the recorded current/public
claim-language hard-fail backlog before public status propagation or downstream
physics routes. The default linter scan is the diagnostic source for this
packet. The remediation must distinguish current public/current-control wording
from historical implementation-plan provenance, because the v14 plan forbids
rewriting historical artifacts merely to satisfy the linter.

## Scope

Allowed:

- Rewrite current public and current-control Markdown wording to use scoped,
  non-promotional claim language.
- Update canonical Markdown sources rather than generated derivatives.
- Record reviewed-context entries only for explicitly listed historical
  implementation-plan backlog that is retained as provenance and not current
  status.
- Produce a remediation receipt and documentation-impact receipt.
- Route only to P3-T05 after validation.

Forbidden:

- Source-law adoption.
- Ontology edit.
- RR_ETransportCompletenessOrInvarianceLaw_v1 adoption.
- PositiveMSProfile_v1 adoption.
- SourceMatterSemanticsAdoptionReadinessLaw_v1 law adoption.
- MetricData(E) adoption or g_eff expansion.
- Matter-coupling, Einstein-equation, benchmark, or completed-derivation
  promotion.
- Public status propagation.
