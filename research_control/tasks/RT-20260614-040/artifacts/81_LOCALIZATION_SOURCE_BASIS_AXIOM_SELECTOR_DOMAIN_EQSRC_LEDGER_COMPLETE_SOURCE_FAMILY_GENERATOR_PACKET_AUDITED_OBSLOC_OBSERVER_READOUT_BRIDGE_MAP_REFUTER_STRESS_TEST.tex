quotient transport, relaxed boundary transport, nonmatching

\begin{stressfinding}[Exact source map survives the pressure]

means the map survives only as an exact-branch source observer/readout
candidate. The stress test therefore retains the map with the exact
branch and source-only qualifiers intact.
\end{stressfinding}

\begin{counterpressure}[Observer language does not import a physical observer]
The token \([n]_{U_X}\) is a source normal-orbit token from the

empirical frame, not a clock-synchronization protocol, and not a local
inertial observer. Treating it as any of those objects would be a
\(\Block\).
\end{counterpressure}

\begin{counterpressure}[Readout syntax is not metric or empirical readout]
The readout is
\[
    \Phi_{U_X}=\ReadLC(X_{\mathrm{loc}})|_{U_X}.

therefore survives as source syntax only. It does not prove readout
minimality, empirical observability, quotient-readout robustness, or
matter-coupling relevance.
\end{counterpressure}

\begin{counterpressure}[Metric-response law remains absent]

\begin{stressfinding}[Missing primitive is sharper rather than fatal]
