# Director Decision Record: DDR-20260614-279

## Decision

Select `project-control-maintainer@0.2.0` for one bounded P7-T01 schema-design
packet.

## Basis

`handoff-0311` requires one P7-T01 project-system memory or registry design
packet to define a dependency graph schema for research objects, claim
boundaries, and task relationships. The P7-T01 plan requires node classes, edge
classes, state labels, output formats, a graph schema artifact, and a handoff to
P7-T02. It also requires the graph to remain navigational support rather than
physics authority.

The selected role is appropriate because the packet creates a project-control
design contract. It does not implement the extractor, change physics claims, or
alter canonical science sources.

## Scope

Allowed:

- Create `research_control/design/research_dependency_graph_schema.md`.
- Define graph node classes, edge classes, state labels, JSON shape, Markdown
  summary expectations, DOT expectations, source-to-graph mapping, and
  validation expectations.
- Register and regenerate the Markdown source through the project memory
  bootstrap.
- Update control registries, task records, documentation-impact receipt,
  `program_state.yaml`, and `handoff-0312`.

Blocked:

- dependency graph extractor implementation
- generated graph artifact creation
- canonical ontology edit
- source-law adoption
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- matter action
- detector semantics
- Einstein equations
- benchmark promotion
- completed derivation
- treating graph data as physics or control authority
- Distance-to-GR ledger change
- Gate Chair verdict or protected evidence-status change

## Role-Fit Matrix

| Candidate role | Decision | Reason |
| --- | --- | --- |
| Project-Control Maintainer | Selected | P7-T01 is a control design contract defining schema and boundaries. |
| Memory-System Maintainer | Not selected | Better fit for P7-T02 extractor implementation and generated memory surfaces. |
| Validator Engineer | Not selected | No validator hardening is required in this schema-only packet. |
| Documentation Curator | Not selected | The artifact is project-control design, not public explanatory documentation. |
| Physics roles | Not selected | The packet has no physics milestone and no scientific payload. |

## Result

The selected packet defines the dependency graph schema as a registered
project-control design note and routes the next bounded packet to P7-T02
extractor implementation.
