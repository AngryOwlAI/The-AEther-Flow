\section{Conditional Source-Purity Lemma}

\begin{lemma}[GenCover packet-interface source-purity]
Assume the \(\GenCover\) source-domain declarations and \(\BottomSrc\) rules
from \texttt{RT-20260614-110} are enforced. Then any non-bottom output
returned by \(\CoverExt\) does not use target topology, target atlas, target
coordinate transition, target metric, proper time, empirical detector
semantics, benchmark success, validation status, registry metadata, role
identity, handoff authority, generated derivatives, file order, finite-replay
overread, or adoption authority as a source premise.
\end{lemma}

\begin{proof}
The non-bottom path for \(\GenCover\) first requires \(\AdmExt\) to be true.
That predicate requires source anchoring, source-local separation, source chart
support, source transition-token candidates, source inverse and cocycle
certificates, source soldering certificates, admissible source-variation
records, and explicit exclusion of forbidden premises. The non-bottom
certificate repeats those components as source-only certificate families.
The formalization excludes target and process-authority data from
\(\mathcal{S}_{\mathrm{src}}\). If such a premise is required, \(\BottomSrc\)
returns \(\Bot\). Therefore a non-bottom \(\CoverExt\) output cannot depend on
the forbidden premises under the packet interface. The argument is conditional
on the interface being enforced and does not prove that non-bottom
certificates exist for arbitrary source-cover extension records.
\end{proof}
