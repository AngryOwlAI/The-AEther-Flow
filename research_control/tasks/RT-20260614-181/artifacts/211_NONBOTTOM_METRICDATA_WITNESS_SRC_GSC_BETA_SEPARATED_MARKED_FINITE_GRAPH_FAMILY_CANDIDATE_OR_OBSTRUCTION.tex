\section{Admitted Transition Tokens}

An admitted transition token
\[
  \tau:G^\beta\to H^{\beta'}

is a source graph isomorphism preserving the directed source-edge relation and
strict reachability while transporting the marking coherently:
\[
  \tau_\ast(\beta(v))=\beta'(\tau(v)).
\]
This is not target atlas covariance and not metric covariance. It is source
graph structure plus explicit marked source transport.

\begin{lemma}[Marked finite graph profile covariance]
If \(\tau:G^\beta\to H^{\beta'}\) is admitted, then
\[
  q_{\beta'}(\tau(v))=\tau_\ast(q_\beta(v)).
\]
\end{lemma}

\begin{proof}
The graph isomorphism preserves directed edges and therefore preserves strict
reachability counts. Coherent \(\beta\)-transport preserves the third profile
component by definition. Thus the marked profile is covariant under admitted
source graph transitions.
\end{proof}
