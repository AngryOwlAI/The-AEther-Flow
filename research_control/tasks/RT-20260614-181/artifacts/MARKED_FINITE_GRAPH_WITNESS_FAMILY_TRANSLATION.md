# Marked Finite Graph Witness-Family Translation

This support artifact translates the `RT-20260614-181` beta-separated marked
finite graph candidate into finite directed graph language. It is not proof
authority. The TeX artifact controls mathematical claims.

| Source-side term | Graph-theoretic translation | Claim limit |
| --- | --- | --- |
| source package `E` | finite directed acyclic graph plus explicit marked source structure `beta` | not target topology |
| response token | directed source edge or generated reachability relation | not physical propagation by itself |
| reachability preorder `R_C` | strict transitive closure of graph edges | not target causal cone |
| transition token `K_tau` | graph isomorphism plus coherent beta transport | not atlas covariance |
| distinguishability `D_N` | marked profile `(incoming reachability count, outgoing reachability count, beta label)` | not Lorentzian nondegeneracy |
| finite variation `V_ML` | bounded graph edit with preserve, source-repair, or bottom behavior | not variational dynamics |
| bottom table `B_src` | named failure map for absent, ambiguous, external, non-injective, non-coherent, cyclic, or promoted readings | not metric construction |

For the declared beta-separated family, a graph has finite vertex set `V`,
directed acyclic edge set `A`, and an explicit source-side injective marking
`beta: V -> Lambda`. The marked profile of a vertex `v` is:

```text
q_beta(v) = (incoming_reach_count(v), outgoing_reach_count(v), beta(v))
```

The beta label is source-side domain data. It is not reconstructed from target
geometry, empirical detectors, benchmark success, process authority, registry
state, or checker output.

The `D_m^beta` marked reconvergent family embeds by assigning the root,
terminal, and middle branches explicit beta labels. The rooted tail-branch
family embeds the same way. A plain unmarked diamond still collapses under
unmarked reachability profiles; it passes only when explicit injective beta is
part of the source presentation.

The checker report is support only. It is not proof of an arbitrary finite-DAG
theorem, not `MetricData(E)` adoption, not `g_eff` construction, not benchmark
evidence, and not validator evidence for physics truth.
