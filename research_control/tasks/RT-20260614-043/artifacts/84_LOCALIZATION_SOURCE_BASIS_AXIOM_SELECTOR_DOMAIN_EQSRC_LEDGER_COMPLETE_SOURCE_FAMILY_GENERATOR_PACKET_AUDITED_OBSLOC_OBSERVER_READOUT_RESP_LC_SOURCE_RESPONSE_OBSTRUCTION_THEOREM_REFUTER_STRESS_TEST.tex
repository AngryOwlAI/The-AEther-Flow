\section{Counterpressure Results}

\begin{counterpressure}[The finite set does not select sign or scale]
The set \(U_X=\{a_0,a_1,a_2\}\) supplies source labels. It does not
carry an ordered causal relation, oriented edge relation, bilinear
pairing, timelike/spacelike split, dimensionful unit, or normalization
rule. A sign or scale chosen from label order would not be invariant
under source relabeling and would therefore be an external convention,
not a source determination.
\end{counterpressure}

\begin{stressfinding}[No selector is found in \(U_X\)]
The finite source neighborhood can index candidate pairs, but it
cannot choose \(\sigma_{ij}\) or \(w_{ij}\). The sign and scale
symmetry pressures survive this component.
\end{stressfinding}

\begin{counterpressure}[The normal-orbit token is not a signed normal]
The datum \([n]_{U_X}\) is an orbit token. The bracketed notation is
material: it records equivalence-class or orbit status rather than a
chosen representative. An orbit token can preserve a normal family
without selecting the orientation of a response sign. Reading it as a
signed timelike vector, local inertial observer, clock direction, or
physical frame would import target observer structure.
\end{counterpressure}

\begin{stressfinding}[No sign escape is found in \([n]_{U_X}\)]
Because the retained datum is the orbit class rather than a preferred
representative, it does not defeat the replacement
\[
    \sigma_{ij}\mapsto -\sigma_{ij}.
\]
The sign obstruction therefore remains scoped and active.
\end{stressfinding}

\begin{counterpressure}[The readout is not a response calibration]
The readout
\[
    \Phi_{U_X}=\ReadLC(X_{\mathrm{loc}})|_{U_X}
\]
is source syntax retained through the exact branch. It is not a
detector output, a calibrated empirical observable, a target chart, a
proper-time reading, a stress-energy response, or a coupling channel.
Finite differences of \(\Phi_{U_X}\) can name a diagnostic burden, but
the inspected source packet does not supply a rule mapping those
differences to signed interval class, absolute or relative scale, or
matter-response token semantics.
\end{counterpressure}

\begin{stressfinding}[No response-token semantics are found in \(\Phi_{U_X}\)]
The response-token relabeling
\[
    \rho_{ij}\mapsto \tau(\rho_{ij})
\]
remains invisible to the retained source data. A token meaning would
need a source response semantics or coupling theorem not present in
the tracked packet.
\end{stressfinding}

\begin{counterpressure}[Exact transports preserve certificates but do not normalize response]
The transports \(T^n\) and \(T^\Phi\) preserve exact-branch
certificate data. They do not provide a dimensionful scale, response
normalization, covariance law for a metric response, matter hook, or
transport-invariant selection among \(w_{ij}\) and \(\lambda w_{ij}\)
for \(\lambda>0\).
\end{counterpressure}

\begin{stressfinding}[No scale escape is found in \(T^n,T^\Phi\)]
Positive rescaling of \(w_{ij}\) remains undetected by the retained
source tuple. If scale is intended to be gauge, a source-side
irrelevance theorem must state the quotient and show which later
metric-response burdens survive it. No such theorem is tracked here.
\end{stressfinding}

\begin{counterpressure}[Gauge language is not yet an irrelevance theorem]
One might try to defuse sign or scale by declaring them conventional
or gauge. That move is not available as a completed result in the
current packet. A source-side irrelevance theorem would need explicit
hypotheses, quotient objects, preserved observables, and a proof that
the quotient still supports the intended response-law burden without
target metric or benchmark import.
\end{counterpressure}

\begin{stressfinding}[The irrelevance route remains open but unsupplied]
The theorem is not a global no-go for every possible future
\(\RespLC\). It is a scoped obstruction for the current exact tuple.
The admissible escape routes are still a source selector primitive or
a source-side irrelevance theorem. Neither is present in the tracked
state inspected by this job.
\end{stressfinding}
