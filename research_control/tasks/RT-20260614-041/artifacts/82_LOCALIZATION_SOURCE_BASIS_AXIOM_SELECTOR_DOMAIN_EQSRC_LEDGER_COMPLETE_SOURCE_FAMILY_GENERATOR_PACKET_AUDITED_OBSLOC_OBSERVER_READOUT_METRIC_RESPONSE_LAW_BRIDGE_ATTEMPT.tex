\begin{abstract}
This draft/control Candidate Constructor artifact executes the
successor required by \texttt{handoff-0082}. It attempts one bounded
source-to-metric interpretation or response law \(\Msrc\) from the
Refuter-retained exact source observer/readout tuple

Gate Chair review, candidate reconstruction, completed derivation, or
global theory rejection is supplied.
\end{abstract}

where \(U_X=\{a_0,a_1,a_2\}\), \([n]_{U_X}\) is the exact source
normal-orbit token,
\(\Phi_{U_X}=\ReadLC(X_{\mathrm{loc}})|_{U_X}\), and \(T^n,T^\Phi\)
are exact certificate transports for
\(\mathcal{C}^{=}_{\mathrm{loc}}\). The prior Refuter result retains
this tuple only under the exact source branch and only as
bridge-facing draft/control data.

The target of this job is not a promoted metric. The target is the
bounded question:
\[

    response law } \Msrc:S_X\mapsto \text{metric-response data?}

\section{Admissibility Contract for \texorpdfstring{\(\Msrc\)}{Msrc}}

\begin{criterion}[Source-only metric-response law]
A source-only \(\Msrc\) candidate must satisfy all of the following:
\begin{enumerate}
    \item it uses only \(S_X\), \(\Bobs\), \(\ReadLC\), \(\ObsLocLC\),
    and exact source-control data from the inspected branch;
    \item it does not import target metric signature, target proper
    time, target locality, target observer protocol, benchmark rank,
    validation status, role authority, or candidate reconstruction;
    \item it supplies an intrinsic signed interval or pairing rule;
    \item it supplies a scale or normalization rule not chosen by a
    target fit;
    \item it is covariant under the available source transports
    \(T^n,T^\Phi\);
    \item it states how the source response would remain meaningful
    beyond the exact branch; and
    \item it identifies matter-response hooks before any matter
    coupling or Einstein-equation claim is in scope.
\end{enumerate}
\end{criterion}

\begin{finding}[The schema names the missing operation]
The trial schema is useful only as a diagnostic. It shows that the
needed operation is not the already-audited observer/readout map

that turns source readout differences and source normal-orbit
transport into interval sign, relative scale, and
transport-covariant pairing data.
\end{finding}

\section{Obstructions}

\begin{obstruction}[No intrinsic signed pairing in the retained tuple]
The tuple \(S_X\) contains a finite source neighborhood, a source
normal-orbit token, a restricted readout, and exact transports. It
does not contain an arity-two signed interval relation, a bilinear
pairing, a causal-cone selector, a signature rule, or a rule that
distinguishes timelike from spacelike response. Choosing any of these
objects requires extra structure beyond the retained tuple.
\end{obstruction}

\begin{obstruction}[No scale or normalization selector]
Even if an external metric form were proposed, \(S_X\) supplies no
source-internal normalization that distinguishes a scale from a
rescaled one. A scale selected by benchmark fit, target proper time,
candidate reconstruction, or empirical observer protocol would be a
hidden target import and is therefore blocked.
\end{obstruction}

\begin{obstruction}[No response or coupling hook]
The retained readout \(\Phi_{U_X}\) is source syntax. It is not a
matter field, stress-energy response, detector output, empirical
observable, or universal coupling rule. A bridge to matter coupling
therefore requires another source-side response primitive before
Einstein-equation recovery can be formulated.
\end{obstruction}

\section{Minimal Missing Primitive}

\begin{finding}[Required primitive]
The minimal missing primitive can be named as a source-internal
response rule
\[
    \RespLC:
    (a_i,a_j,\Phi_{U_X},[n]_{U_X},T^n,T^\Phi)
    \longmapsto
    (\sigma_{ij},w_{ij},\rho_{ij}),
\]
where \(\sigma_{ij}\) is an intrinsic signed interval class,
\(w_{ij}\) is a source scale or weight, and \(\rho_{ij}\) is a
response/coupling token. This is not introduced here as canonical
ontology. It is the smallest named draft/control missing primitive
that would need a later concrete witness, theorem, or obstruction.
\end{finding}

\begin{controlrule}[No adoption by naming]
Naming \(\RespLC\) does not adopt it. The present artifact supplies no
canonical ontology edit, no benchmark claim, and no accepted metric
law. It only records that an admissible \(\Msrc\) would require this
kind of signed response primitive or an equivalent source-side theorem
that eliminates the need for it.
\end{controlrule}
