\section{Audit Target}

The target model has two cells \(C_{\mathrm{toy}}=\{U_0,U_1\}\), toy

\[

  \in \{+1,-1\}\times\{1,2\}\times T_{\mathrm{toy}}^{C_{\mathrm{toy}}},

The audit asks whether this construction hides any target-GR import,
arbitrary convention, target calibration, token-semantics overread, or
ontology-overread.

\section{Audit Screens}

\paragraph{Target metric import.}
No Lorentzian metric, manifold, geodesic structure, causal cone,
proper-time law, or target Einstein-equation behavior is used to define
\(R_{\mathrm{toy}}\), \(D_X\), or \(A_X\). The quantities \(D_X\) and
\(A_X\) are finite response analogues on two cells only. They must not
be read as \(\texttt{g\_eff}\).

\paragraph{Arbitrary convention leakage.}
The model does not choose a sign, scale, or token semantics from an
external convention. It returns those values only when the toy source
object explicitly contains \(\varepsilon\), \(\lambda\), and \(\tau\).
This is a source-purity pass only for the finite toy construction. It
also means the missing \(\texttt{Resp\_lc}\) primitive has not been
derived; it has been represented as explicit toy data.

\paragraph{Calibration import.}
The normalization value \(\lambda\in\{1,2\}\) is a finite toy tag. It
does not import target units, proper time, physical ruler calibration,
or observational scale.

\paragraph{Token-semantics overread.}
The token map \(\tau\) is an uninterpreted source-side toy label map.
Token renaming changes names only. It supplies no matter-coupling law
and no empirical readout semantics.

\paragraph{Authority import.}
Validation status, registry rows, role names, and handoff labels are
process-control facts. They do not become physics evidence for
\(\texttt{Resp\_lc}\), \(\texttt{M\_src}\), \(\texttt{g\_eff}\), matter
coupling, Einstein equations, benchmark status, or Gate Chair review.

\section{Tagged-Readout Non-Import Lemma}

\begin{proposition}[Conditional no-target-import screen]
Assume a finite toy object \(X\) contains explicit source-side toy tags
\((\varepsilon,\lambda,\tau)\), and assume
\(R_{\mathrm{toy}}(X)=(\varepsilon,\lambda,\tau)\) while \(D_X\) and
\(A_X\) are defined only as finite functions of \(\lambda\) and
\(\varepsilon\lambda\). Under those assumptions, the finite construction
does not import a target Lorentzian metric, target proper-time scale, or
matter-coupling law by definition.
\end{proposition}

\begin{proof}
The dependency list of \(R_{\mathrm{toy}}\) is exactly the explicit
tag triple \((\varepsilon,\lambda,\tau)\). The dependency list of
\(D_X\) is \(\lambda\), and the dependency list of \(A_X\) is
\((\varepsilon,\lambda)\). None of these definitions refers to a target
metric tensor, continuum manifold, action principle, stress-energy
tensor, empirical observer protocol, benchmark solution, or validation
authority. Therefore the construction passes the stated no-target-import
screen as a finite toy readout. The proof is conditional: it does not
derive the tags, adopt them as canonical ontology, or show that the
current untagged retained tuple supplies them.
\end{proof}

\begin{proposition}[Untagged obstruction preservation]
The audit leaves the current untagged \(\texttt{Resp\_lc}\) burden
blocked.
\end{proposition}

\begin{proof}
The model explicitly defines \(R_{\mathrm{toy}}\) only on tagged toy
objects. For \(X_{\emptyset}\), no orientation, normalization, or token
map is present, and the relation is undefined. Hence the model supplies
no rule that extracts response sign, scale, or token semantics from the
current untagged retained tuple. The missing primitive is preserved
rather than hidden.
\end{proof}
