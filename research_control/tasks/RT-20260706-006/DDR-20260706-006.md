# DDR-20260706-006

## Analysis

Tracked state at `handoff-0637` routes exactly one bounded v17 P5-T01
metric-use ledger schema packet. The v17 plan requires
`research_control/design/metric_use_ledger_schema_v1.md` and
`registries/METRIC_USE_LEDGER.csv`, with the required CSV header and explicit
allowed and forbidden metric-use categories.

The plan names `schema-maintainer@0.1.0`, but the active role registry does
not register that role. The prior handoff already resolves the role-fit issue:
bind P5-T01 to an active project-control role overlay. The active
Project-Control Maintainer role can maintain project-control schemas and
registries under an owning AgentJob. It is therefore the least-risk registered
role for this packet.

## Decision

Create `RT-20260706-006` and bind exactly one AgentJob,
`AJ-RT-20260706-006-001`, to `project-control-maintainer@0.2.0` through a
one-job task overlay.

Required artifacts:

```text

registries/METRIC_USE_LEDGER.csv
research_control/tasks/RT-20260706-006/artifacts/metric_use_ledger_schema_receipt.md
```

is deferred to P5-T02.
