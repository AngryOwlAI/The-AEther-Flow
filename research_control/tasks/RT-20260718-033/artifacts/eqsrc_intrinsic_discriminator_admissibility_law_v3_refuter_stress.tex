\section{Stress Target and Surviving Formal Core}

For a supplied finite two-truncated chain complex over \(\Ftwo\),
\[
 E=\left(C_2(E)\xrightarrow{\partial_2^E}
 C_1(E)\xrightarrow{\partial_1^E}C_0(E)\right),
 \qquad \partial_1^E\partial_2^E=0,
\]
v3 defines
\[
 A_E=\ker\partial_1^E,\qquad
 B_E=\operatorname{im}\partial_2^E,\qquad
 K_E=A_E/B_E,
\]
and
\[
 x\,\EqCand_E\,y
 \quad\Longleftrightarrow\quad x-y\in B_E.
\]

The fresh audit already verified the typed factorization theorem in
\(\mathbf{Set}\), its linear specialization, and the criterion
\[
 \operatorname{RelRefl}(F_1|_{A_E})
 \quad\Longleftrightarrow\quad H_1(F)\text{ is injective}
\]
for a chain map \(F:E\to E'\). The present stress preserves those results.
It attacks only the stronger overread that exact v3 selects its own chain
package, differential, physical morphisms, or physical admissibility from
current ontology.

\section{Congruence Representation Without Selection}

\begin{theorem}[Finite linear-congruence representation]
Let \(A\) be a finite-dimensional \(\Ftwo\)-vector space and \(B\leq A\) a
subspace. Define a two-truncated chain package by
\[
 C_2=B,\qquad C_1=A,\qquad C_0=0,\qquad
 \partial_2:B\hookrightarrow A,\qquad\partial_1=0.
\]
Then the v3 candidate relation is exactly the linear congruence
\[
 x\sim_B y\quad\Longleftrightarrow\quad x-y\in B.
\]
\end{theorem}

\begin{proof}
The chain condition is automatic because \(\partial_1=0\).
Consequently \(A_E=A\) and \(B_E=\operatorname{im}\partial_2=B\), so the
displayed candidate definition is precisely congruence modulo \(B\).
\end{proof}

Thus v3 can represent every finite \(\Ftwo\)-linear congruence once \(B\) is
supplied. The theorem does not select \(B\), a differential realizing it, or
one congruence as physical source equivalence.

\section{Fixed-Carrier Four-Differential Countermodel}

Let
\[
 C_2=\Ftwo\langle f\rangle,\qquad
 C_1=\Ftwo\langle a,b\rangle,\qquad C_0=0,\qquad \partial_1=0.
\]
There are four possible images
\[
 \partial_2 f\in\{0,a,b,a+b\}.
\]
Each choice is a valid chain package on the same carrier spaces.

\begin{theorem}[Four distinct relations on fixed carriers]
The four differentials above induce four distinct candidate relations. For
\(\partial_2f=0\), the relation is equality and has four related ordered
pairs. For each nonzero image \(v\), the relation is congruence modulo
\(\langle v\rangle\), has two classes of size two, and has eight related
ordered pairs.
\end{theorem}

\begin{proof}
For the zero differential, \(B=0\). For a nonzero image \(v\),
\(B=\{0,v\}\), and the four states split into two cosets of \(B\). Distinct
one-dimensional subspaces of \(\Ftwo^2\) contain different nonzero vectors,
so they induce distinct pair relations.
\end{proof}

The symmetric difference between equality and any nonzero-differential
relation has four ordered pairs. The symmetric difference between two
distinct nonzero-differential relations has eight ordered pairs. Hence even a
rank-one change of the differential can change the candidate relation while
all carrier spaces and the chain condition remain fixed.

\section{Rank-One Chain-Map Witness}

Write \(E_0\) for the zero-differential package and \(E_a\) for the package
with \(\partial_2f=a\). Define
\[
 F_2=0,\qquad F_1=\operatorname{id}_{\Ftwo^2},\qquad F_0=0.
\]
This is a chain map \(E_0\to E_a\), since both sides of the degree-two chain
equation vanish. It preserves the source equality relation, but it does not
reflect the destination relation: \(0\) and \(a\) are unrelated in \(E_0\)
and related in \(E_a\). Consistently,
\[
 H_1(F):\Ftwo^2\longrightarrow \Ftwo^2/\langle a\rangle
\]
is the quotient map and is not injective.

This witness confirms the audited chain-map criterion. Its negative content is
selection-level: the candidate permits both packages and supplies no
current-ontology rule choosing between their differentials or relations.

\section{Nontrivial Instantiability and Degenerate Models}

The package \(E_a\) has four states, two equivalence classes, two states per
class, and a two-element declared boundary-translation group. It is therefore
a nontrivial source-only finite instance. This passes the requested
instantiability stress.

Degenerate cases are also mathematically well defined. If \(B=0\), the
relation is equality. If \(B=A\), the relation is universal. These endpoints
do not select a physical equivalence, establish completeness, or invalidate
the intermediate nontrivial instances.

\section{Declared Robustness Is Orbit-Relative}

\begin{theorem}[Boundary-orbit identity]
For every supplied package \(E\), the equivalence class of \(x\in A_E\) under
\(\EqCand_E\) is exactly its orbit under translations by \(B_E\):
\[
 [x]_{\EqCand_E}
 =\{x+c:c\in B_E\}
 =\operatorname{Orb}_{\AdmVar(E)}(x).
\]
\end{theorem}

\begin{proof}
By definition, \(y\EqCand_E x\) if and only if \(y-x\in B_E\), which is
equivalent to \(y=x+c\) for some boundary \(c\in B_E\).
\end{proof}

Every declared boundary move therefore preserves the relation exactly. But
the same supplied differential determines both \(B_E\), hence the relation,
and the translation group used to certify robustness. The identity is a
construction-relative theorem. It is not an independent rule selecting
which differential or variations are physically admissible.

The fixed-carrier family exhibits the limitation explicitly:
\[
 \partial_2
 \longmapsto B_E
 \longmapsto
 \left(\EqCand_E,\AdmVar(E)\right).
\]
Changing \(\partial_2\) changes both the answer and the answer-preserving move
class in tandem.

\section{Categorical and Malformed-Map Boundaries}

The general factorization result is a theorem about typed functions in
\(\mathbf{Set}\). Linearity follows only under the separately declared linear
hypothesis, and the homology criterion follows for chain maps. These
categorical statements pass the stress at their exact scope.

A displayed mistyped map is not an element of the typed function space to
which those theorems apply. Therefore ``return \(\Bottom\) for a mistyped
map'' is a meta-level rejection rule unless the proposal supplies a tagged
error carrier and a total operation with that carrier as codomain. This is a
formalization and certificate gap in the fail-closed interface, not a
counterexample to the typed theorems.
