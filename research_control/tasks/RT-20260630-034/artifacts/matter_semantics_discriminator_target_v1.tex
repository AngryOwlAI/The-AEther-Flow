\section{Inputs and Domain}

\begin{definition}[Current source basis]
For a fixed source instance \(E\), let \(\Bcur(E)\) be the current
draft/control basis available to this packet:
\begin{enumerate}
  \item the P5-T02 source-side matter-semantics target and no-import
    certificates;
  \item the P5-T03 draft/control matter-semantics candidate construction;
  \item the P7-T03 red-team review and its
    \(\mathsf{not\_enough\_assumptions}\) verdict;
  \item the current Distance-to-GR matter-coupling burden statement.
\end{enumerate}
The basis explicitly excludes target stress-energy tensors, target matter
actions, empirical detector protocols, target metric/proper-time imports,
benchmark behavior, Einstein-equation premises, generated-output authority,
and Gate Chair authority as mathematical premises.
\end{definition}

\begin{definition}[Admissible candidate records]
\(\MSAdm(E;\Bcur)\) is the set of draft/control candidate records
\[
  C=(S_E,P_E,R_E,Q_E,\Gamma_E)
\]
such that \(C\) satisfies the P5-T02/P5-T03 source-side syntax requirements
and the certificate bundle \(\Gamma_E\) contains explicit witnesses for
\[
  \NoDetector(E),\quad \NoSE(E),\quad \NoAction(E),\quad \NoTarget(E).

Membership in \(\MSAdm(E;\Bcur)\) is only candidate admissibility.  It is not
a physical matter semantics, not a source law, not a coupling law, and not
matter coupling.
\end{definition}

\begin{definition}[Candidate source equivalence]
For \(C_1,C_2\in\MSAdm(E;\Bcur)\), write
\[
  C_1 \MSEq C_2
\]
when a later proof, using only source-side data in \(\Bcur(E)\) and no-target
certificates, establishes that the two records define the same source-side
matter-semantics bookkeeping up to source relabeling and finite/local
certificate-preserving variation.  In the absence of such a proof, equivalence
is not assumed.
\end{definition}

\section{Discriminator Target}

\begin{definition}[\(\MSDisc(E;\Bcur)\)]
A draft/control source-side matter-semantics discriminator target is a partial
selector
\[
  D_E:\MSAdm(E;\Bcur)\rightharpoonup \mathcal{L}_E \cup \{\bot\}
\]
or an equivalent ordering/choice rule satisfying the following obligations:
\begin{enumerate}
  \item \textbf{Source-only domain.} \(D_E\) is defined only from source-side
    records and certificates in \(\Bcur(E)\).
  \item \textbf{No-target imports.} \(D_E\) does not use target
    stress-energy, detector protocols, matter actions, target metric
    structure, proper-time normalization, benchmark behavior, or
    Einstein-equation premises.
  \item \textbf{Relabeling invariance.} Source relabeling of \(E\) transports
    candidate records without changing the discriminator result except by the
    corresponding source isomorphism.
  \item \textbf{Finite-variation stability.} Certificate-preserving
    finite/local variation may not change a selected non-bottom class unless
    the variation changes an explicit source-side certificate used by \(D_E\).
  \item \textbf{Nonuniqueness fails closed.} If two non-bottom admissible
    candidates cannot be proved source-equivalent, the result is \(\bot\) and
    the packet records \(\MSFail(E;\Bcur,O)\).
  \item \textbf{No process authority.} Registry rows, validation passes,
    handoffs, commits, generated wiki notes, local caches, and support-only
    formalization outputs are not proof authority for \(D_E\).
\end{enumerate}
\end{definition}

\begin{definition}[\(\MSUniq(E;\Bcur)\)]
The uniqueness obligation \(\MSUniq(E;\Bcur)\) is satisfied only if a later
packet proves the following statement by source-side means:
\[
  C_1,C_2\in\MSAdm(E;\Bcur),\quad
  D_E(C_1)\ne\bot,\quad D_E(C_2)\ne\bot
  \quad\Longrightarrow\quad C_1 \MSEq C_2
\]
or else records a precise nonuniqueness obstruction.  The implication is a
future proof obligation, not a theorem established in this packet.
\end{definition}

\section{Pressure Lemma and Repair Target}

\begin{lemma}[P7-T03 underdetermination pressure]
Under the assumptions inspected by P7-T03, scoped \(g_{\mathrm{eff}}\) and
parameterized finite/local witness evidence can coexist with at least two
admissible source-side continuations whose readout alphabets or response-token
semantics are not proved source-equivalent.  Therefore those assumptions do
not by themselves determine a coupling-law-relevant matter semantics.
\end{lemma}

\paragraph{Reason.}
P7-T03 found no hidden target import in the frontier inventory as written, but
also found no source-side discriminator or uniqueness theorem.  No-import
certificates prevent smuggling; they do not select among admissible source-side
interpretations.  Without \(D_E\) or \(\MSUniq(E;\Bcur)\), two admissible
candidate records may remain incomparable.  This is an underdetermination
statement about the current basis, not an impossibility theorem.

\begin{proposition}[Draft/control repair target]
The object \(\MSDisc(E;\Bcur)\) together with \(\MSUniq(E;\Bcur)\) is the
minimal repair target required before any future packet may use the P5
matter-semantics candidate as coupling-law-relevant evidence.
\end{proposition}

\paragraph{Boundary.}
The proposition states a target and burden.  It does not produce a
non-bottom discriminator, does not prove uniqueness, does not adopt a source
law, and does not authorize coupling-law or matter-coupling work.

\begin{proposition}[No-target-import preservation]
If a later packet supplies \(D_E\) and proves \(\MSUniq(E;\Bcur)\) using only
the source-side domain and certificates named above, then that later proof may
be evaluated as a source-side repair candidate.  Even then, the proof would
not by itself adopt a source law, adopt \(\MetricData(E)\), expand
\(g_{\mathrm{eff}}\), adopt a coupling law, derive matter coupling, import
stress-energy semantics, import detector semantics, import a matter action,
derive Einstein equations, promote a benchmark, or complete a GR derivation.
\end{proposition}

\paragraph{Reason.}
The discriminator target's domain explicitly excludes target physical
semantics and process-authority shortcuts.  Passing the target would at most
make a later source-side matter-semantics candidate less underdetermined.  It
would still need independent audit, stress, selector, and any protected human
authority required for adoption or downstream promotion.

\section{Failure Conditions}

A later construction attempt must return \(\MSFail(E;\Bcur,O)\) if any of the
following occurs:
\begin{enumerate}
  \item no source-only discriminator \(D_E\) can be defined from the current
    basis;
  \item \(D_E\) depends on target stress-energy, detector protocols, matter
    actions, target metric/proper-time normalization, benchmark behavior, or
    Einstein-equation premises;
  \item finite/local certificate-preserving variation changes a non-bottom
    result without an explicit certificate change;
  \item two admissible non-bottom candidates are not proved source-equivalent;
  \item the argument treats registry metadata, generated derivatives, support
    tooling, validation output, handoff status, role status, approval status,
    or commit status as scientific proof.
\end{enumerate}

When \(\MSFail(E;\Bcur,O)\) is returned, same-milestone continuation remains
open as \(\mathsf{blocked\_adoption\_open\_continuation}\) unless a separate
no-go theorem is proved and authorized.  The allowed wording is: current
ontology does not derive the source-side matter-semantics discriminator.  The
disallowed overread is: therefore such a discriminator is impossible.
