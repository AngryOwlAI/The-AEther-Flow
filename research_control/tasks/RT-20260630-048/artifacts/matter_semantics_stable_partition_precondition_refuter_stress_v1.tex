\section{Stress Results}

\begin{proposition}[Guarded finite-variation behavior]
For any finite source variation of an admissible record \(C\), the
precondition has exactly the following bounded behavior as written:
\begin{enumerate}
  \item if the variation preserves \(\MSSig(C)\) and the guard still holds,
    the record remains in the same cell of \(\MSPart\);
  \item if the variation changes \(\MSSig(C)\) and the guard still holds, the
    record moves to the corresponding different cell; and
  \item if the variation destroys core formation, admissibility, or a
    required no-target guard, the output is \(\MSFail\).
\end{enumerate}
\end{proposition}

\paragraph{Reason.}
\(\MSPart\) is defined by fibers of the source-side function \(\MSSig\).
Fiber membership is therefore stable exactly under preservation of
\(\MSSig\). Changing a signature coordinate changes the fiber, and guard
failure is defined as failure rather than a new semantic class.

\begin{proposition}[Certificate deletion is fail-closed]
Deleting a required no-target certificate class from the current guard bundle
does not create a new matter-semantics class. It forces the precondition
branch to \(\MSFail\).
\end{proposition}

\paragraph{Reason.}
RT-046 includes the current no-target certificate classes in the guard. The
stress branch that deletes a required certificate therefore violates the
guard. Treating the resulting state as a semantic class would contradict the
definition.

\begin{proposition}[Source-signature stability is explicit and local]
The source-signature coordinates \(\mathrm{Core}_E(C)\),
\(\mathrm{RR}_E(C)\), and \(\mathrm{AdmFlag}_E(C)\) are explicit. A variation
that changes any coordinate cannot silently preserve cell membership under
\(\MSStablePre\) as written.
\end{proposition}

\paragraph{Reason.}
The partition is by equality of the full repaired source signature. There is
no hidden quotient that erases one coordinate while retaining the same
precondition.

\begin{proposition}[Pressure-pair non-identification]
For a pressure pair \(C_+\), \(C_-\) with
\[
  \mathrm{RR}_E(C_+)\neq\mathrm{RR}_E(C_-),
\]
\(\MSStablePre\) keeps \(C_+\) and \(C_-\) in distinct cells whenever the
guard holds.
\end{proposition}

\paragraph{Reason.}
\(\mathrm{RR}_E\) is a coordinate of \(\MSSig\). Distinct
\(\mathrm{RR}_E\) values imply distinct signatures and therefore distinct
fibers. Identifying the pressure pair would require a different source-side
irrelevance theorem.

\begin{proposition}[\(\mathrm{RR}_E\) semantic overread fails closed]
Any attempted use of \(\mathrm{RR}_E\) as detector response, empirical
measurement, matter semantics, stress-energy semantics, matter-action data,
or coupling-law data violates the RT-046/RT-047 guard rather than extending
\(\MSStablePre\).
\end{proposition}

\paragraph{Reason.}
The audited use of \(\mathrm{RR}_E\) is source-pure only as uninterpreted
source syntax modulo explicit source relabeling. Physical interpretation is
outside the guarded domain.

\begin{proposition}[No accidental irrelevance-law adoption]
\(\MSStablePre\) cannot be forced into readout/response irrelevance-law
adoption as written.
\end{proposition}

\paragraph{Proof sketch.}
The precondition theorem is a partition theorem for fibers of \(\MSSig\). It
contains no relation that identifies records with different \(\mathrm{RR}_E\)
values. Any irrelevance law would have to introduce an independent
source-side identification theorem and pass its own audit and stress. Thus the
precondition can survive stress as a guarded partition target without
adopting irrelevance.
