\section{Discriminator Collapse}

\begin{countermodel}[Discriminator collapse returns failure]
Let
\[
  U_X=\{x\}, \qquad U_Y=\{y_0,y_1\}.
\]
Suppose \(x\), \(y_0\), and \(y_1\) are duplicate-compatible under readout
and response-label syntax. Supply a collapsed discriminator profile
\[
  \Prof_X(x)=h,\qquad \Prof_Y(y_0)=h,\qquad \Prof_Y(y_1)=h.
\]
Then \(\Delta\)-refined compatibility does not separate \(y_0\) from
\(y_1\). If both \(x\mapsto y_0\) and \(x\mapsto y_1\) belong to
\(\Cand_{XY}\), the discriminator repair alone does not select between them.
The correct output is \(\Sel_{XY}(\Cand_{XY})=\bot\) unless an additional
source-side selector chooses a unique source-minimal candidate.
\end{countermodel}

This countermodel is source-internal. It does not use target topology, target
charts, metric scale, empirical calibration, benchmark behavior, validation
status, generated notes, or role authority. It shows that a collapsed
discriminator blocks construction rather than authorizing arbitrary
transition selection.

\begin{proof}

discriminator collapses required distinctions or the preorder has no unique

process-authority fallback appears in either branch.
\end{proof}

is a fail-closed bridge-facing interface whose positive branch requires
