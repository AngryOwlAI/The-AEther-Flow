# Missing Source-Law Inventory Phase 2 Registration Audit

## Analysis

Phase 2 makes the Phase 1 inventory discoverable without turning it into
physics authority. The tracked YAML file remains the structured control input.
The Markdown companion is registered as the human-readable source surface and
derivative retrieval support is regenerated through the project memory system.

## Registration Decision

| Surface | Phase 2 decision | Reasoning |
| --- | --- | --- |
| `research_control/missing_laws/missing_source_law_inventory.md` | Register as `MD-MISSING-SOURCE-LAW-INVENTORY` in `MARKDOWN_SOURCE_REGISTRY.csv`. | Current lookup returns no source object, while the file is a tracked Markdown control companion that humans and agents need to find. |
| `research_control/missing_laws/missing_source_law_inventory.yaml` | Do not source-register in Phase 2. | Phase 0 found no first-class YAML source registry. Stable tracked path is sufficient for control consumption. |
| Dedicated missing-law CSV registry | Defer. | No evidence yet shows that YAML plus Markdown is insufficient or that row-level registry queryability is required. |
| Bootstrap/generated derivatives | Regenerate only through approved tooling. | Generated wiki, semantic, Obsidian, file-object, and index surfaces remain derivative retrieval support. |

## Boundary

The Markdown row is `project_control` authority for inventory discoverability
only. It is not scientific evidence for adopting a missing law, `AtlasGlue_src^+`,
`AtlasGlueDisc_src^+`, `M_src`, `g_eff`, matter coupling, Einstein equations,
benchmark status, or Gate Chair closure. The inventory remains navigation
evidence for `/continue-research`; it is not a second router and it does not
execute batch packets.

## Verification Targets

- `MARKDOWN_SOURCE_REGISTRY.csv` contains `MD-MISSING-SOURCE-LAW-INVENTORY`.
- `wiki/markdown/md-missing-source-law-inventory.md` is generated by bootstrap.
- Memory lookup can resolve `MD-MISSING-SOURCE-LAW-INVENTORY` after bootstrap.
- No YAML source registry or dedicated missing-law registry is created.
