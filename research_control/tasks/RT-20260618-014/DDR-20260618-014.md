# DDR-20260618-014: Phase 2B Claim Gates

## Decision

Route one bounded Documentation Curator AgentJob to implement Phase 2B of
`research_control/design/documentation_curator_corpus_migration_plan.md`.

## Rationale

The user explicitly approved the next logical step after Phase 2A. The
migration plan defines Phase 2B as one page family:
`claim-gates-explainer`. This packet addresses a public-risk ambiguity:
readers need to understand how proposals, audits, refutations, stress tests,
completions, handoffs, freeze labels, and human gates constrain claim language
without treating negative results as global theory rejection.

Phase 3A pages are not included because they are separate recommended packets
with different reader jobs.

## Claim Boundary

This decision authorizes a publication brief, source spec, GitHub-facing
Markdown, tracked HTML derivative, screenshot QA, review evidence, registry
updates, and generated memory/wiki refresh for Phase 2B only. It does not
authorize canonical ontology edits, benchmark promotion, Gate Chair verdicts,
science draft execution, first-principles derivation claims, physics claim
promotion, role authority changes, unregistered claim boundaries, generated
output authority, Phase 3 migration, or corpus-wide migration.
