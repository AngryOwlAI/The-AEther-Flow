\section{Stress Lemmas}

\begin{lemma}[Tag erasure preserves the finite toy response]
The response relation \(R_{v2}\) is recoverable from the unlabeled finite path
relation.
\end{lemma}

\begin{proof}
The unlabeled three-vertex path has one degree-two vertex and two degree-one
vertices. This determines the center orbit and endpoint orbit without using
presentation names. The path relation determines shortest path length between
unordered pairs, so the distance classes \(0,1,2\) remain available without
independent response tags.
\end{proof}

\begin{lemma}[Source relabeling preserves the response]
For every isomorphism \(\sigma\) of the finite source path,
\[
  R_{v2}(\{\sigma x,\sigma y\})=R_{v2}(\{x,y\}).
\]
\end{lemma}

\begin{proof}
Source isomorphisms preserve adjacency and finite path length. Since
\(R_{v2}\) is defined as graph distance in the source adjacency relation, the
response relation is invariant under such relabeling.
\end{proof}

\begin{lemma}[Edge perturbation is not physical robustness]
Changing \(A_{v2}\) is a source-relation edit. It either changes the finite
source object or activates the P6-T02 fail-closed bottom branch for
disconnected pairs.
\end{lemma}

\begin{proof}
If an edge is removed, some pairs are no longer connected and the P6-T02
finite-variation probe returns \(\BottomSrc\) for those pairs. If the endpoint
edge is added, the finite path becomes a triangle and the distance-two class
disappears. In neither case does target geometry, physical metric structure,
empirical readout, \(g_{\mathrm{eff}}\), or matter coupling repair the branch.
\end{proof}

\begin{lemma}[Target and downstream substitutions are blocked overreads]
Target distance, physical metric structure, empirical readout values,
\(g_{\mathrm{eff}}\), and matter coupling cannot be substituted for
source graph distance in this finite toy model.
\end{lemma}

\begin{proof}
The only response input in the model is the finite source adjacency relation.
Target geometry, physical metrics, empirical readouts, stress-energy
semantics, matter action, Einstein-equation premises, validator status,
registry metadata, handoff state, and commit state are not elements of
\(S_{v2}\), \(A_{v2}\), \(Inc_{v2}\), or the graph-distance construction.
Using any of them would change the candidate rather than stress it.
\end{proof}
