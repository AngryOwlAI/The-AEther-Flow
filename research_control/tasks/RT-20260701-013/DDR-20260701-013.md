# DDR-20260701-013: V13 P3-T03 Post-Stress Route Template

## Decision

Select `project-control-maintainer@0.2.0` as a task overlay for one bounded
v13 P3-T03 post-stress route template control packet.

## Basis

The latest tracked handoff `handoff-0421` requires one bounded P3-T03
post-stress route template control packet before any matter-semantics,
detector-semantics, coupling-law, matter-coupling, Einstein-equation,
benchmark, or promotion route.

The v13 plan defines P3-T03 as a reusable template for post-stress selector
tasks. The required sections are stress input artifact, audit input artifact,
construction input artifact, exact object under classification, available route
options, rejected route options, freeze criteria, Distance-to-GR delta,
forbidden conclusions, handoff text, and validation checklist.

claim fences.
