\section{Direct Finite Verification}

\begin{lemma}[Transport certificate validity inside declared scope]
The certificate \(c_{\mathrm{tr}}\) is a valid finite/local source transport
certificate inside
\[
  \Scope(c_{\mathrm{tr}})=\Esrc.
\]
Consequently
\[
  \Asrc \DeclEq \Bsrc \quad\text{inside } \Scope(c_{\mathrm{tr}})
\]
as a declared source-object equivalence only.
\end{lemma}

\begin{proof}
The finite check has three rows. For each \(i\in\{0,1,2\}\), the row
\(\tau(A,i)=(B,i)\) is present. The source guard is preserved because
\(G'(i)=G(i)\). The response token is preserved because \(R'(i)=R(i)=r_i\).
The domain entry and codomain entry have matching index \(i\), so the
domain-codomain boundary is compatible in every row. Thus the certificate
payload is explicit, source-side, and finite. By the P4-T01 schema, this is a
`valid_transport_certificate` with
\[
  \mathrm{expected\_equivalence\_result}
  =\mathrm{declared\_equivalence\_allowed}
\]
only inside the declared scope.
\end{proof}
