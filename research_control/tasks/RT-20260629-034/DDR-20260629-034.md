# Director Decision Record: DDR-20260629-034

## Decision

Select `validator-engineer@0.2.0` for one bounded v12 P1-T03 layered
Distance-to-GR ledger validator-guard packet.

## Basis

`research_control/program_state.yaml` names `RT-20260629-033` and
`handoff-0328`. The handoff authorizes exactly one next packet: harden
validator guard tests for layered ledger semantics without changing scientific
status.

The P1-T03 plan requires deterministic validator checks and negative fixtures
for unsafe readings of `matter_coupling`, `g_eff`, accepted scoped rows,
finite toy frozen-negative scope, and generated snapshot authority. This is
directly within `validator-engineer@0.2.0`.

## Scope

Allowed:

- update `scripts/research_control/validate_research_control.py` for layered
  ledger guard semantics;
- add focused negative tests in `tests/test_research_control.py`;
- add a missing machine-readable finite-toy overread guard token when required
  by the hardened validator;
- regenerate current-frontier, dependency graph, memory, and registry
  derivatives required by validation and checkpoint;
- create normal Continue Research receipts.

Blocked:

- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
- unscoped `g_eff` adoption or `g_eff` scope expansion;
- coupling-law adoption;
- matter-coupling derivation or adoption;
- stress-energy semantics;
- stress-energy tensor;
- matter action;
- detector semantics;
- Einstein equations;
- exact-GR benchmark promotion;
- benchmark Gate Chair closure;
- completed derivation;
- treating a validator, generated snapshot, memory layer, graph, checker,
  commit, or handoff as scientific proof.
