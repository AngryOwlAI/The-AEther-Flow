# Director Decision Record: DDR-20260629-040

## Decision

Execute P2-T04 as one bounded Validator Engineer task overlay.

The job extends `scripts/research_control/validate_research_control.py` with a
frontier theorem inventory lint check and adds focused unit tests in
`tests/test_research_control.py`.

## Basis

`handoff-0334` routes exactly one P2-T04 packet: add an inventory validator or
lint check. The P2-T01 schema already defines the validator forward contract,
and P2-T03 populated the live inventory.

This is validator/tooling work. It has no physics derivation milestone and
does not create or alter theorem statements, source laws, ontology, metric
objects, matter coupling, Einstein equations, benchmark status, or Gate Chair
authority.

## Scope

Allowed:

- validate that the inventory source exists and is registered;
- validate required inventory fields;
- validate source paths and generated-output authority boundaries;
- validate nonblank physical non-conclusions;
- validate high-risk overread guard presence;
- add focused fixture tests for missing non-conclusions and bad source paths;
- run the existing research-control validation suite;
- refresh generated retrieval, current-frontier, and graph layers;
- create normal task, role, AgentJob, completion, documentation-impact,
  claim-boundary, state, and handoff receipts.

Blocked:

- editing physics TeX sources;
- editing `registries/DISTANCE_TO_GR_LEDGER.csv`;
- changing inventory scientific meaning;
- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
- unscoped `g_eff` adoption or `g_eff` scope expansion;
- coupling-law adoption;
- matter-coupling derivation or adoption;
- stress-energy semantics;
- stress-energy tensor;
- matter action;
- detector semantics;
- Einstein equations;
- exact-GR benchmark promotion;
- benchmark Gate Chair closure;
- completed derivation.
