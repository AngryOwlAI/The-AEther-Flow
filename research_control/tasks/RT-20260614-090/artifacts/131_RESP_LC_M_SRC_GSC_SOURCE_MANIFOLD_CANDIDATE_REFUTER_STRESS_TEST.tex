\section{Stress Matrix}

\begin{stress}[Quotient-support noncanonicity]
\(\Qsrc\) is conditional source quotient support. It is not by itself a
source manifold.
\end{stress}

\begin{proof}
The construction defines \(\Qsrc\) by selected source transition tokens and
their guards. A quotient support can identify source tokens in a way that is
compatible with the declared token algebra while still failing source-local
separation, Hausdorff-like behavior, dimension or rank coherence, or
independence under admissible source-cover refinement. Those are exactly the
properties a source-manifold regularity primitive would need to supply.
\end{proof}

\begin{stress}[Source-chart nonseparation]
The maps \(\chi_i^{\mathrm{src}}\) are source-chart candidates, not adopted
coordinate charts of \(\Msrc\).
\end{stress}

\begin{proof}
The maps are built from source carriers into \(\Qsrc\). The candidate artifact
does not define a topology on \(\Qsrc\), an open-set basis, a smooth structure,
a differentiability class, a dimension theorem, or a source-local separation
axiom. Therefore the chart language is candidate syntax only.
\end{proof}

\begin{stress}[Transition-token degeneracy]
Non-bottom \(\GSC\) output blocks selected algebraic defects, but it does not
upgrade transition tokens into smooth transition maps.
\end{stress}

\begin{proof}
The selected tokens \(\Tau_{ij}\) are source transition tokens satisfying the
inverse and cocycle guards required by non-bottom \(\GSC\) output. This is a
source-token algebraic condition. It does not supply differentiable transition
maps, regular overlap domains, or a source-soldering theorem linking
\(\RespLC\) readouts to chart support.
\end{proof}

\begin{proof}
