# DDR-20260622-010: Phase 6 Bridge Checkpoint Documentation Phase 2 Publication Brief And Source-Spec Impact Audit

## Decision

Route one bounded Documentation Curator AgentJob to implement Phase 2 of the
Phase 6 bridge checkpoint governance documentation update.

Phase 2 authorizes a publication-brief and source-spec impact audit for the
two primary public explainer stacks selected by Phase 0:

- `project-system-improvement`
- `validator-operator-workflow`

The task may record proposed publication-brief and source-spec source-basis
changes, but it must not mutate the live publication corpus in this phase.
Strict publication validation requires parity across the publication brief,
registry row, source spec, GitHub-facing Markdown, and tracked HTML; therefore
brief/source-spec source-material changes must be synchronized with derivative
updates in a later publication packet.

The task does not authorize source-spec edits, GitHub-facing Markdown edits,
tracked HTML edits, screenshot replacement, validator changes, resolver
changes, checkpoint changes, role changes, skill-contract changes, sidecar
creation, sidecar registry changes, or physics claim changes.

## Selected Role

- Role: `documentation-curator`
- Version: `2.0.0`
- AgentJob: `AJ-RT-20260622-010-001`
- Execution overlay:
  `documentation-curator@2.0.0--RT-20260622-010`

## Rationale

The active publication pipeline is brief first, but this repository's strict
publication validator treats the page stack as a synchronized unit. The two
selected public pages need new source basis and boundary language, but applying
that live to briefs or source specs before derivative updates would leave the
publication corpus invalid. Phase 2 therefore records the impact and defers
corpus mutation.

Documentation Curator is the narrowest role because the task changes
only a task-local page-stack impact audit without changing executable behavior.
