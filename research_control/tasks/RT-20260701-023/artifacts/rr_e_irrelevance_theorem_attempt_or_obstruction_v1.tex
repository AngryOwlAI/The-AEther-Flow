\]
where \(S(r)\) denotes retained non-\(\RRE\) source support syntax, \(C(r)\)

\end{definition}

\begin{definition}[Source quotient candidate]
A source quotient candidate for \(\RRE\) irrelevance is a map
\[

\]
whose fibers identify records only when either:
\begin{enumerate}[label=Q\arabic*.,leftmargin=*]
  \item a source transport certificate \(\TrRR(r,r')\) is supplied; or

\section{Conditional Irrelevance Theorem Candidate}

\begin{lemma}[Factor-through \(\RRE\) irrelevance]
Let \(F:D_E\to X\) be a source-side object, label, relation code, or route
predicate. Suppose there exists a source-side quotient candidate
\(\pi_{\RRE}:D_E\to \bar D_E\) and a map \(\bar F:\bar D_E\to X\) such that
\[
  F = \bar F\circ\pi_{\RRE}.
\]
If \(\pi_{\RRE}(r)=\pi_{\RRE}(r')\), then \(F(r)=F(r')\).
\end{lemma}

\begin{proof}
The proof is purely formal. Since \(F=\bar F\circ\pi_{\RRE}\),
\[
  F(r)=\bar F(\pi_{\RRE}(r))=\bar F(\pi_{\RRE}(r'))=F(r').
\]
No detector semantics, target metric, stress-energy semantics,
\(\MetricData(E)\), \(\geff\), benchmark evidence, registry state, validator
state, or generated derivative is used. The burden is moved into the source
definition of \(\pi_{\RRE}\) and into the proof that \(F\) factors through it.
\end{proof}

\begin{proposition}[Separation without transport]
Let \(r,r'\in D_E\). If
\[
  S(r)=S(r'),\qquad C(r)=C(r'),\qquad \Qsrc(r)\ne \Qsrc(r'),
\]
and no \(\TrRR(r,r')\), no \(\InvRR(F;r,r')\), and no factorization
\(\FactRR(F)\) is supplied, then a P5 source-side construction may not identify
\(r\) and \(r'\) for \(F\). The identification branch returns \(\RRUnder\).
\end{proposition}

\begin{proof}
By the P5-T01 theorem target, \(r\SepRR r'\) holds when retained
\(\RRE\) syntax differs and no source transport certificate is available. The
only allowed P5-T02 identification routes are source transport or source
invariance/factorization. The hypotheses exclude all three routes. Therefore
identification has no source-side witness. The fail-closed branch is
\(\RRUnder\), not detector semantics and not a target-physics conclusion.
\end{proof}

\section{Minimal Countermodel}

\begin{countermodel}[\(\RRWitness\)]
Let \(D_E=\{r_0,r_1\}\). Define
\[
  S(r_0)=S(r_1)=s,\qquad C(r_0)=C(r_1)=c,
\]
and choose distinct retained source syntax tokens
\[
  \Qsrc(r_0)=q_0,\qquad \Qsrc(r_1)=q_1,\qquad q_0\ne q_1.
\]
Assume no source transport certificate \(\TrRR(r_0,r_1)\) and no source
invariance certificate \(\InvRR(F;r_0,r_1)\). Define a source-side label
\[
  F_Q(r)=\Qsrc(r).
\]
Then \(F_Q(r_0)\ne F_Q(r_1)\). Therefore the unrestricted theorem
\[
  \text{all source-side \(F\) are \(\RRE\)-irrelevant}
\]
is false on \(D_E\). More narrowly, any theorem claiming \(F(r_0)=F(r_1)\)
for arbitrary \(F\) cannot be proven from the current P5 inputs.
\end{countermodel}

\begin{proof}
All objects in the construction are source syntax objects. The function
\(F_Q\) is permitted because it only reads retained source syntax. Since
\(q_0\ne q_1\), \(F_Q(r_0)\ne F_Q(r_1)\). The countermodel does not say that
every future \(F\) depends on \(\RRE\). It says only that source-side
irrelevance is not automatic for arbitrary \(F\); it must be proven by
transport, invariance, or factorization.
\end{proof}

\section{Obstruction Record}

\begin{obstruction}[\(\RRUnder\)]
Current ontology and current P5 inputs do not derive a source-side rule that
decides, for every admissible \(\RRE\)-variation pair, whether retained
\(\RRE\) syntax is irrelevant to the next matter-semantics source object.
The missing primitive is:
\[
  \RRMissing.
\]
This primitive would need to define one of the following in source-only terms:
\begin{enumerate}[label=M\arabic*.,leftmargin=*]
  \item a complete source transport rule for \(\RRE\) records;
  \item an invariance rule naming which downstream source-side objects are
  insensitive to \(\RRE\) variations and why;
  \item a quotient law proving that a declared source object factors through a
  source quotient that safely removes \(\RRE\);
  \item a separation law proving that a declared source object must preserve
  \(\RRE\) distinctions.
\end{enumerate}
Until such a primitive is supplied, the project has a precise P5 obstruction:
conditional irrelevance is available only after explicit source
factorization/transport, while unrestricted \(\RRE\) irrelevance is defeated
by \(\RRWitness\).
\end{obstruction}
