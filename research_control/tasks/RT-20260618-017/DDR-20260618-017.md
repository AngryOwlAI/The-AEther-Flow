# DDR-20260618-017: Phase 3C Research-Control System Merge Decision

## Decision

Route one bounded project-system AgentJob to complete Phase 3C of
`research_control/design/documentation_curator_corpus_migration_plan.md` as a
decision-only packet.

The decision is that `research-control-system-explainer` does not currently
have a distinct standalone reader job after Phase 3A and Phase 3B. It remains
merged into the active Phase 3 research-control operation pages and related
operator references.

## Rationale

The migration plan required a distinct-reader-job test before reviving the
historical `research-control-system-explainer` filename. The reviewed Phase 3
coverage now includes:

- `research-agent-workflow-explainer`, for lane selection, memory preflight,
  one bounded AgentJob, stop conditions, and generated-output boundaries;
- `director-agentjob-lifecycle-explainer`, for task, DDR, AgentJob,
  execution-role, completion, handoff, registry, allowlist, and immutable
  record operation;
- `parent-child-synthesis-explainer`, for the internal one-job parent/child
  execution invariant; and
- `role-routing-explainer`, for registered roles, overlays, provisional roles,
  execution-role records, human gates, and actual authority inspection order.

The remaining possible reader job, operating the `research_control/` directory
as a reference surface, is better served by `research_control/README.md` plus
future Phase 4 operator pages. A new standalone page would duplicate the
workflow and lifecycle pages without adding a new reader problem.

## Claim Boundary

This decision authorizes a control review artifact, task records, registry
rows, documentation-impact receipt, and generated
memory/wiki refresh. It does not authorize publication briefs, GitHub-facing
Markdown, tracked HTML, screenshot QA for a new page, corpus-wide migration,
canonical ontology edits, benchmark promotion, Gate Chair verdicts, science
draft execution, physics claim promotion, role registration, schema changes,
validator behavior changes, routing behavior changes, or generated-output
authority.
