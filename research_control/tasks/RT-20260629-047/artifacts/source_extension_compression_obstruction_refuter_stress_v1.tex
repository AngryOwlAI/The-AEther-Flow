\section{Stress Lemmas}

\begin{lemma}[Single-row deletion obstruction]
Let \(r\) be any positive dependency row in the P4-T01 dependency table whose
P4-T03 assignment is \texttt{retain\_conservative} or
\texttt{retain\_conservative\_guard}. Deleting \(r\) does not produce a
nontrivial source-law compression under \(\Bcur\).
\end{lemma}

\begin{proof}
The deleted row is a currently retained input or guard for a scoped
source-extension object or precondition. Deleting it removes part of the
scoped package; it does not provide a derivation from current source ontology.
Because P4-T01 records zero positive rows as derived from current source
ontology, the deleted package still has no positive \texttt{derive} row.
\end{proof}

\begin{lemma}[Tag-forgetting fail-closed lemma]
If the scoped-source tags distinguishing conservative evidence, source-side
records, support-only receipts, and forbidden target imports are forgotten,
then the compression route fails closed rather than deriving matter coupling,
\(\MetricData(E)\), or unscoped \(\geff\).
\end{lemma}

\begin{proof}
The P4-T02 no-target-import condition and the P4-T04 audit require those
distinctions. Forgetting them makes it impossible to verify whether a row is
source-side evidence, process receipt, or forbidden target/physical import.
The permitted behavior is therefore fail-closed behavior, not promotion.
\end{proof}

\begin{proof}

\texttt{eliminate\_as\_mathematical\_premise}. They are not derivational
premises. Their removal cannot create a source-law derivation of a positive
row.
