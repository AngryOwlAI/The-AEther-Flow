\section{Stress Lemmas}

\begin{lemma}[Closure deletion blocks theorem status]
Deleting identity witnesses, inverse witnesses, or composition witnesses from
the typed source family blocks the corresponding reflexivity, symmetry, or
transitivity branch of \(\EqSrcT\).
\end{lemma}

\begin{proof}
The P2-T03 object defines identity, inverse, and composition as typed
obligations. It does not assert that all future source families automatically
contain the relevant witnesses. Therefore deleting a witness deletes the
premise needed for the corresponding equivalence-relation property. The
comparison rule can block or expose a countermodel slot, but it cannot turn
missing closure data into a theorem.
\end{proof}

\begin{lemma}[Invariant weakening is fail-closed]
If the invariant ledger no longer records enough source-side data to verify
preservation under a declared morphism, the positive \(\EqSrcT\) branch is not
available.
\end{lemma}

\begin{proof}
The invariant ledger is part of the side condition for \(\Csrc(X,Y)=\EqSrc\).
Weakening the ledger removes preservation evidence. The typed object supplies
no target geometry, benchmark success, registry authority, or validation
authority that can replace missing source invariant data. The result is a
narrower domain, a blocked comparison, or a repaired source ledger obligation.
\end{proof}

\begin{lemma}[Outside-family morphisms and unmapped proxy edges are blocked]
An outside-family morphism or unmapped proxy edge cannot be used to extend
\(\EqSrcT\).
\end{lemma}

\begin{proof}
Admissible morphisms are exactly those declared in \(\Msrc\) and compatible
with \(\Isrc\), \(\Asrc\), and \(\Psrc\). A morphism outside \(\Msrc\), or a
proxy edge without a source-side mapping rule, fails the typed side condition.
Thus the object blocks the comparison rather than expanding the family by
process authority or target-side analogy.
\end{proof}

\begin{lemma}[\(\RetainH\) and \(\GenH\) remain boundary conditions]
The typed object does not adopt \(\RetainH\) or \(\GenH\). If either is needed
for a future family theorem, it must be supplied by a separate authorized
packet.
\end{lemma}

\begin{proof}
The P2-T03 object explicitly records \(\RetainH\) and \(\GenH\) as boundary
conditions. P2-T04 found that this statement is source-pure as written. P2-T05
stress confirms that requiring either condition without declaration creates a
live obligation, not a theorem premise.
\end{proof}

\begin{lemma}[Process authority cannot repair missing closure]
Validation success, registry metadata, role identity, handoff state, commit
state, and generated derivatives cannot provide source-side identity, inverse,
composition, invariant, \(\RetainH\), or \(\GenH\) witnesses.
\end{lemma}

\begin{proof}
Those objects are provenance and process-control evidence. None is an element
of \(\Osrc\), a morphism in \(\Msrc\), an invariant in \(\Isrc\), or a
source-side closure witness. Treating them as mathematical premises would
change the comparison rule into an authority-status rule, which the typed
object blocks.
\end{proof}
