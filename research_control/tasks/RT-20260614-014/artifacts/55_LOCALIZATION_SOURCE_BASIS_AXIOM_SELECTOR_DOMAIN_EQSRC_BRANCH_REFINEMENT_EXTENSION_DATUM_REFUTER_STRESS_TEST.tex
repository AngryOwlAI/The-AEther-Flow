\begin{abstract}
This draft/control artifact stress-tests the audited branch-refinement
extension datum from tasks \texttt{RT-20260614-012} and
\texttt{RT-20260614-013}. The local positive result survives only inside
the declared finite branch family \(B_{1},B_{2},B_{3}\), where the
comparison preserves source branch tags, branch-local annotation totals,
proxy guards, forbidden-channel guards, influence coverage, boundary
anchors, and branch-preserving quotient descent. A pure global renaming
of source branch tags is harmless only when it transports the same source
ledger and adds no target semantics. Alternative branch-family
construction, label collapse or target-semantic relabeling,
annotation-monoid weakening, guard deletion, contraction-only
over-admission, quotient variation, relation-property extension,
boundary-anchor perturbation, and downstream use all remain blocked.
General \(\EqSrc\), \(\RetainH\), \(\GenH\), candidate reconstruction,
canonical ontology edit, benchmark promotion, Gate Chair review, and
completed-derivation language remain blocked.
\end{abstract}

\section{Scope}

This artifact is the role output for task \texttt{RT-20260614-014}. It
does not construct a new datum and does not audit target import. Those
steps were completed in \texttt{RT-20260614-012} and
\texttt{RT-20260614-013}. The Refuter question is:
\[
    \text{Does the audited local }\EqBr\text{ packet survive pressure
    outside its declared branch-family boundary?}
\]
The answer is narrow. The declared family survives as draft/control
evidence. Broader use and broader generalization remain blocked unless a
later source-side packet supplies new ledgers and passes the ordinary
audit and refutation sequence.

\section{Stress Method}

\begin{stressscreen}[Nine pressure channels]
The Refuter applies nine channels:
\begin{enumerate}
    \item branch-label perturbation, including harmless global source-tag
    renaming, label collapse, and target-semantic relabeling;
    \item alternative branch-family construction, including added branch
    arity, cross-branch merge nodes, and nondeclared source shapes;
    \item annotation-monoid weakening, where atoms are deleted, merged,
    weighted, or selected by downstream success;
    \item guard deletion or relaxation, where mapped proxy guards or
    forbidden-channel guards are removed from the comparison rule;
    \item contraction-only over-admission, where many-to-one maps are
    treated as sufficient without the full branch ledger;
    \item quotient variation, where representative choice merges branch
    structure or erases blocker evidence;
    \item relation-property extension, where reflexivity, symmetry, or
    transitivity is asserted beyond the declared family;
    \item boundary-anchor perturbation, where input or output carriers
    move, split, or become observer-like endpoints; and
    \item downstream-use pressure, where the local datum is used for
    \(\RetainH\), \(\GenH\), candidate reconstruction, or promotion.
\end{enumerate}
\end{stressscreen}

\section{Local Retention Screen}

\begin{stressfinding}[The declared branch-domain receipt survives]
Inside the declared positive family
\[
    \ObjBr=\{B_{1},B_{2},B_{3}\},
\]
each object admits the reviewed admissible branch-preserving contraction
to \(B_{1}\). The contraction fixes the boundary anchors \(i,o\), sends
left-branch carriers to \(\ell\), sends right-branch carriers to \(r\),
preserves branch-local annotation totals \(A_{L}\) and \(A_{R}\),
preserves mapped proxy guards and forbidden-channel guards, and maps
influence chains to the corresponding base-branch edges. Therefore the
audited local statement
\[
    \CmpBr(B_i,B_j;\InvBr)=\EqBr(B_i,B_j)
    \quad\text{for } i,j\in\{1,2,3\}
\]
is retained as branch-domain draft/control evidence.
\end{stressfinding}

\begin{controlrule}[No domain erasure]
The retained result is valid only while the object domain remains the
declared finite branch family. Removing that domain clause changes the
comparison rule and invalidates the local pass.
\end{controlrule}

\section{Label and Family Pressure}

\begin{stressfinding}[Pure source-tag permutation is harmless]
Let \(\pi:\{L,R\}\to\{L,R\}\) be the global swap
\(\pi(L)=R,\ \pi(R)=L\). If every object in \(\ObjBr\) is relabeled by
\(\pi\) while preserving the same branch-local annotation totals, guard
assignments, influence coverage, and admissible contractions, then the
datum changes only by source-tag renaming. No target metric, target
proper-time, target-locality, or observer-protocol semantics are added.
The local comparison therefore remains a bookkeeping-equivalent
draft/control receipt.
\end{stressfinding}

\begin{counterpressure}[Label collapse or target-semantic relabeling blocks]
If left and right tags are collapsed into one branch class, if new tags
are assigned because downstream behavior improves, or if branch tags are
read as target-left versus target-right observer or locality sectors,
then the comparison no longer uses branch labels as source bookkeeping.
The result is \(\Block\).
\end{counterpressure}

\begin{counterpressure}[Alternative branch-family construction is not admitted]
Consider a three-branch source object
\[
    T=(i,m,\ell,r,o)
\]
with three incomparable internal arms, or a cross-branch join object
whose left and right arms meet at an extra internal merger node before
\(o\). The current datum contains no invariant ledger for added branch
arity, merger-node admissibility, cross-branch blocker propagation, or
comparison against \(B_{1}\). Those objects are therefore outside the
declared family, and their use returns \(\Block\).
\end{counterpressure}

\section{Annotation, Guard, and Quotient Pressure}

\begin{counterpressure}[Annotation-monoid weakening blocks broader use]
If annotation atoms are deleted, merged across branches, weighted by
later success, or selected after downstream behavior is known, annotation
conservation no longer functions as source bookkeeping. It becomes a
possible target or candidate-performance proxy. The stress result is
\(\Block\) for any weakened monoid unless a superseding source-only atom
ledger proves the change independent of target success.
\end{counterpressure}

\begin{counterpressure}[Guard deletion erases adverse evidence]
The audited pass depends on mapped proxy guards and forbidden-channel
guards remaining active. If those guards are deleted or relaxed, an
unmapped proxy or target-channel admission can be hidden inside an
otherwise positive comparison. Therefore guard deletion returns
\(\Block\).
\end{counterpressure}

\begin{counterpressure}[Contraction-only admission is too weak]
A bare many-to-one map can erase branch multiplicity, branch-local
annotation placement, blocker state, and influence coverage. The audited
pass depends on contraction plus the full branch ledger. Therefore
contraction alone cannot define general \(\EqSrc\), cannot justify
quotienting blocked objects into positive objects, and cannot support
candidate use.
\end{counterpressure}

\begin{counterpressure}[Quotient variation is local only]
The current quotient rule is safe only when it preserves left-right
branch distinction until the declared branch-preserving contraction to
\(B_{1}\) is completed and when it preserves branch-local annotation,
guard, blocker, influence, and boundary receipts. A quotient that merges
left and right branches, chooses representatives because downstream
behavior improves, or erases negative evidence returns \(\Block\).
\end{counterpressure}

\section{Relation, Boundary, and Downstream-Use Pressure}

\begin{counterpressure}[Relation properties are local]
Reflexivity, symmetry, and transitivity are documented only for the
declared branch family where every positive object contracts to \(B_{1}\)
while preserving the same ledger. They are not proven for added branch
families, cross-branch merge objects, label-collapsed objects,
annotation-weakened objects, guard-deleted objects, or altered
quotients. General \(\EqSrc\) therefore remains unproved.
\end{counterpressure}

\begin{counterpressure}[Boundary perturbation blocks the pass]
Moving \(i\) or \(o\), splitting an endpoint, identifying an endpoint
with a target observer protocol, or choosing boundary anchors because a
target comparison improves changes the source boundary ledger. The
current positive receipt has no proof of boundary-anchor invariance under
such perturbations. These cases return \(\Block\).
\end{counterpressure}

\begin{counterpressure}[Downstream use fails the boundary test]
No step in the audited local datum supplies \(\RetainH\), \(\GenH\), or
candidate reconstruction. Treating local \(\EqBr\) as a source basis for
those downstream claims would import an unproved extension. The Refuter
result is therefore \(\Block\) for downstream use until a separate
source-family packet proves the required relation properties and passes
smuggling audit and stress testing.
\end{counterpressure}

\section{Verdicts}

\begin{verdict}[Local branch-domain retention]
The audited branch-refinement extension datum survives this stress test
only as local branch-domain evidence:
\[
    \EqBr\big|_{\{B_{1},B_{2},B_{3}\}} \Rightarrow \Pass
    \quad\text{draft/control only.}
\]
This means the positive branch family remains useful as a narrow
source-side witness family, not as a general \(\EqSrc\) theorem.
\end{verdict}

\begin{verdict}[Generalization block]
The same packet fails to support alternative branch-family construction,
label collapse or target-semantic relabeling, annotation-monoid
weakening, guard deletion, contraction-only admission, broader quotient
variation, general relation-property extension, boundary perturbation, or
downstream use. Those attempted extensions return \(\Block\) under the
present authority record.
\end{verdict}

\begin{verdict}[No promotion]
This stress test does not discharge general \(\EqSrc\), \(\RetainH\), or
\(\GenH\). It does not prove semantic \(\NoTargetH\), does not
canonically adopt \(\NoTargetSyn\), does not authorize candidate
reconstruction, does not edit canonical ontology, does not promote
benchmark status, does not request Gate Chair review, and does not permit
completed-derivation language.
\end{verdict}
