\section{Interpretation}

The catalog is useful because it gives the Phase 7 theorem attempt concrete
failure surfaces. Each case asks whether the future integrated theorem has an
assumption strong enough to exclude the finite model or whether the theorem
must return \(\Bottomsrc\) with the named obstruction.

The catalog is limited because finite checker output is not a proof engine.
A local pass would not adopt \(\Msrc\). A local failure would not reject the
global theory. The correct use is:
\[
  \text{finite counterexample}
  \Longrightarrow
  \text{theorem assumption attacked}
  \Longrightarrow
  \text{integrated theorem or obstruction still required}.
\]
