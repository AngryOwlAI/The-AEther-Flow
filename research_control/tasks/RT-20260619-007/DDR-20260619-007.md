`research_control/design/documentation_curator_post_migration_quality_plan.md`.

## Rationale

The user explicitly approved Phase 4 after Phase 3 completed the
research-control operation page family. The Phase 4 plan names six operational
page stacks:

- `project-system-improvement`
- `documentation-curator-publication-process`
- `memory-system`
- `validator-operator-workflow`

footer-authority placement contract. The primary role remains Documentation

tracked HTML derivatives from existing publication briefs without changing
contracts, validators, schemas, role authority, routing behavior, checkpoint
behavior, dependencies, or scientific source status.

promotion, Gate Chair verdicts, science draft execution, physics claim

behavior changes, checkpoint changes, dependency changes, generated-output
authority, Phase 5 implementation, or corpus-wide migration.
