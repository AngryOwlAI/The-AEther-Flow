\section{Stress Surface}

The audited candidate obtains positive matter-semantics candidate records only
from source matter-signature labels, finite/local source supports,
compatibility certificates, non-import bundles, source probe tokens, source
readout syntax, source response tokens, and fail-closed guards. The Refuter
stress question is whether this remains meaningful when the candidate is
subjected to source relabeling, finite variation, tag removal, sector deletion,
degeneracy, \(\geff\)-scope pressure, explicit-label collapse, new-primitive
pressure, and support-only proof-authority erasure.

The result is conditional survival. The candidate survives as a
bridge-facing draft/control path only when the source relabeling transports the
source labels, supports, compatibility certificates, non-import bundles, probe
tokens, and evidence paths while preserving certificate pass/fail values. If
those source records are erased, collapsed into explicit names, or replaced by
target or process authority, positive matter-like distinctions are not
preserved; the branch fails closed to \(\BottomS\), \(\BottomR\),
\(\FailureObs\), or \texttt{source\_undetermined}.

\begin{lemma}[Relabeling stress survival with declared transport]
Let \(\rho:E\to E'\) be a source relabeling that transports source supports,
source matter-signature labels, compatibility certificates, non-import
bundles, probe tokens, and evidence paths by fieldwise relabeling. If \(\rho\)
preserves compatibility-certificate and non-import-bundle pass/fail values,
then every non-bottom \(\MSCand(E;\Bcur)\) record transports to a non-bottom
\(\MSCand(E';\rho\Bcur)\) record.
\end{lemma}

\begin{proof}
The membership, readout, and response-token rules inspect only transported
source labels, finite/local source supports, compatibility-certificate values,
non-import-certificate values, source probe-token fields, and evidence paths.
By hypothesis all inspected fields and pass/fail values are preserved. The
transported record therefore satisfies the same source-only predicates in
\(E'\). This is a conditional source-side transport statement, not target
covariance, physical equivalence, matter coupling, or benchmark evidence.
\end{proof}

\begin{lemma}[Tag-removal and sector-deletion fail-closed stress]
If source matter-signature labels, sector supports, compatibility
certificates, or non-import bundles required by a positive
\(S_E^{\mathrm{msc}}\) record are removed, the candidate no longer determines
positive matter-like distinctions for the affected record. The branch returns
\(\BottomS\), \(\BottomR\), \(\FailureObs\), or
\texttt{source\_undetermined}; it does not prove an adopted source law or a
matter-coupling result.
\end{lemma}

\begin{proof}
Positive sector membership is defined by the presence of a source
matter-signature label, finite/local source support, passing compatibility
certificate, and passing non-import bundle. Removing any required member of
that support family falsifies the local positive-membership premise. The
candidate's declared finite-variation behavior therefore routes the affected
record to bottom, failure obstruction, or undetermined source status. A missing
source support is not target matter semantics, not stress energy, not a
detector result, and not a coupling law.
\end{proof}

\begin{lemma}[Degeneracy is not repaired by target semantics]
