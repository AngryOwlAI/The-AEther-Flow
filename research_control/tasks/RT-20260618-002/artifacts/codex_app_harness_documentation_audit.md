# Codex App Harness Documentation Audit

## Objective

Clarify that AEther-Flow is currently developed and operated through the Codex
app for governed AI-agent workflows.

## Changes

- Added a `Current AI-agent harness` subsection to `README.md`.
- Added a Codex app tier to the README requirements list.
- Updated the technical-requirements source spec to include the Codex app
  harness as a distinct tier.
- Updated the matching GitHub-facing and HTML derivatives.
- Refreshed memory, wiki, semantic, and registry derivatives through bootstrap.

## Boundary

The update does not claim that Codex app access is scientific authority. It does
not claim permanent harness lock-in. It says only that reproducing the governed
research-agent workflow as currently practiced requires the Codex app until a
future harness is explicitly documented and validator-backed.
