# Director Decision Record

## Current Objective

Document the current AI-agent operating harness for the repository: the governed
research-agent workflow is presently developed and operated in the Codex app.
The documentation must also preserve the separate facts that read-only source
inspection and Python validators can run outside the Codex app and that a future
AI harness would need an explicit compatibility boundary before being treated as
supported.

## Role-Fit Matrix

Documentation Curator was considered because the human request framed the work
as documentation. That role is not the correct authority boundary here because
the edit changes the control-marked Requirements section and forces registry and
generated derivative synchronization.

Project-Control Maintainer is selected with a narrow task overlay. The overlay
permits the minimum explanatory and generated surfaces needed to state the
current Codex app harness boundary while preserving source-first authority and
not changing physics claims or workflow validators.

Memory-System Maintainer is not selected because bootstrap and wiki refresh are
derivative synchronization steps for this task rather than the primary work.

## Selected Role

`project-control-maintainer@0.1.0` with one-job overlay permission for
control-marked requirements wording, the technical-requirements source spec, the
matching GitHub-facing and HTML derivatives, registry rows, and task-local
receipts.

## Claim Boundary

The task may claim only that Codex app is the current supported harness for the
governed AI-agent workflow as practiced in this repository. It must not claim
that Codex app access creates scientific authority, that the project is
permanently tied to Codex, or that the physics derivation status changed.
