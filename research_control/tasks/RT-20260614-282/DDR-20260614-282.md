# Director Decision Record: DDR-20260614-282

## Decision

Select `project-control-maintainer@0.2.0` for one bounded P7-T04 Continue
Research graph-summary packet.

## Basis

`handoff-0314` requires one P7-T04 project-control packet to surface a compact
generated dependency graph summary in Continue Research context. The P7-T04
plan requires active task, latest handoff, active burden, immediate upstream
objects, accepted scoped objects, draft/control objects, human-gated objects,
blocked downstream objects, frozen negative routes, next recommended route, and
graph path or hash.

The selected role is appropriate because the packet changes project-control
routing context and tests. It has no physics milestone and cannot turn generated
graph output into physics evidence, proof authority, claim-promotion authority,
or control authority.

## Scope

Allowed:

- Surface a compact `dependency_graph_summary` in `continue_research.py`.
- Include the required P7-T04 summary fields with bounded list sizes.
- State that generated graph summary is navigational support only and does not
  replace canonical source inspection.
- Add focused tests for required fields, graph path or hash, readability limits,
  and support-only authority boundary.
- Regenerate graph artifacts after final tracked control state.
- Update control registries, task records, documentation-impact receipt,
  `program_state.yaml`, and `handoff-0315`.

Blocked:

- canonical ontology edit
- source-law adoption
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- matter action
- detector semantics
- Einstein equations
- benchmark promotion
- completed derivation
- treating graph output or graph summary as physics evidence
- treating generated graph artifacts as control authority
- treating graph summary as replacement for canonical source inspection
- Distance-to-GR ledger change
- Gate Chair verdict or protected evidence-status change

the generated graph as navigation only, then routes the next bounded packet to
