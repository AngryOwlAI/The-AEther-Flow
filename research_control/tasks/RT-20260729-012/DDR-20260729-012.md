The protected P8-T07 result makes P9-T01 eligible after checkpoint while
preserving Gate D as `NOT_READY`. The existing source record contains exact
finite and proposal-only objects, but it does not derive an unscoped effective
metric, physical dynamics, Einstein equations, or exact-GR recovery. A lawful
benchmark program must therefore separate source computation from target
comparison more strongly than a prose warning.

The packet will model each case as a provenance-directed acyclic graph. Source
execution may depend only on fixed source roots, explicitly declared
source-extension roots, independent calibration roots, and hashed code. A
target oracle may be opened only after source outputs and their hashes are
sealed. If a forbidden target root reaches any source input, intermediate,
branch selector, parameter selection, stopping rule, or tolerance, the case
fails closed before comparison.

Under these explicit hypotheses, a target agreement result cannot be caused
by reusing the target theory inside the source computation. This is a
protocol-soundness result only. It does not show that the source theory
produces any physical benchmark output.
