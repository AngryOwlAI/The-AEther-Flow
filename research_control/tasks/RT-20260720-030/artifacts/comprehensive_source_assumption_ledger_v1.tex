\section{Status algebra}

\begin{definition}[Two-axis status]
For an assumption token $a$, its structural role is
\[
 r(a)\in\{\mathsf{Primitive},\mathsf{Derived},\mathsf{Gauge},
 \mathsf{Operational},\mathsf{Open},\mathsf{NotApplicable}\},
\]
and its authority status is
\[
 q(a)\in\{\Adopted,\Proposed,\Open,\HumanGated\}.
\]
The axes are independent.  In particular,
\(r(a)=\mathsf{Primitive}\) does not imply \(q(a)=\Adopted\), and the
existence of a document for $a$ does not imply
\(r(a)=\mathsf{Derived}\).
\end{definition}

\begin{definition}[Provenance state]
Every assumption token has exactly one audit outcome:
\begin{enumerate}
  \item one or more canonical source paths with observed SHA-256 hashes; or
  \item an explicit missing-source or no-premise marker.
\end{enumerate}
A missing-source marker makes the debt visible but is not a derivation premise.
Generated wiki, registry metadata, role identity, validator status, and this
ledger are not source-side proof premises.
\end{definition}

\section{No-circular-upgrade theorem}

\begin{definition}[Derivation certificate]
Let $V$ be a finite set of assumption and result tokens.  An edge
$y\to x$ means that $x$ uses $y$ as a premise.  A valid derivation
certificate for $x$ consists of a finite ancestral subgraph $D_x$, a rank
$h: D_x\to\mathbb{N}$ with $h(y)<h(z)$ for every premise edge $y\to z$,
and a canonical provenance record for every primitive leaf.  A leaf carrying
only a missing-source marker is open and cannot serve as a discharged premise.
\end{definition}

\begin{theorem}[Circular provenance cannot upgrade status]
If the ancestry of $x$ contains a directed cycle through $x$, or if every
putative proof of $x$ terminates at a leaf with only a missing-source marker,
then no valid derivation certificate can change $r(x)$ from primitive,
proposed, or open to derived.  Documentation of the cycle does not alter this
conclusion.
\end{theorem}

\begin{proof}
Suppose first that a valid certificate exists and that its ancestry contains
the cycle
\(x=x_0\to x_1\to\cdots\to x_n=x\).
The rank condition gives
\(h(x_0)<h(x_1)<\cdots<h(x_n)=h(x_0)\), a contradiction.  Thus a valid
well-founded certificate cannot contain the cycle.  In the second case,
well-foundedness supplies at least one terminal leaf, but the definition
requires canonical premise provenance at every primitive leaf.  A
missing-source marker records the absence of that premise and therefore fails
the base condition.  Adding a ledger entry changes neither the graph nor the
missing base evidence, so it cannot create a derivation certificate.
\end{proof}

\begin{corollary}[Target-import guard]
The adopted exact-GR metric, time orientation, matter action, coupling, or
dynamics cannot be used as a source premise in a claimed derivation of the
same target object unless a separate acyclic source-to-target bridge with
independent canonical premises is supplied.
\end{corollary}

\section{Circularity audit}

Four blocked upgrade patterns are explicit in the companion matrix:
\begin{enumerate}
  \item target metric $\to$ target time direction $\to$ relabeled source
  order $\to$ effective metric $\to$ target metric;
  \item benchmark coupling $\to$ benchmark matter semantics $\to$ claimed
  source matter semantics $\to$ source coupling $\to$ benchmark coupling;
  \item exact-GR dynamics $\to$ target metric $\to$ claimed source dynamics
  $\to$ exact-GR recovery; and
  \item assumed four-dimensional smoothness $\to$ scoped source manifold
  $\to$ claimed derivation of four-dimensional smoothness.
\end{enumerate}
These are dependency-shape guards, not claims that the repository has already
made the prohibited upgrades.
