\section{Findings}

\begin{lemma}[MetricFormAssign source-purity audit lemma]
As written, \(\MetricFormAssign\) does not require target topology, target
atlas, target coordinate transitions, target metric, Lorentzian metric,
Lorentzian signature, proper-time scale, detector semantics, empirical
calibration, benchmark fit, candidate reconstruction, process authority,
\(\MetricData(E)\) adoption, \(\SigScaleCont\) source-law adoption, or
\(\geff\) construction.
\end{lemma}

\begin{proof}
The non-bottom branch of the proposal is conditioned on explicit source-side
metric-form record slots and source-transition preservation. Each target or
process source listed above is either excluded by the input boundary or routed
to \(\BottomSrc\) when it is the only source of a required component. The
proof is therefore only an audit of the written proposal. It does not prove
existence, uniqueness, robustness, source-law adoption, or downstream GR
recovery.
\end{proof}

The audit yields seven concrete findings:
\begin{enumerate}[leftmargin=*]
  \item The carrier scope is source-pure only when declared as a source
  carrier or finite source package scope, not read from a target manifold.
  \item The form token is source-pure only when supplied as source-side data,
  not copied from a target metric tensor, line element, inverse, determinant,
  or causal cone.
  \item The pairing syntax is source-pure only when not imported from proper
  time, detector calibration, coordinate differentials, empirical clock
  behavior, or benchmark fit.
  \item The signature-scale binding cannot promote \(\SigScaleCont\) from
  scoped evidence or precondition status to source law.
  \item The transport token is an obligation under admitted source
  transitions, not a target atlas or smooth transition theorem.
  \item The nondegeneracy token is a certificate obligation or controlled
  bottom slot, not target determinant or inverse-metric authority.
  \item Validator success, role authority, registry metadata, handoff state,
  generated derivatives, local cache, file order, and commit state do not
  supply metric-form content.
\end{enumerate}
