# DDR-20260707-003

## Decision

Select `validator-engineer@0.2.0` with a one-task project-system overlay to
repair the CI failures caused by a registered Markdown source path being
ignored and absent from Git, then by folder-map generation depending on ignored
local/cache directories present outside a clean checkout.

## Basis

The GitHub Actions failure showed that `MARKDOWN_SOURCE_REGISTRY.csv`
referenced `implementations_plans/recommendations_implementation_plan_continue_task-v16.md`,
while a clean checkout did not contain that path because
`implementations_plans/*` ignored it. The repair is project-system work:
restore Git visibility for the registered source, add a validator guard for
future ignored or untracked registry paths, stabilize folder-map generation
against ignored local/cache directories, and refresh generated memory
derivatives.
