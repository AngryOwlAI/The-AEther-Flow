# Director Decision Record: DDR-20260704-012

## Decision

Execute one bounded `documentation-curator@2.0.0` task overlay for v15 P17-T03.

The selected route creates and registers
`markdown/html-explainer-specs/negative-results-and-obstructions-explainer.md`
as the source spec for a future human-facing negative-results explainer. It
updates the deferred publication-brief registry row so the active publication
process recognizes the spec. Because registered HTML source specs require an
existing `output_path`, it also synchronizes the generated GitHub-facing
Markdown and tracked HTML derivatives through the source-spec path. It does
not create a publication action, corpus migration, or physics claim
promotion.

## Basis

`handoff-0557` routes next to P17-T03 if the public explainer system is active.
The system is active because `markdown/html-explainer-specs/README.md`,
`registries/PUBLICATION_BRIEF_REGISTRY.csv`, and
`scripts/validate_publication_process.py` define retained public explainer
source specs and enforce that specs are listed in the publication-brief
registry.

The v15 plan requires the source spec to explain what a frozen route means,
what a scoped obstruction means, why negative results matter, current
frozen/obstructed routes, and what remains open. The P17-T02 publication brief
already defines the reader job and authority boundaries for this source-spec
packet.

## Scope

Allowed:

- create one HTML explainer source spec under `markdown/html-explainer-specs/`;
- update `registries/PUBLICATION_BRIEF_REGISTRY.csv` to name the source spec
  and derivative output targets;
- register the source spec in `registries/MARKDOWN_SOURCE_REGISTRY.csv`;
- synchronize the generated noncanonical GitHub-facing Markdown and tracked
  HTML derivatives from the registered source spec;
- update task, job, role, completion, handoff, program-state, registry, and
  documentation-impact receipts;
- refresh generated memory derivatives.

Blocked:

- direct HTML-only publication outside the source-spec path;
- treating generated derivatives as source authority;
- before/after corpus migration review as if this were corpus migration;
- corpus migration;
- physics claim promotion;
- source-law adoption;
- future source-extension impossibility;
- program-wide rejection;
- benchmark promotion or completed derivation.
