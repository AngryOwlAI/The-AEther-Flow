# DDR-20260706-036

## Decision

Select `project-control-maintainer@0.2.0` with a P12-T04 dashboard tooling
overlay for one bounded AI methodology metrics dashboard integration packet.

## Basis

- `handoff-0667` selects one bounded v17 `P12-T04` methodology dashboard
  integration packet.
- `implementations_plans/recommendations_implementation_plan_continue_task-v17.md`
  requires dashboard labels that identify metrics as AI-system diagnostics and
  forbid ranking physics truth by workflow activity.
- `research_control/design/v17_recommendation_backlog.yaml` expects
  `output/ai_methodology_metrics_dashboard.json` and
  `wiki/indexes/ai_methodology_metrics_dashboard.md`.
- `output/physics_progress_metrics.json` and
  `output/physics_progress_metrics.md` supply the current P12 methodology
  metric values and advisory warning rows.
- The active role registry does not expose `tooling-engineer@0.1.0`.
  `project-control-maintainer@0.2.0` is the closest active tooling-compatible
  role because this packet adds deterministic renderer tooling, a focused test,
  generated dashboard outputs, and task-local validation without editing
  science sources.

## Boundary

This decision authorizes only the P12-T04 dashboard renderer, focused test,
generated dashboard JSON and Markdown outputs, refreshed metrics report
outputs, task-local validation, normal control registry updates, generated
derivative refresh, and handoff synchronization. It does not authorize
canonical ontology edits, source-law adoption, `MetricData(E)` adoption,
`g_eff` scope expansion, matter-coupling derivation, Einstein-equation
derivation, benchmark promotion, Gate Chair verdicts, physics-truth ranking,
or completed-derivation claims.
