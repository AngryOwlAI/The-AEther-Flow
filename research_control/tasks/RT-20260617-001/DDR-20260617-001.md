# Director Decision Record DDR-20260617-001

## Decision

Route `RT-20260617-001` to one task-overlay
`validator-engineer@0.1.0` AgentJob,
`AJ-RT-20260617-001-001`.

## Basis

The user explicitly required that every future `/continue-research`
physics research task use the parent-child perspective synthesis
pattern. The existing project-system implementation treated
`role_decomposition.mode: "parent_child_parallel_synthesis"` as
optional. That created a validator gap and a control-contract drift
between user intent and future AgentJob requirements.

## Role Fit

`validator-engineer@0.1.0` is the correct base role because the durable
fix requires validator behavior, tests, schema text, skill text,
Director guidance, and documentation-impact receipts. The task does
not execute physics research and does not alter scientific claim
status.
