\(p_1\), and a support marker \(\mathsf{left}\), \(\mathsf{middle}\), or

\begin{definition}[Quotient support]

\[
q_0=\{u_0,v_0,w_0\},\qquad
q_1=\{u_1,v_1,w_1\}.
\]
The source-local separation certificate is the profile/incidence evidence
distinguishing \(p_0\) from \(p_1\) across the finite cover. Thus
\[

If that source evidence is collapsed, or if a target topology or target
metric is used to separate \(q_0\) and \(q_1\), the branch returns \(\Bot\).
\end{definition}

\section{Soldering}

\[
  r_0 \leadsto q_0,\qquad r_1 \leadsto q_1.
\]
\end{definition}

\begin{construction}[Soldering equivalence]
\(\SolderSrc\) attaches \(r_0\) to the \(q_0\) support in
\(\chi_U,\chi_V,\chi_W\), and \(r_1\) to the \(q_1\) support in the same

If a single readout token attaches to incompatible quotient supports without
source equivalence, or if proper time or target metric data are used to
select the attachment, \(\BottomSrc\) returns \(\Bot\).
\end{construction}
