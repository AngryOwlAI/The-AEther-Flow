# DDR-20260701-043: P4 Validation-Status Schema Split

## Decision

Route one bounded `project-control-maintainer@0.2.0` AgentJob for v14
`P4-T02` validation-status schema split.

## Rationale

The latest tracked handoff requires a schema split before public status
propagation or downstream physics routes. The P4-T01 inventory established
that one field family currently mixes validator receipts, protected
authorization, and downstream scientific-promotion authority. The logical next
step is therefore a narrow project-control schema update.

The user provided human authorization for human gates in the goal request. This
decision records that authorization as sufficient for the protected
project-control schema split only. It does not authorize ontology edits, source
law adoption, Gate Chair verdicts, benchmark promotion, downstream physics
promotion, or completed-derivation claims.

- Add a validation-status layer schema contract.
- Add prospective validator support for `validation_layers` and
  `authorization_layers`.
- Keep historical completions and handoffs backward compatible.

  authorization layer names.
- Update completion and handoff templates for future records.

- Regenerate current frontier and memory derivatives through approved tooling.
