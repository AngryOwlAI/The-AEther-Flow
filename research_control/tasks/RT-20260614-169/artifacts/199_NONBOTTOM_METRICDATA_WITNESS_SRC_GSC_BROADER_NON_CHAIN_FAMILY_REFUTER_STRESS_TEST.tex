\section{Rooted Tail-Branch Stress Lemma}

\begin{lemma}[Rooted tail-branch family stress survival]
For every finite \(n\ge 2\), under the source package \(\Bn\), admitted
rooted-tail-branch source transition tokens, and repair-or-bottom finite
variation rule from \texttt{RT-20260614-167}, the audited
\(\Witness(\Bn)\) candidate survives the required Refuter stress dimensions
only as rooted tail-branch finite source-family draft/control candidate data.
\end{lemma}

\begin{proof}
Collapse stress is handled by the response-profile condition. For \(\Bn\),
omitting identities, the profiles are
\[
p_n(r)=(n+1,0),\qquad
p_n(x_i)=(n-i,i),\qquad
p_n(y)=(0,1).
\]
The root \(r\) is the unique site with zero strict predecessors and maximal
strict successors. Tail sites are distinguished by predecessor count. The
isolated branch leaf \(y\) is separated from \(x_i\) for \(i<n\) by successor
count, and from \(x_n\) because \(p_n(x_n)=(0,n)\ne(0,1)\) when \(n\ge 2\).
Thus all declared sites are distinguished.

Nonuniqueness stress is handled by source-gauge uniqueness. The valuation
record identifies \(r\), \(y\), each \(x_i\), and the primitive edges
compatible with the rooted tail-branch schema. Two presentations with the
same record differ only by admitted source relabeling. If a broader gauge
policy is demanded, this packet cannot use target geometry or process state
to select a record; it must fail closed or route to a separate source-side
law.

Source-transition covariance stress is handled by limiting \(K_{\tau}\) to
source relabelings and structure-preserving source isomorphisms that preserve
the root, isolated branch leaf, ordered tail roles, primitive edge relation,
and strict reachability relation. Broader transition demands are not target
coordinate covariance and are not repaired by a target metric.

Finite-variation stress is handled by the declared repair-or-bottom rule.
Source-isomorphic edits preserve the record. Tail extension repairs to
\(\Bnprime\) with \(n'\ge 2\). Tail shortening repairs only when the result
still has \(n'\ge 2\). Deleting \(r\to y\), deleting \(r\to x_1\), breaking
incidence, introducing reconvergence, forcing profile collapse, importing
target structure, or using process authority returns a named bottom or
\(\OBGEFF\) branch.

Therefore every required stress dimension either preserves rooted
tail-branch family candidate status or fails closed. No branch yields adopted
\(\MetricData(E)\), an arbitrary source-package theorem, an arbitrary
finite-DAG theorem, \(\geff\), matter coupling, Einstein equations,
benchmark promotion, completed derivation, future source-extension
impossibility, or global theory rejection.
\end{proof}

\section{Counterpressure Cases}

\begin{stresscase}[Diamond pressure remains outside the survival scope]
Let \(\Diamond\) have directed edges
\[
0\to 1,\quad 0\to 2,\quad 1\to 3,\quad 2\to 3.
\]
The middle sites have the same strict reachability profile:
\[
p(1)=p(2)=(1,1).
\]
\end{stresscase}

\begin{proof}
Both middle sites receive one predecessor and reach one successor. The
profile discriminator that distinguishes \(\Bn\) therefore collapses on the
diamond. This is a pressure case against arbitrary finite-DAG, arbitrary
reconvergent branching, and arbitrary source-package overread. It is not a
refutation of \(\Bn\), because \(\Diamond\) is not a rooted tail-branch
package: it contains reconvergence and no isolated \(y\)-leaf.
\end{proof}

\begin{stresscase}[Reconvergent branch pressure]
If a source variation adds a primitive edge \(y\to x_j\), \(1\le j\le n\), or
adds a second path that reconverges into the tail, the edited package need
not preserve the profile-injectivity proof or the declared rooted
tail-branch schema.
\end{stresscase}

\begin{proof}
The candidate admits primitive branching at \(r\) without reconvergence. A
new reconvergent branch changes the schema and is not an admitted source
isomorphism. The repair-or-bottom rule therefore cannot silently treat this
as a successful \(\Bn\) instance. It must either be classified in a later
authorized family or return the finite-variation, collapse, or scope bottom
branch.
\end{proof}

\begin{stresscase}[Admitted tail variation is not arbitrary robustness]
Tail extension from \(\Bn\) to \(B_{n+1}\) and tail shortening to
\(B_{n-1}\) when \(n-1\ge 2\) can repair inside the declared family.
Deletion of \(r\to y\), deletion of \(r\to x_1\), or tail shortening below
\(n=2\) does not repair to a declared family member.
\end{stresscase}

\begin{proof}
The repair condition requires exactly one root with two outgoing primitive
edges, one isolated branch leaf, and one directed tail of length at least
two. Tail extension and admissible tail shortening preserve or repair that
schema. The listed deletions or too-short tail cases violate it and return a
named source bottom branch. The bottom branch is not a witness and not
\(\MetricData(E)\).
\end{proof}
