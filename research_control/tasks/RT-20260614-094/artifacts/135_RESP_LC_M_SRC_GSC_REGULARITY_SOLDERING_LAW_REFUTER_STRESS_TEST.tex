\section{Stress Matrix}

\begin{stress}[Source-local nonseparation]
Can non-bottom \(\RegSold\) still identify source tokens or quotient classes
that must remain separated for adoption-level \(\Msrc\)?
\end{stress}

\begin{proof}
\(\SepSrc\) returns non-bottom only when source context supplies
distinguishing evidence invariant under admissible source relabelings. This
blocks the simplest collapse branch in a finite or local witness where the
separating evidence is explicit. It does not prove a general separation
theorem for all source-cover data. Therefore the stress survives only with an
explicit witness-level separation certificate; otherwise \(\BottomSrc\) must
return \(\Bot\).
\end{proof}

\begin{stress}[Topology or regularity noncanonicity]
Does \(\TopRegSrc\) select a canonical source regularity structure, or can
multiple incompatible structures satisfy the same source data?
\end{stress}

\begin{proof}
\(\TopRegSrc\) is source-pure as audited, but its support mode may be
topological, order-theoretic, sheaf-like, combinatorial, categorical, or
algebraic. If a witness leaves the support mode unspecified, multiple
non-equivalent structures can satisfy the same loose data. The stress
therefore requires the finite/local witness to state the support mode,
overlap rule, and refinement behavior. Without that, the branch bottoms out.
\end{proof}

\begin{stress}[Transition-token degeneracy]
Do inverse and cocycle tokens genuinely imply the selected source regularity
class?
\end{stress}

\begin{proof}
Inverse-token and cocycle-token checks remain algebraic unless a further
certificate connects them to the selected source regularity class over the
chosen overlap supports. Thus \(\RegSrc\) survives the stress only when a
finite/local witness supplies a transition-compatibility certificate. The
stress does not upgrade tokens into differentiable transition maps and does
not import target smoothness.
\end{proof}

\begin{stress}[Rank or dimension incoherence]
Can source-chart support produce inconsistent local rank or dimension
analogues across overlaps?
\end{stress}

\begin{proof}
Rank coherence is not automatic from chart names or transition-token syntax.
A witness must supply a source rank analogue and show that it is stable on the
listed overlaps, or it must define an equivalence class that controls the
variation. If incompatible local ranks remain, \(\BottomSrc\) returns
\(\Bot\). The stress therefore permits finite/local witness construction but
not global rank adoption.
\end{proof}

\begin{stress}[Soldering nonuniqueness]
Can the same \(\RespLC\) token solder to multiple incompatible source-chart
supports?
\end{stress}

\begin{proof}
\(\SolderSrc\) treats \(\RespLC\) readouts as source syntax. The stress branch
is nonuniqueness: a single readout token may attach to multiple supports. The
law survives only if a source equivalence relation identifies those supports
as admissibly equivalent, or if the ambiguity returns \(\Bot\). No target
metric, proper time, empirical detector semantics, or observer protocol may
break the tie.
\end{proof}

\begin{stress}[Finite-variation fragility]
Does \(\VarRegSrc\) preserve the required structures under admissible finite
variations, or only under the original candidate-local variation family?
\end{stress}

\begin{proof}
\(\VarRegSrc\) is an obligation class, not a proof of arbitrary robustness.
For a finite/local witness, the allowed variation family can be listed and
the preservation of \(\SepSrc\), \(\TopRegSrc\), \(\RegSrc\), and
\(\SolderSrc\) can be checked case by case. This survives as bounded
source-extension scaffolding. It does not discharge arbitrary finite-variation
robustness.
\end{proof}

\section{Finite/Local Stress-Survival Lemma}

\begin{lemma}[Finite/local RegSold stress survival]
Suppose a finite or local witness supplies explicit source data for
\(\SepSrc\), \(\TopRegSrc\), \(\ChartSuppSrc\), \(\RegSrc\), \(\SolderSrc\),
\(\VarRegSrc\), and \(\BottomSrc\). Suppose further that every ambiguous,
nonunique, unsupported, target-importing, or process-authority branch returns
\(\Bot\). Then \(\RegSold\) survives the nine stress tests as proposal-only
finite/local source-extension scaffolding.
\end{lemma}

\begin{proof}
Each stress branch either demands explicit source-side witness data or a
fail-closed bottom result. In the finite/local case, the witness can list the
tokens, quotient classes, support regions, transition tokens, overlap
certificates, rank analogue, soldering equivalence relation, and bounded
variation family directly. If all listed branches are source-side and all
unsupported branches bottom out, no target structure or process authority is
needed. The conclusion is bounded to the listed witness domain.
\end{proof}

\begin{guard}[Bounded scope]
The lemma does not prove arbitrary finite-variation robustness, does not prove
that non-bottom witnesses exist generally, and does not adopt \(\RegSold\) or
\(\Msrc\).
\end{guard}
