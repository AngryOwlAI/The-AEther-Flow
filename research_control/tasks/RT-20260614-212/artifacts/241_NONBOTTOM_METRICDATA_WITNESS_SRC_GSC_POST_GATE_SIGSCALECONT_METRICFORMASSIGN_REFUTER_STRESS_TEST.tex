\section{Stress Lemmas}

\begin{lemma}[Presentation-indexed metric-form survival]
Under form-token and pairing-syntax nonuniqueness, \(\MetricFormAssign\)
survives only as presentation-indexed source-extension data. If a unique
unmarked target metric form or interval syntax is demanded without explicit
source-side record tokens, the candidate returns \(\BottomSrc\).
\end{lemma}

\begin{proof}
The proposal admits \(\FormTok\) and \(\PairTok\) only as source-side record
data. Distinct supplied tokens therefore define distinct marked source
presentations or declared equivalence classes. A demand for a unique unmarked
metric form or interval syntax asks the candidate to import content from
outside the source-side token record. That violates the domain condition for
the non-bottom branch, so the fail-closed branch returns \(\BottomSrc\).
\end{proof}

\begin{lemma}[Nondegeneracy and transition-coherence stress lemma]
\(\MetricFormAssign\) survives nondegeneracy, inverse, and cocycle stress only
when the relevant certificates and transports are supplied as source-side
data. Target-repaired or process-repaired certificates and transports return
\(\BottomSrc\).
\end{lemma}

\begin{proof}
The audited candidate makes source-side nondegeneracy or controlled-bottom
certification and preservation by admitted source transitions part of the
non-bottom branch. If inverse or cocycle behavior fails, metric-form record
data are not preserved as source-side data. If repair uses target atlas
structure, target metric structure, proper time, benchmark behavior,
validator success, role authority, handoff state, generated derivatives,
local cache state, file order, or commit status, the repair is not source-side
data. In either case the non-bottom branch is unavailable and the candidate
returns \(\BottomSrc\).
\end{proof}
