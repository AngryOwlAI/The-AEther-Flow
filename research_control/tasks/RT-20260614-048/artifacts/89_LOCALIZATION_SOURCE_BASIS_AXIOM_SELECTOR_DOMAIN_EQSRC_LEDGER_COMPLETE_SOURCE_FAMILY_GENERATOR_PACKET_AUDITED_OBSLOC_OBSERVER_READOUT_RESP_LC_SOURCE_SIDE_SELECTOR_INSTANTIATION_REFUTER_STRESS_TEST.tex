\section{Counterpressure Results}

\begin{stressfinding}[The finite label set does not select response orientation]
The finite set \(U_X=\{a_0,a_1,a_2\}\) supplies source labels and pair
indices. It does not contain an oriented causal relation, signed
interval form, time orientation, clock direction, or invariant rule
selecting response sign. Choosing a sign from notation, listing order,
or intended physical reading would add convention external to the
retained tuple.
\end{stressfinding}

\begin{stressfinding}[The normal-orbit token does not supply \(o^R_X\)]
The datum \([n]_{U_X}\) is retained as an orbit token. It records a
class, not a chosen signed representative. Reading it as a physical
observer normal, local inertial frame, time arrow, or metric
orientation would import target observer or target metric structure.
Thus \(o^R_X\) is not instantiated.
\end{stressfinding}

\begin{stressfinding}[The readout syntax does not supply \(\nu^R_X\)]
The readout
\[
    \Phi_{U_X}=\ReadLC(X_{\mathrm{loc}})|_{U_X}
\]
is source syntax. It is not a detector output, calibrated response,
target coordinate, proper-time reading, or fitted metric scale.
Differences in \(\Phi_{U_X}\) may name a burden, but the tracked
artifacts do not define a positive response unit or normalization.
Thus \(\nu^R_X\) is not instantiated.
\end{stressfinding}

\begin{stressfinding}[The readout syntax does not supply \(\kappa^R_X\)]
No tracked source rule distinguishes response-token identity from
token relabeling. Assigning detector class, matter species,
stress-energy response, or empirical meaning to a token would import
matter coupling. Thus \(\kappa^R_X\) is not instantiated.
\end{stressfinding}

\begin{stressfinding}[Exact transports do not select response components]
The transports \(T^n\) and \(T^\Phi\) preserve exact-branch
certificate syntax. They do not define sign orientation, positive
response scale, response-token identity, metric response covariance,
or finite-variation robustness beyond the exact branch.
\end{stressfinding}

\begin{stressfinding}[No source-side theorem fills the gap]
The source-side irrelevance route was tested in \texttt{RT-20260614-045}
and returned a quotient-burden obstruction for current data. The
selector contract in \texttt{RT-20260614-046} is conditional. The
audit in \texttt{RT-20260614-047} preserves the contract boundary but
does not provide a witness. Therefore no already-tracked theorem or
artifact instantiates the selector.
\end{stressfinding}
