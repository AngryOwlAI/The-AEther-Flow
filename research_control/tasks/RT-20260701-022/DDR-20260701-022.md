# DDR-20260701-022: V13 P5-T01 RR_E Theorem Target Formalizer

## Decision

Select `ontology-formalizer@0.2.0` as a task overlay for one bounded v13
P5-T01 `RR_E` theorem-target formalization packet.

## Basis

The latest tracked handoff `handoff-0430` requires one bounded P5-T01 packet
before any matter-semantics, detector-semantics, coupling-law,
matter-coupling, stress-energy, matter-action, Einstein-equation, benchmark,
or promotion route.

The v13 plan classifies P5-T01 as an
`ontology_law_research_packet_rr_e_theorem_target` physics task. The immediate
output is not theorem proof and not adoption. It is a source-side theorem
target: define what an `RR_E` record is, what separation preservation means,
what source-side irrelevance would require, which assumptions are allowed,
which assumptions would smuggle detector semantics, which finite/local
examples distinguish separation from irrelevance, and what obstruction label
applies when irrelevance is underdetermined.

## Selected Role

Reasoning: the packet needs formal objects, assumptions, forbidden imports, a
fail-closed obstruction family, and theorem-target proof obligations. The role
can create science-draft TeX and control receipts but cannot edit canonical
ontology or promote claims.

process-authority imports; give finite/local examples distinguishing

fail-closed label; route to P5-T02.
