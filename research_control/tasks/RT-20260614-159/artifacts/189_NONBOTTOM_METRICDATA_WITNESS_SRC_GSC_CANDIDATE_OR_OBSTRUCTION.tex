\section{Transition-Covariance Argument}\label{transition-covariance-argument}

\begin{lemma}[Source transition covariance]
Let \(\tau:S_{\Ezero}\to S_{\Ezero}\) be an admitted source transition token,
that is, a finite relabeling isomorphism preserving directed response
incidence and the marked chain class. Then
\[
  \MetricTokenVal(\tau X_0)=\tau\MetricTokenVal(X_0)
\]
as source-gauge classes.
\end{lemma}

\begin{proof}
The oriented chain class is invariant by definition of the admitted
transition tokens. The counting-measure class is invariant under bijection of
the finite site set. The reachability preorder is preserved because directed
response incidence and composition are preserved. Response-profile
distinguishability is preserved because incoming and outgoing reachability
counts are relabeled with the sites. The finite-variation rule is stated over
the chain class and equivalent source response tokens, so it is carried to an
equivalent rule under relabeling. Therefore every component of
\(\MetricTokenVal(X_0)\) is preserved up to source gauge.
\end{proof}
