\section{Repaired Source Signature}

\begin{definition}[Finite repaired basis]
Let \(\mathcal V_{\mathrm{rep}}(C;E,\Bcur)\) be the finite family generated
from an admissible record \(C=(S_E,P_E,R_E,Q_E,\Gamma_E)\in\MSAdm(E;\Bcur)\)
by the stress variations explicitly named in RT-040: finite support-token
variation, finite probe-token variation, certificate deletion, and sector
deletion. The basis is source syntax only. It includes no target metric,
detector protocol, stress-energy tensor, matter action, benchmark behavior,
or Einstein-equation premise.
\end{definition}

\begin{definition}[Stable core]
The stable core
\[
  \mathrm{Core}_E(C)=
  \bigl(S_E^{\mathrm{core}},P_E^{\mathrm{core}},
  \Gamma_E^{\mathrm{core}},U_E^{\mathrm{core}}\bigr)
\]
is the intersection of support tokens, probe tokens, no-target certificate
classes, and sector labels that remain required across
\(\mathcal V_{\mathrm{rep}}(C;E,\Bcur)\). If this finite intersection cannot
be formed from source data alone, the repair map returns \(\bot\). The
certificate core must contain the source-side classes witnessing
\(\NoDetector(E)\), \(\NoSE(E)\), \(\NoAction(E)\), and \(\NoTarget(E)\).
\end{definition}

\begin{definition}[Readout-response syntax coordinate]
\[
  \mathrm{RR}_E(C)=(R_E,Q_E)/{\equiv_{\mathrm{src}}}
\]
is the source-syntax equivalence class of the readout map and response-marker
family under explicit source relabelings already present in the current
basis. It is not detector semantics, not stress-energy semantics, not a matter
action, and not a target-side interpretation of a measurement.
\end{definition}

\begin{definition}[Repair signature]
The repaired signature is
\[
  \MSSig(C)=
  \bigl(\mathrm{Core}_E(C),\mathrm{RR}_E(C),
  \mathrm{AdmFlag}_E(C)\bigr),
\]
where \(\mathrm{AdmFlag}_E(C)\) records whether all required no-target
certificates and current-basis admissibility guards are present. If
\(\mathrm{AdmFlag}_E(C)=0\), define \(\MSSig(C)=\bot\).
\end{definition}

\begin{definition}[Stable repair relation and projection]
For \(C_1,C_2\in\MSAdm(E;\Bcur)\), define
\[
  C_1\mathrel{\MSRepEq} C_2
  \quad\Longleftrightarrow\quad
  \MSSig(C_1)=\MSSig(C_2)\neq\bot.
\]
The repaired projection is
\[
  \MSRepProj:\MSAdm(E;\Bcur)\to
  \MSAdm(E;\Bcur)/{\MSRepEq}\cup\{\bot\},
\]
sending nonbottom records to their \(\MSRepEq\)-class and all records with
\(\MSSig=\bot\) to \(\bot\). Define the repaired discriminator as
\[
  \MSRepDisc(C)=
  \begin{cases}
    \bigl(\MSRepProj(C),\mathrm{RR}_E(C)\bigr), & \MSSig(C)\neq\bot,\\
    \bot, & \MSSig(C)=\bot.
  \end{cases}
\]
The pair
\[
  \MSStableRepair(E;\Bcur)=
  \bigl(\MSSig,\MSRepEq,\MSRepProj,\MSRepDisc\bigr)
\]
is the constructed repair candidate. The name
\(\MSIrrelRepair\) denotes this same proposal-only repaired quotient family
when considered as a response to the \(\mathrm{MSSemanticsQuotient}_{v1}\)
target.
\end{definition}

\section{Repair Checks}

\begin{proposition}[Uniqueness of the repaired relation]
\(\MSRepEq\) is uniquely determined by \(\MSSig\) on the finite repaired
basis.
\end{proposition}

\paragraph{Reason.}
The relation is equality of a fixed source-side signature. The previous
identity relation, certificate-fiber relation, and all-fiber collapse are no
longer competing choices because the repair packet explicitly names the
signature map that selects the relation. This is a proposal-only construction,
not a proof that the current canonical ontology derives the signature as an
adopted law.

\begin{proposition}[Finite-variation robustness]
Finite variations that preserve \(\mathrm{Core}_E(C)\), required certificates,
sector core, and \(\mathrm{RR}_E(C)\) preserve the repaired class. Variations
that change one of those source-side coordinates either move to a different
nonbottom class or return \(\bot\).
\end{proposition}

\paragraph{Reason.}
The repaired projection factors through \(\MSSig\). Preserving the signature
preserves the quotient class by definition. Changing a signature coordinate
does not cause arbitrary middle-collapse drift: it either selects a different
class or fails closed if admissibility or core formation is lost.

\begin{proposition}[Certificate-deletion stability]
Deleting non-core certificate redundancies leaves the repaired class
unchanged. Deleting any core no-target certificate sends the repaired
signature to \(\bot\).
\end{proposition}

\paragraph{Reason.}
Only \(\Gamma_E^{\mathrm{core}}\) enters \(\MSSig\). Redundant certificates
outside the core are ignored by the repaired signature. Core certificate
deletion violates \(\mathrm{AdmFlag}_E(C)=1\) and fails closed. Thus the
repair gives a stable source-side deletion rule rather than silently changing
the quotient.

\begin{proposition}[Sector-deletion invariance on retained core sectors]
For a source-side sector restriction \(\rho_U\), if
\(U_E^{\mathrm{core}}\subseteq U\), then restricting before or after
\(\MSRepProj\) gives the same repaired class. If the sector deletion removes
part of \(U_E^{\mathrm{core}}\), the result is \(\bot\).
\end{proposition}

\paragraph{Reason.}
The sector coordinate of \(\MSSig\) is the retained source core
\(U_E^{\mathrm{core}}\). Deleting sectors outside that core does not alter the
signature. Deleting the core invalidates the repaired admissibility guard and
fails closed.

\begin{proposition}[Nondegeneracy on the pressure pair]
For the RT-035 pressure pair \(C_+\) and \(C_-\),
\[
  \mathrm{RR}_E(C_+)\neq\mathrm{RR}_E(C_-)
  \quad\Longrightarrow\quad
  C_+\not\mathrel{\MSRepEq}C_-.
\]
\end{proposition}

\paragraph{Reason.}
RT-037 records that \(C_+\) and \(C_-\) share support, probe-token family, and
no-target certificates but differ in readout map and response-marker syntax.
Because \(\mathrm{RR}_E\) is part of \(\MSSig\), the repaired projection does
not erase the source distinction. This repairs the RT-040 degeneracy failure
but also means the candidate does not prove readout/response irrelevance for
the pressure pair.

\section{Interpretation of the Constructed Candidate}

The constructed object is a stable, nondegenerate proposal-only quotient
repair candidate. It addresses the five RT-040 failure modes as follows:
\begin{enumerate}
  \item collapse nonuniqueness is controlled by a named source-side signature;
  \item finite-variation fragility is replaced by signature preservation,
    class change, or fail-closed behavior;
  \item certificate deletion has an explicit core versus non-core rule;
  \item sector deletion has an explicit retained-core restriction rule;
  \item quotient degeneracy is avoided by retaining source
    readout-response syntax in the repaired signature.
\end{enumerate}

This gain has a precise limitation. The repaired candidate does not collapse
\(C_+\) and \(C_-\). It therefore repairs the quotient as a stable
discriminator-like source-side partition, not as an adopted irrelevance law.
The current ontology still does not derive a general source-side theorem that
readout and response-marker differences are irrelevant to matter semantics.
