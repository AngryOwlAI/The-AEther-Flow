\section{Audit Lemmas}

\begin{lemma}[No target-atlas import in the finite witness as written]
Under the written source-symbol reading of \(\Wfin\), the positive finite
branch uses only finite source carriers, declared source discriminator
profiles, source-token candidate transitions, a source selector preorder,
finite inverse checks, finite cocycle checks, and a finite source quotient.
It does not use target topology, target smooth atlas data, target coordinate
transitions, metric scale, proper time, empirical calibration, benchmark
behavior, validation receipts, generated derivatives, or role labels.
\end{lemma}

\begin{proof}
Each profile value is a finite source tuple. Candidate transitions are maps
between finite source carriers. The selector score is defined from source-token
comparisons and finite check defects. The inverse and cocycle equations are
finite token equalities. The quotient support is generated from selected
source transition pairs. No step calls target open sets, target coordinate
maps, differentiability, metric tensors, interval scale, proper-time
functionals, empirical calibration, benchmark solutions, validation receipts,
generated notes, or role labels. Therefore the finite witness avoids
target-atlas import under the stated dependency reading.
\end{proof}

\begin{lemma}[Supplied-data authority guard]
\(\Wfin\) remains source-pure only if the discriminator profiles, selector
preorders, inverse data, and cocycle data are explicit supplied source data.
If those data are inferred from target geometry, benchmark behavior,
validation status, registry status, role authority, generated derivatives, or
the bare label ``source'', the witness fails this audit.
\end{lemma}

\begin{proof}
The finite witness constructs a positive branch relative to the supplied
finite data. It does not derive \(\Prof\), \(\Sel\), inverse compatibility, or
cocycle compatibility from the current canonical ontology. Replacing explicit
source inputs with process authority changes the dependency basis. Replacing
them with target or benchmark structure imports forbidden structure. Hence
source-purity requires explicit source-side inputs, and absence or
underdetermination must route to \(\Bot\).
\end{proof}

\begin{lemma}[Finite-source overread guard]
A conditionally source-pure finite witness does not imply general
\(\AtlasGlueDisc\) adoption, \(\AtlasGlue\) adoption, full \(\Msrc\)
construction, or arbitrary finite-variation robustness.
\end{lemma}

\begin{proof}
\(\Wfin\) has three finite patches, two tokens per patch, declared profile
values, declared candidate transitions, and explicit finite checks. General
\(\Msrc\) would require source-authorized coverage, overlap recognition,
transition selection, inverse compatibility, cocycle compatibility, and
finite-variation robustness beyond this supplied finite datum. The finite
positive branch therefore supplies bridge-facing draft/control evidence only;
it is not a general atlas-gluing theorem.
\end{proof}
