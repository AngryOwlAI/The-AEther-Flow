# Director Decision Record: DDR-20260630-029

## Decision

Select `validator-engineer@0.2.0` for one bounded P6-T03 finite/local
source-side witness schema skeleton formalization packet.

## Basis

`handoff-0380` requires one P6-T03 packet to formalize the finite/local
source-side witness schema skeleton, including the finite source index graph,
sector assignment, source token assignment, relabeling map, restriction map,
bridge-slot compatibility predicate, no-target-import certificate predicate,
fail-closed bottom label, and support-only pass/fail report type.

The P6-T03 output is deterministic support tooling and tests. It is not a
canonical science-source edit and does not adopt a source law, `MetricData(E)`,
`g_eff`, matter coupling, stress-energy semantics, Einstein equations,
benchmark status, or a completed derivation claim. Validator Engineer is
therefore the narrowest role fit.

## Scope

Allowed:

- Implement a standard-library Python finite/local witness schema skeleton.
- Add deterministic focused tests for graph, sector, token, relabeling,
  restriction, no-target-import, bridge-slot, and fail-closed invariants.
- Emit a task-local support-only JSON report and traceability artifact.
- Update control registries, program state, handoff, documentation-impact, and
  generated derivatives.

Blocked:

- canonical ontology edit
- canonical-ontology candidate status
- source-law adoption
- source-extension data adoption beyond exact scoped gate result
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- detector semantics
- matter action
- Einstein equations
- benchmark promotion
- completed derivation
- support-only formalization as proof authority
- future source-extension impossibility
- global theory rejection
- P6-T04 traceability registry implementation in this packet
