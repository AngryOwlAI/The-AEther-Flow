# DDR-20260619-009: Post-Migration Phase 6 Full Corpus QA

## Decision

Route one bounded Documentation Curator AgentJob to implement Phase 6 of
`research_control/design/documentation_curator_post_migration_quality_plan.md`.

## Rationale

The user explicitly approved Phase 6 after Phase 5 completed the overview and
source-authority footer/coherence rewrite. Phase 6 is a closure packet: it
verifies the 17 reviewed publication page stacks, refreshes publication-registry
evidence paths to a final full-corpus QA artifact, captures desktop and mobile
screenshots for each tracked HTML page, runs bootstrap regeneration for
memory/wiki/registry derivatives, and checkpoints the transaction.

The primary role remains Documentation Curator because the packet validates and
publishes evidence for existing public documentation surfaces. It does not
change contracts, validators, schemas, role authority, routing behavior,
checkpoint behavior, dependencies, or scientific source status.

## Claim Boundary

This decision authorizes publication-brief registry evidence refresh,
full-corpus screenshot QA, full-corpus review evidence, generated memory/wiki
refresh, documentation-impact receipt, and control registry rows for the
post-migration quality closure packet. It does not authorize canonical ontology
edits, benchmark promotion, Gate Chair verdicts, science draft execution,
physics claim promotion, schema edits, role registration, routing changes,
validator behavior changes, checkpoint changes, dependency changes,
generated-output authority, direct HTML-only page rewrites, or optional/deferred
publication-surface migration.
