# Director Decision Record: DDR-20260614-276

## Decision

Select `validator-engineer@0.2.0` for one bounded P6-T02 metrics
implementation packet.

## Basis

`handoff-0308` requires one P6-T02 packet to implement the P6-T01
payload-density and route-orbit diagnostics in
`scripts/research_control/report_physics_progress_metrics.py` with focused
tests. The P6-T01 design explicitly keeps diagnostics operational,
warning-only, and outside `scientific_progress_metrics`.

The selected role is project-system validation/tooling. This packet has no
physics milestone and cannot promote workflow metrics into physics evidence.

## Scope

Allowed:

- Implement `payload_density_metrics`.
- Implement `route_orbit_risk_metrics`.
- Implement advisory `diagnostic_warnings`.
- Add focused tests in `tests/test_research_control.py`.
- Preserve JSON output and extend Markdown output with compact diagnostic
  sections.
- Update control registries, task records, documentation-impact receipt,
  `program_state.yaml`, and `handoff-0309`.

Blocked:

- canonical ontology edit
- source-law adoption
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- matter action
- detector semantics
- Einstein equations
- benchmark promotion
- completed derivation
- diagnostic warning as hard gate
- workflow metrics as physics evidence
- Distance-to-GR ledger change
- `continue_research.py` warning surfacing
- Gate Chair verdict or protected evidence-status change

## Role-Fit Matrix

| Candidate role | Decision | Reason |
| --- | --- | --- |
| Validator Engineer | Selected | P6-T02 is deterministic metrics tooling plus focused tests. |
| Project-Control Maintainer | Not selected | P6-T01 already produced the design artifact; P6-T02 edits the metrics script. |
| Documentation Curator | Not selected | No public explanatory surface or source-backed documentation packet is needed. |
| Gate Chair | Not selected | The packet cannot decide evidence status or adoption. |
| Physics roles | Not selected | The packet has no physics milestone and no scientific payload. |

## Result

The selected packet implements payload-density metrics, route-orbit risk
metrics, and advisory diagnostic warnings in the metrics reporter while keeping
all operational diagnostics outside `scientific_progress_metrics`.
