# Director Decision Record: DDR-20260614-277

## Decision

Select `validator-engineer@0.2.0` for one bounded P6-T03 routing-support
packet.

## Basis

`handoff-0309` requires one P6-T03 packet to surface payload-density and
route-orbit warnings in `scripts/research_control/continue_research.py`
context packets. The P6-T03 plan requires the Director to see warnings before
routing, while preserving the rule that warnings do not automatically block a
valid human-gated Gate Chair route.

The selected role is project-system validation/tooling. This packet has no
physics milestone and cannot promote operational diagnostics into physics
evidence.

## Scope

Allowed:

- Add advisory warning fields to the Continue Research context packet:
  `payload_density_warning`, `route_orbit_warning`,
  `same_burden_repetition_warning`, `gate_ready_without_gate_warning`, and
  `recommended_guard_action`.
- Use `report_physics_progress_metrics.py` as the diagnostic source.
- Add focused tests proving warnings remain advisory and Gate Chair route
  availability is not removed.
- Update control registries, task records, documentation-impact receipt,
  `program_state.yaml`, and `handoff-0310`.

Blocked:

- canonical ontology edit
- source-law adoption
- `MetricData(E)` adoption
- `g_eff` adoption or scope expansion
- coupling-law adoption
- matter-coupling derivation or adoption
- stress-energy semantics
- stress-energy tensor
- matter action
- detector semantics
- Einstein equations
- benchmark promotion
- completed derivation
- diagnostic warning as hard gate
- workflow metrics as physics evidence
- Distance-to-GR ledger change
- `report_physics_progress_metrics.py` modification in this packet
- Gate Chair verdict or protected evidence-status change

## Result

The selected packet surfaces existing payload-density and route-orbit
diagnostics in the Director context packet while keeping warnings advisory,
nonblocking, and non-promotional.
