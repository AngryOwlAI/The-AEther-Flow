\section{Selector-Contract Theorem}

\begin{lemma}[Selector components break the quotient action]
If \(\SelResp(S_X)\) satisfies the admissibility conditions, then the
sign reversal, positive rescaling, and response-token relabeling action
from the prior quotient packet is no longer a free source-invisible
action on selector-instantiated representatives.
\end{lemma}

\begin{proof}
The prior action was source-invisible because the retained tuple
contained no field that selected sign, scale, or response-token
meaning. Under the present hypothesis, \(o^R_X\) selects sign
orientation, \(\nu^R_X\) selects positive normalization, and
\(\kappa^R_X\) selects response-token semantics from source-side
structure. A sign reversal changes the selected \(o^R_X\) class, a
positive rescaling changes the selected \(\nu^R_X\) normalization, and
a token relabeling changes the selected \(\kappa^R_X\) identity
criteria unless it is an allowed source-token automorphism preserving
\(\kappa^R_X\). Therefore those transformations are no longer free
symmetries of selector-instantiated response representatives.
\end{proof}

level. The discharge is conditional and does not by itself supply
\(\RespLC\), \(\Msrc\), \(\geff\), matter coupling, or Einstein

\begin{proof}

This proves only a conditional representative-choice result. The

\end{proof}
