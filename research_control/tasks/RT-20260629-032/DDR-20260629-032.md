# Director Decision Record: DDR-20260629-032

## Decision

Select `project-control-maintainer@0.2.0` for one bounded v12 P1-T01
Distance-to-GR layered status taxonomy design packet.

## Basis

`research_control/program_state.yaml` names `RT-20260629-031` and
`handoff-0326`. The latest handoff routes exactly one P1-T01 packet: design a
layered status taxonomy for the Distance-to-GR ledger without changing
scientific meaning.

The current ledger uses flat `current_status` values. Rows such as `g_eff` and
`matter_coupling` can therefore appear to carry physical promotion unless the
reader also consumes the blocking-burden and evidence notes. P1-T01 is a
schema-design and validator-contract task, not a physics packet and not a CSV
migration.

## Scope

Allowed:

- Create `research_control/design/distance_to_gr_status_layers_v1.md`.
- Describe proposed additive ledger columns, controlled vocabulary, row mapping,
  migration plan, and validator requirements.
- Create the P1-T01 task packet, role overlay, AgentJob, completion receipt,
  documentation-impact receipt, claim-boundary row, and handoff.
- Update `program_state.yaml`, the current-frontier snapshot, generated memory
  metadata, generated dependency graph, and control registries as required by
  validation and checkpoint.

Blocked:

- editing `registries/DISTANCE_TO_GR_LEDGER.csv` in P1-T01;
- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
- unscoped `g_eff` adoption;
- `g_eff` scope expansion;
- coupling-law adoption;
- matter-coupling derivation or adoption;
- stress-energy semantics;
- stress-energy tensor;
- matter action;
- detector semantics;
- Einstein equations;
- exact-GR benchmark promotion;
- benchmark Gate Chair closure;
- completed derivation;
- treating the design artifact, implementation plan, handoff, generated wiki
  note, semantic extract, Obsidian note, local cache, validator output, graph,
  checker, or commit as scientific proof.

## Role-Fit Matrix

| Candidate role | Fit judgment | Reason |
| --- | --- | --- |
| `project-control-maintainer@0.2.0` | selected | The task designs a control/schema contract and validator requirements. |
| `process-integrity-auditor@0.1.0` | acceptable but not selected | The task has process-integrity consequences, but the primary output is a schema design artifact. |
| Physics roles | not selected | The packet has no derivation milestone and must not create a physics payload. |

## Result

The selected AgentJob produced an additive layered status design that maps all
current ledger rows while preserving their scientific meaning and routing the
implementation to P1-T02.
