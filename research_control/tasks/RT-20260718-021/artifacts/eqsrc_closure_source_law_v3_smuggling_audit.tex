\section{Congruence and Acceptance Audit}

\begin{lemma}[Certificate-acceptance congruence]
For \(w,w'\in\Cert(A,B)\), if
\(w\equiv_{\Cert}^{A,B}w'\), then
\[
 \Accept_{A,B}(w)=\Accept_{A,B}(w').
\]
The constructors \(\mathsf{Inv}\) and \(\mathsf{Comp}\) preserve
certificate congruence on their displayed domains.
\end{lemma}

\begin{proof}
Certificate congruence is the conjunction of ledger, proxy, and provenance
component congruence. The ledger and proxy decisions respect their component
relations. Each \(\delta_{n,A,B}\) sends certificate-congruent inputs to
\(\equiv_n\)-equivalent outcomes, and each pass set
\(\mathcal O_n^{\Pass}\) is saturated. Every conjunct defining \(\Accept\)
therefore has the same Boolean status on \(w\) and \(w'\). The component
identity, inverse, and composition maps respect their congruences, so the
componentwise certificate constructors preserve \(\equiv_{\Cert}\).
\end{proof}

The candidate's component-and-outcome coherence clause is partly redundant:
component agreement is already built into certificate congruence and outcome
agreement follows from decision invariance. Redundancy does not create an
inconsistency and leaves the full law's substantive unit, inverse, and
associativity obligations intact.

\begin{remark}[Typed fail closure]
The displayed function
\(\Accept_{A,B}:\Cert(A,B)\to\{\Pass,\Block\}\) is total on its typed domain.
An ill-typed or missing external input is not an element of that domain and
does not literally receive an object-level value unless an ambient error or
option carrier is added. The candidate's sound fail-closed reading is that a
malformed proposed interpretation is rejected as a model of \(\Law\).
\end{remark}

\section{Accepted-Totality and Conditional-Theorem Audit}

\begin{proposition}[Conditional equivalence theorem passes]
For every well-formed structure satisfying \(\Law\), the relation
\[
 A\sim_{\mathrm{cand},v3}B
 \quad\Longleftrightarrow\quad
 \exists w\in\Cert(A,B)\quad\Accept_{A,B}(w)=\Pass
\]
is an equivalence relation.
\end{proposition}

\begin{proof}
Accepted identity totality supplies an accepted
\(\mathbf 1_A:A\to A\), proving reflexivity. Accepted inverse totality maps
each accepted \(w:A\to B\) to an accepted
\(\mathsf{Inv}(w):B\to A\), proving symmetry. Accepted composition totality
maps accepted \(w:A\to B\) and \(v:B\to C\) to an accepted
\(\mathsf{Comp}(v,w):A\to C\), proving transitivity.
\end{proof}

This proof uses the three accepted-totality clauses. The full coherence law is
strictly stronger, as shown below. More importantly, the proposition assumes a
structure satisfying \(\Law\); it does not derive the component decisions or
accepted-totality clauses from current ontology.

\section{Semantic Source-Factorization Audit}

\begin{definition}[Source-factorization criterion]
Let \(\Omega\) be a set of ambient interpretations containing source, target,
and workflow coordinates, let \(S\) be the tuple space of declared source
roots, and let
\(\pi_{\mathrm{src}}:\Omega\to S\) forget all non-source coordinates. A map
\(F:\Omega\to Y\) is source-factorized when there is a map
\(\bar F:S\to Y\) such that
\[
 F=\bar F\circ\pi_{\mathrm{src}}.
\]
When \(\pi_{\mathrm{src}}\) is surjective, this is equivalent to \(F\) being
constant on every fiber of \(\pi_{\mathrm{src}}\).
\end{definition}

\begin{lemma}[Acyclic factorization propagation]
If each root of a finite acyclic definition graph has independently audited
source-only transitive provenance and every internal node is a source
constructor applied only to its predecessors, then every node factors through
\(\pi_{\mathrm{src}}\). Consequently \(\Accept\) and candidate-law
satisfaction are invariant under target or workflow variation with the source
root tuple fixed.
\end{lemma}

\begin{proof}
Order the finite graph topologically. The root maps factor by hypothesis. If
all predecessors of a node factor, composing their factorizations with the
node's declared source constructor gives a factorization for the node.
Induction reaches all rank-0 through rank-2 interpretations. The finite
Boolean conjunction defining \(\Accept\) and the rank-4 law clauses are
functions of those factorized values, so they factor as well.
\end{proof}

The candidate states both halves needed by this lemma: a finite acyclic
definition tree and transitive classification of roots and aliases. The
second half is essential. A target-derived hash, lookup value, learned
parameter, or opaque-oracle result could otherwise be frozen and renamed a
source primitive, making simple counterfactual invariance vacuous. Version 3
explicitly classifies these channels by transitive provenance and blocks
opaque, target-derived, or process-derived roots.

This is a pass for the proposal's semantic admissibility condition. It is not
a concrete source-purity theorem for current ontology because the packet
supplies no actual rank-0 through rank-2 definition trees or physical
interpretation.

\section{Minimal Mathematical Witnesses}

\begin{proposition}[One-object source-only consistency witness]
The proposal has an abstract one-object model.
\end{proposition}

\begin{proof}
Take \(\mathcal F_{\mathrm{src}}=\{A\}\). Let the ledger and proxy fibers and
every outcome carrier be singletons, let
\(\mathcal N_{\mathrm{src}}\) be one singleton index set, and let the unique
outcome be in its saturated pass set. Take no primitive provenance leaves.
The provenance terms generated from \(\mathsf{id}[A]\), inverse, and
composition are congruent to \(\mathsf{id}[A]\) under the constructor
equations. Use the unique component constructors and equivalences, and make
all component decisions return \(\Pass\). Every certificate constructor,
accepted-totality clause, congruence condition, and coherence equation then
holds.
\end{proof}

This proves formal consistency and non-vacuity only. The model is degenerate
and is neither a physical realization nor a current-ontology interpretation.

\begin{proposition}[Coarse equivalence does not imply the full law]
The induced object relation can be an equivalence while the full unit
compatibility clause fails.
\end{proposition}

\begin{proof}
Use one source object and a ledger
\(\Lambda(A,A)=\{e,a\}\) with equality, identity \(e\), identity dagger, and
composition constantly equal to \(e\). Let all other component fibers be
singletons and all certificates be accepted. Accepted identity, inverse, and
composition totality hold, so the one-object relation is an equivalence.
For the certificate whose ledger component is \(a\), however, composition
with the identity certificate has ledger component \(e\), which is not
congruent to \(a\). Unit compatibility fails, so the structure is not a model
of the full \(\Law\).
\end{proof}

The witness confirms that the conditional relation proof is correct without
collapsing the law's stronger coherence assumptions into a theorem.
