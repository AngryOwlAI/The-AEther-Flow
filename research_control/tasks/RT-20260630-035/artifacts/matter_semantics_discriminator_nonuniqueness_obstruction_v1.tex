\section{Failure Of Current-Basis Uniqueness}

\paragraph{No source-equivalence proof.}
The current basis contains no source-side theorem proving
\[
  C_+ \equiv_{\mathrm{MS},E_{\pm}} C_-.
\]
The two records have different source readout values and different response
markers.  Treating them as equivalent would require an additional rule saying
which readout-token differences are irrelevant for matter-semantics
bookkeeping.  Treating one as selected would require an additional rule saying
which source readout-token semantics is coupling-law relevant.  Neither rule
is present in \(B_{\mathrm{cur}}\).

\paragraph{No lawful non-bottom selector.}
A non-bottom discriminator \(D_E\) that selects \(C_+\) over \(C_-\), selects
\(C_-\) over \(C_+\), or collapses both into one non-bottom label must use one
of the following:

  \mathrm{MSResponseSemanticsLaw}_{v1},\quad
  \mathrm{MSSemanticsQuotient}_{v1},

or an equivalent source-side primitive.  The current ontology does not derive
any of these primitives.  Importing stress-energy semantics, detector
protocols, matter-action dynamics, target metric/proper-time normalization,
benchmark behavior, or Einstein-equation premises would violate the
RT-034 discriminator target.
