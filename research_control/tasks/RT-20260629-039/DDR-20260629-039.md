# Director Decision Record: DDR-20260629-039

## Decision

Execute P2-T03 as one bounded Project-Control Maintainer task overlay.

The job populates `research_control/design/frontier_theorem_inventory.md` using
the registered schema at
`research_control/design/frontier_theorem_inventory_schema_v1.md`. The
inventory remains Markdown control/science bridge material. It records existing
source-backed status only and does not create new theorem statements,
canonical definitions, ontology edits, or physics authority.

## Basis

`handoff-0333` requires P2-T03: populate the canonical frontier theorem
inventory with current accepted scoped blocked and frozen frontier items.
P2-T02 already selected and registered the Markdown source location. The next
logical step is therefore population, not another source-location decision.

The active burden is control synthesis over existing sources. Although the
inventory touches physics-bearing artifacts, this packet does not create a new
science theorem, TeX artifact, or Distance-to-GR status change. A physics role
would be appropriate only if this packet needed new mathematical payload or
science-bearing theorem authority.

## Scope

Allowed:

- populate `research_control/design/frontier_theorem_inventory.md`;
- cite registered TeX artifacts, registered Markdown control sources, and
  registry rows as source authority;
- record at least 15 current frontier items;
- include explicit physical non-conclusions and overread guards;
- refresh generated retrieval, current-frontier, and graph layers;
- create normal task, role, AgentJob, completion, documentation-impact,
  claim-boundary, state, and handoff receipts.

- creating new theorem statements;
- editing physics TeX sources;
- editing `registries/DISTANCE_TO_GR_LEDGER.csv`;
- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
