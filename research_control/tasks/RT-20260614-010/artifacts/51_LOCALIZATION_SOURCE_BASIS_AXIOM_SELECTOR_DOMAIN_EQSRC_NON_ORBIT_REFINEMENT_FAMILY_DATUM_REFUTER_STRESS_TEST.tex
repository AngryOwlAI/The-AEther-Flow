\begin{abstract}
This draft/control artifact stress-tests the audited non-orbit
refinement-family datum from tasks \texttt{RT-20260614-007} and
\texttt{RT-20260614-009}. The local positive result survives only inside
the declared decorated finite source-chain domain: \(Y_{1},Y_{2},Y_{3}\)
remain compared by contraction to the same base chain while preserving
boundary anchors, finite order, annotation mass, proxy guards,
forbidden-channel guards, influence order, and no-target-channel
exclusion. The stress test blocks broader use. Branch refinements,
non-chain refinements, annotation-monoid weakening, contraction-only
over-admission, boundary-anchor perturbation, quotient descent,
relation-property extension, and downstream-use pressure all require new
source-side ledgers before any general \(\EqSrc\) claim. \(\RetainH\),
\(\GenH\), candidate reconstruction, canonical ontology edit, benchmark
promotion, Gate Chair review, and completed-derivation language remain
blocked.
\end{abstract}

\section{Scope}

This artifact is the role output for task \texttt{RT-20260614-010}. It
does not construct a new datum and does not audit target import. Those
steps were performed by the Ontology Formalizer and Smuggling Auditor.
The Refuter question is:
\[
    \text{Does the audited local }\EqRef\text{ packet survive pressure
    outside its declared chain-refinement domain?}
\]
The answer is split. The local chain-domain result is retained as
draft/control evidence. Every broader use is blocked unless a later
source-side packet supplies the missing ledgers and passes the ordinary
audit and refutation sequence.

\section{Stress Method}

\begin{stressscreen}[Eight pressure channels]
The Refuter applies eight channels:
\begin{enumerate}
    \item branch refinements, where one internal source event splits
    into incomparable source branches;
    \item non-chain refinements, where the partial order is finite but
    not a chain;
    \item annotation-monoid weakening, where atoms are deleted, merged,
    weighted, or selected by downstream success;
    \item contraction-only over-admission, where many-to-one maps are
    treated as sufficient without domain restrictions;
    \item boundary-anchor perturbation, where input or output carriers
    move or become target-observer-like endpoints;
    \item quotient descent, where representatives are identified before
    blocker state and annotations are proven invariant;
    \item relation-property extension, where reflexivity, symmetry, or
    transitivity is claimed beyond the declared family; and
    \item downstream-use pressure, where the local datum is used for
    \(\RetainH\), \(\GenH\), candidate reconstruction, or promotion.
\end{enumerate}
\end{stressscreen}

\section{Branch and Non-Chain Pressure}

\begin{counterpressure}[Branch refinement is not admitted by the current ledger]
Let \(B\) be a diamond-shaped finite source object with source boundary
anchors \(i,o\) and incomparable internal carriers \(b_{1},b_{2}\):
\[
    i\prec b_{1}\prec o,\qquad i\prec b_{2}\prec o,\qquad
    b_{1}\npreceq b_{2},\quad b_{2}\npreceq b_{1}.
\]
A many-to-one contraction \(B\to Y_{1}\) can collapse both branch
carriers to the internal carrier \(a\), but that fact is not sufficient
for \(\EqRef\). The current datum defines admissibility by chain
refinement, not arbitrary finite partial-order contraction. Therefore
branch use returns \(\Block\) unless a future task supplies a branch
invariant ledger.
\end{counterpressure}

\begin{counterpressure}[Non-chain variation lacks relation-property receipts]
For a general non-chain finite partial order \(P\), the local proof of
transitivity by common contraction to \(Y_{1}\) is no longer enough. One
must prove that the comparison respects incomparable-source structure,
branch multiplicity, influence-edge coverage, blocker state, and
annotation conservation under every admitted comparison. No such
non-chain relation-property ledger is present in the audited packet.
\end{counterpressure}

\section{Annotation and Contraction Pressure}

\begin{counterpressure}[Annotation-monoid weakening blocks broader use]
If annotation atoms are deleted, merged, weighted by later success, or
selected after observing downstream behavior, annotation conservation no
longer functions as source bookkeeping. It becomes a possible target or
candidate-performance proxy. The stress result is \(\Block\) for any
weakened monoid unless a superseding source-only atom ledger proves that
the change is independent of target success.
\end{counterpressure}

\begin{counterpressure}[Contraction-only admission is too weak]
A bare contraction map can erase branch multiplicity, source-order
shape, blocker state, and annotation placement. The audited pass depends
on contraction plus declared chain-domain restrictions plus invariant
preservation. Therefore contraction alone cannot define general
\(\EqSrc\), cannot justify quotienting blocked objects into positive
objects, and cannot support candidate use.
\end{counterpressure}

\section{Boundary and Quotient Pressure}

\begin{counterpressure}[Boundary perturbation blocks the pass]
Moving \(i\) or \(o\), splitting an endpoint, identifying an endpoint
with a target observer protocol, or choosing endpoints because a target
comparison improves changes the source boundary ledger. The current
positive receipt has no proof of boundary-anchor invariance under such
perturbations. These cases return \(\Block\).
\end{counterpressure}

\begin{counterpressure}[Quotient descent is not supplied]
The audited datum does not prove that quotienting by admissible
contraction preserves annotation mass, proxy guard state,
forbidden-channel state, influence coverage, blocker status, and
relation properties for a larger family. A quotient may be defined later,
but it must preserve adverse evidence rather than erase it. Current
quotient descent beyond the declared chain family returns \(\Block\).
\end{counterpressure}

\section{Relation-Property and Downstream-Use Pressure}

\begin{counterpressure}[Relation properties are local]
Reflexivity, symmetry, and transitivity are documented only for the
positive chain family where every object contracts to the same \(Y_{1}\)
and preserves the same invariant ledger. They are not proven for branch
objects, arbitrary non-chain objects, weakened annotation objects,
boundary-perturbed objects, or quotient representatives. General
\(\EqSrc\) therefore remains unproved.
\end{counterpressure}

\begin{counterpressure}[Downstream use fails the boundary test]
No step in the audited local datum supplies \(\RetainH\), \(\GenH\), or
candidate reconstruction. Treating local \(\EqRef\) as a source basis for
those downstream claims would import an unproved extension. The Refuter
result is therefore \(\Block\) for downstream use until a separate
source-family packet proves the required relation properties and passes
smuggling audit and stress testing.
\end{counterpressure}

\begin{verdict}[Local chain-domain retention]
The audited non-orbit refinement-family datum survives this stress test
only as local chain-domain evidence:
\[
    \EqRef\big|_{\ObjRef^{\mathrm{chain}}} \Rightarrow \Pass
    \quad\text{draft/control only.}
\]
This means the positive chain refinements remain useful as a narrow
source-side witness family, not as a general \(\EqSrc\) theorem.

refinements, annotation-monoid weakening, contraction-only admission,

completed-derivation language.
\end{verdict}
