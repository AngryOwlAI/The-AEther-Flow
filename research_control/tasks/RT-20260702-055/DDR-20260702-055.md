# DDR-20260702-055

## Decision

Select `project-control-maintainer@0.2.0` with a one-job task overlay for
`RT-20260702-055`, implementing v15 `P0-T03` only.

## Evidence

- `research_control/program_state.yaml` pointed to `RT-20260702-054` and
  `handoff-0507`.
- `research_control/handoffs/handoff-0507.yaml` required one bounded v15
  `P0-T03` recommendation trace matrix packet before P1, P2, or later v15
  work.
- `implementations_plans/recommendations_implementation_plan_continue_task-v15.md`
  defines `P0-T03` as a machine-checkable trace matrix containing rows for all
  `V15-R01` through `V15-R31`.
- The plan's P0 boundary forbids physics theorem work, ontology edits, and
  claim promotion.

## Scope

The AgentJob may create a task-local CSV trace matrix, ordinary research-control
task files, registry rows, current handoff, generated dependency/frontier
derivatives, and documentation-impact receipts.

The AgentJob must not execute P1 registry audit, P2 theorem work, source-law
adoption, matter-semantics adoption, detector-semantics adoption, coupling-law
adoption, matter-coupling derivation, Einstein-equation work, benchmark
promotion, or completed-derivation claims.

## Rationale

The logical next step is traceability before implementation. A recommendation
matrix lets later packets prove whether each `V15-Rxx` item is implemented,
deferred, superseded, or blocked without reinterpreting the external
recommendation set from memory.

## Role-Fit Matrix

| Role | Fit | Reason |
| --- | --- | --- |
| `project-control-maintainer@0.2.0` | selected | The packet creates project-control traceability records, task-local artifacts, registry rows, and handoff state without changing science claims. |
| `process-integrity-auditor@0.1.0` | not selected | P1-T01 will audit active-state consistency; P0-T03 only builds the trace matrix needed before that audit. |
| `ontology-formalizer@0.2.0` | not selected | No science formalization or theorem packet is authorized in P0-T03. |
| `gate-chair@0.1.0` | not selected | No protected adoption, benchmark, or claim-promotion verdict is requested or permitted. |

## Validation Requirement

The completion must show that:

- all `V15-R01` through `V15-R31` rows exist;
- every row has `physics_promotion_allowed=false`;
- planned or deferred rows name evidence paths;
- validators pass; and
- the handoff routes to P1.
