\section{Stress Lemmas}

\begin{lemma}[Relabeling invariance of missing-law obstruction]
Let \(\rho:T_E(\Bcur)\to T_E(\Bcur)\) be a bijective source relabeling that
preserves the source data available in \(\Bcur\). If \(\Bcur\) does not derive
\(\MatSrcDiscLaw\), then relabeling by \(\rho\) does not derive a non-bottom
\(\MatterDisc\).
\end{lemma}

\begin{proof}
The P5-T03 obstruction is not about a particular token name. It is about the
absence of a source-side rule assigning non-bottom matter-sector labels from
source data alone. A relabeling that preserves the available source structure
preserves that absence. Therefore the relabeled basis still lacks the
required discriminator law.
\end{proof}

\begin{lemma}[Tag-removal fail-closed lemma]
If the tags separating source syntax, target interpretation, and process
receipt surfaces are forgotten, then the matter-semantics route fails closed
to \(\Guarded\) rather than deriving matter-sector semantics.
\end{lemma}

\begin{proof}
The P5-T02 target and P5-T04 audit require no stress-energy import, no matter
action import, no detector import, no target metric import, and no
support-only proof authority. Forgetting the tags needed to check those
conditions makes a non-bottom assignment unverifiable. The only permitted
response is fail-closed behavior, not promotion.
\end{proof}

\begin{lemma}[Sector-deletion obstruction lemma]
Deleting a non-bottom sector label, or deleting all source evidence that would
distinguish non-bottom sectors, cannot create a source-intrinsic
\(\MatterDisc\) under \(\Bcur\).
\end{lemma}

\begin{proof}
Sector deletion removes possible outputs or possible evidence. It does not
add a derivation rule. If the original basis lacks \(\MatSrcDiscLaw\), then a
smaller or less informative sector grammar still lacks the rule needed to
justify a non-bottom source-side classification.
\end{proof}

\begin{lemma}[Support-erasure stability]
Removing generated derivatives, validators, registries, role records,
handoffs, approvals, commits, local caches, semantic extracts, wiki notes,
file order, and support-only checkers from proof status leaves the P5-T03
obstruction unchanged.
\end{lemma}

\begin{proof}
P5-T03 and P5-T04 already treat those surfaces as routing, receipt, or
retrieval support only. They are not mathematical premises. Their removal
therefore cannot create \(\MatSrcDiscLaw\), \(\SemMatterSrc\), or a non-bottom
\(\MatterDisc\).
\end{proof}
