# Director Decision Record: DDR-20260629-033

## Decision

Select `validator-engineer@0.2.0` for one bounded v12 P1-T02
Distance-to-GR ledger schema migration packet.

## Basis

`research_control/program_state.yaml` names `RT-20260629-032` and
`handoff-0327`. The latest handoff routes exactly one P1-T02 packet: implement
the additive ledger schema migration from
`research_control/design/distance_to_gr_status_layers_v1.md` without changing
scientific status.

The existing validator enforced an exact ten-column
`registries/DISTANCE_TO_GR_LEDGER.csv` header. Therefore the migration required
validator and focused test changes in the same bounded transaction. This makes
`validator-engineer@0.2.0` the narrowest role fit.

## Scope

Allowed:

- append the P1-T02 layered status columns to
  `registries/DISTANCE_TO_GR_LEDGER.csv`;
- preserve all legacy `current_status` values and existing scientific meaning;
- update `scripts/research_control/validate_research_control.py` so the ledger
  parses and validates under the additive schema;
- add focused regression coverage for required overread guards;
- create the migration report and normal Continue Research receipts;
- regenerate current-frontier, memory, graph, and registry derivatives required
  by validation and checkpoint.

Blocked:

- canonical ontology edit;
- source-law adoption;
- `MetricData(E)` adoption;
- unscoped `g_eff` adoption;
- `g_eff` scope expansion;
- coupling-law adoption;
- matter-coupling derivation or adoption;
- stress-energy semantics;
- stress-energy tensor;
- matter action;
- detector semantics;
- Einstein equations;
- exact-GR benchmark promotion;
- benchmark Gate Chair closure;
- completed derivation;
- treating the migrated ledger, validator, tests, generated wiki note,
  semantic extract, Obsidian note, local cache, graph, checker, commit, or
  handoff as scientific proof.

## Role-Fit Matrix

| Candidate role | Fit judgment | Reason |
| --- | --- | --- |
| `validator-engineer@0.2.0` | selected | The exact ledger-header validator had to change, and focused regression coverage is required for validator behavior. |
| `process-integrity-auditor@0.1.0` | acceptable but not selected | The packet has process-integrity consequences, but the blocking implementation dependency is validator/schema enforcement. |
| Physics roles | not selected | The packet has no derivation milestone and must not create a physics payload. |

## Result

The selected AgentJob migrated the ledger to the additive layered schema,
updated validator enforcement, added a focused overread-guard regression test,
and preserved all scientific status boundaries.
