\section{Stress Results}

\begin{proposition}[Conditional relabeling invariance]
\(\mathrm{RR}_E\) is invariant under the explicit source relabelings already
quotiented by \(\equiv_{\mathrm{src}}\), but the current packet does not
derive a canonical maximal relabeling group.
\end{proposition}

\paragraph{Reason.}
By definition,
\(\mathrm{RR}_E(C)=(R_E,Q_E)/{\equiv_{\mathrm{src}}}\). Relabelings inside
that named equivalence class preserve \(\MSSig\). Relabelings not already
declared source-equivalent may change \(\mathrm{RR}_E\), move the record to a
different repaired class, or fall outside the finite/local basis. This is
source-pure under the RT-043 guard, but it is only conditional invariance.

\begin{proposition}[Finite-variation behavior is deterministic, not
irrelevance]
The repaired quotient has a deterministic finite/local response to the named
stress variations: it preserves the class when the repaired signature is
preserved, changes class when a signature coordinate changes, and returns
\(\bot\) when admissibility or core formation fails.
\end{proposition}

\paragraph{Reason.}
The projection \(\MSRepProj\) factors through \(\MSSig\). This repairs the
uncontrolled middle-collapse behavior found in RT-040, but it does not prove
that source readout/response differences are irrelevant. It makes those
differences explicit coordinates of the repaired signature.

\begin{proposition}[Certificate deletion is stable only under the core rule]
Deleting non-core certificate redundancies preserves the repaired class.
Deleting a core no-target certificate sends the repaired signature to
\(\bot\). The core rule is finite-basis explicit, not an adopted source law.
\end{proposition}

\paragraph{Reason.}
Only the stable certificate core enters the repaired signature. The result is
unambiguous inside the stated finite repair basis, but the current ontology
does not derive a general certificate-core law beyond that basis.

\begin{proposition}[Sector restriction commutes only on retained-core sectors]
Restricting to sectors that retain \(U_E^{\mathrm{core}}\) preserves the
repaired class. Removing any part of the retained core returns \(\bot\).
\end{proposition}

\paragraph{Reason.}
This is the sector analogue of the certificate-core rule. It is a safe
fail-closed finite/local behavior, not a global functorial sector-deletion
theorem and not matter semantics.

\begin{proposition}[Nondegeneracy passes by retaining \(\mathrm{RR}_E\)]
For the pressure pair \(C_+\) and \(C_-\),
\[
  \mathrm{RR}_E(C_+)\neq\mathrm{RR}_E(C_-)
  \quad\Longrightarrow\quad
  C_+\not\mathrel{\MSRepEq}C_-.
\]
\end{proposition}

\paragraph{Reason.}
Because \(\mathrm{RR}_E\) is a coordinate of \(\MSSig\), the repaired
equivalence relation separates records that differ in source readout/response
syntax. This corrects the RT-040 degeneracy failure without importing target
detector semantics.

\begin{proposition}[Readout/response irrelevance obstruction]
\(\MSStableRepair\) cannot also serve as \(\MSIrrelRepair\) in the strong
readout/response irrelevance-law sense for the pressure pair.
\end{proposition}

\paragraph{Proof sketch.}
A readout/response irrelevance quotient would identify records whose only
relevant difference is source readout/response syntax, subject to the
candidate's admissibility guards. But the repaired signature contains
\(\mathrm{RR}_E\), so such records are separated whenever their
\(\mathrm{RR}_E\) classes differ. Thus the repair obtains nondegeneracy by
denying the irrelevance collapse. This is a scoped obstruction to adoption of
the repaired quotient as a source-side irrelevance law, not a refutation of
all future source-side irrelevance theorems.

\begin{proposition}[Discriminator redundancy]
The definition
\[
  \MSRepDisc(C)=\bigl(\MSRepProj(C),\mathrm{RR}_E(C)\bigr)
\]
is redundant for nonbottom records because \(\MSRepProj(C)\) is already
determined by a signature containing \(\mathrm{RR}_E(C)\).
\end{proposition}

\paragraph{Reason.}
The redundancy is not circular in the target-import sense, but it confirms
that the repaired object is a discriminator-like partition rather than an
irrelevance quotient. Adding \(\mathrm{RR}_E\) twice reinforces the
nondegenerate partition reading and weakens the irrelevance-law reading.

\section{Obstruction}

\begin{definition}[Scoped repair obstruction]
\[
  \Ob(E;\Bcur)
\]
is the statement that, under the current finite/local source basis,
\(\MSStableRepair\) is deterministic and nondegenerate as a source-side
partition, but \(\MSIrrelRepair\) is obstructed as a readout/response
irrelevance law because \(\mathrm{RR}_E\) is a defining signature coordinate.
\end{definition}

\begin{proposition}[Scoped obstruction verdict]
\(\Ob(E;\Bcur)\) holds for
\(\MSStableRepair/\MSIrrelRepair\) as written.
\end{proposition}

\paragraph{Proof sketch.}
The relabeling, finite-variation, certificate-deletion, sector-restriction,
and nondegeneracy tests show that the repair behaves coherently as a
finite/local source partition. The irrelevance and redundancy tests show that
the same repair cannot be read as an irrelevance law for readout/response
syntax. This produces a local scoped obstruction to the adoption route while
leaving a possible stable-partition or precondition continuation for a
selector to evaluate.
