# DDR-20260622-007: Research-Improvement Bridge Phase 6

## Decision

Route one bounded Validator Engineer AgentJob to execute Phase 6 checkpoint
conditional allowlist governance for project-improvement sidecar paths.

## Rationale

Phase 5 integrated the bridge into workflow contracts while deliberately
deferring checkpoint governance. The user explicitly authorized Phase 6. The
remaining risk was that future valid bridge sidecars could be blocked as
outside the active AgentJob allowlist, while a broad sidecar-directory allowlist
would be too permissive.

The correct Phase 6 rule is conditional: a sidecar YAML/Markdown pair is
checkpoint-eligible only when an AgentJob-allowed changed source YAML contains
a generated `project_improvement_bridge` reference to that exact sidecar and
the sidecar points back to the source while preserving project-system-only
boundaries.

## Claim Boundary

This decision authorizes only checkpoint conditional sidecar allowlist logic,
research-control diff-validator integration, focused tests, script README
operator documentation, task evidence, control registry rows,
documentation-impact receipt, and generated memory refresh outputs.

normal research handoff replacement, resolver behavior changes, sidecar
registry creation, skill contract changes, role contract changes, canonical
science source edits, physics claim promotion, benchmark promotion, Gate Chair
authority, or generated-output authority expansion.
