# DDR-20260619-017: Reader Scope Footer Relocation Phase 6 Full-Corpus QA

## Decision

Route one bounded Documentation Curator AgentJob to execute Phase 6 of
`research_control/design/documentation_curator_reader_scope_footer_relocation_plan.md`.

## Rationale

The user explicitly approved Phase 6 after Phase 5 migrated the project-system,
memory, operator, role, and requirement page family. The Phase 6 burden is a
closure packet: validate the full 17-page Reader Scope relocation, refresh
full-corpus desktop and mobile screenshot evidence, update publication evidence
registry paths, regenerate memory/wiki/registry derivatives through bootstrap,
and checkpoint the transaction.

The work remains Documentation Curator work because it validates and documents
source-backed public reader surfaces under existing publication contracts. It
does not rewrite publication briefs, alter validators, change role contracts,
change schemas, change memory-system behavior, change routing behavior, change
checkpoint behavior, add dependencies, edit canonical science sources, or
change physics claim status.

## Claim Boundary

This decision authorizes Reader Scope placement QA, publication-brief registry
evidence path refresh, full-corpus screenshot QA, review evidence, generated
memory/wiki refresh, documentation-impact receipt, and control registry rows
for the Phase 6 closure packet only. It does not authorize canonical ontology
edits, benchmark promotion, Gate Chair verdicts, science draft execution,
physics claim promotion, validator behavior changes, schema edits, role
registration, skill-contract changes, memory-system behavior changes, routing
changes, checkpoint changes, dependency changes, generated-output authority,
public page rewrites beyond evidence synchronization, or a new corpus migration.
