\section{Audit Lemmas}

\begin{lemma}[No-target-topology import as written]
Under the written source-symbol reading of \(\AtlasGlue\), the quotient
support construction uses only source carriers, source site tokens, source
readout syntax, response-label syntax, source-token comparison rules, and
transition-token pairs. It does not use target topology or a target smooth
atlas.
\end{lemma}

\begin{proof}
Coverage is defined as a relation on \(I\times\Omega^+\), not as open sets.
Overlaps are relations in \(U_i\times U_j\), not intersections in a target
space. Transition tokens are partial bijections between source carrier
subsets, not coordinate-transition functions. The quotient is generated from
the disjoint union of the source carriers. No step calls target open sets,
smooth charts, differentiability, metric scale, calibration, benchmark
solutions, validation receipts, or role labels.
\end{proof}

\begin{lemma}[Source-authority guard]
The \(\AtlasGlue\) primitive remains source-pure only if coverage claims,
overlap membership, transition-token assignments, and label-comparison rules
are supplied as explicit source-side data. If any of those data are inferred
from target charts, benchmark behavior, validator success, registry status,
role authority, generated derivatives, or the bare label ``source'', the
primitive fails this audit.
\end{lemma}

\begin{proof}
The primitive's theorem depends on the declared relations \(\Cov\), \(\Ov\),
and \(\Tau\), plus label compatibility. The proof does not derive those
relations from the old source tuple \(\SX\), nor from validation or registry
authority. Therefore the proof is source-pure only when those relations are
independently present as source-side input. Replacing that input with target
or process authority would change the dependency basis and would smuggle in
the very authority the primitive excludes.
\end{proof}
