# Director Decision Record: DDR-20260704-011

## Decision

Execute one bounded `documentation-curator@2.0.0` task overlay for v15 P17-T02.

The selected route creates and registers a deferred publication brief at
`markdown/publication-briefs/negative-results-and-obstructions.publication-brief.md`.

evidence, corpus migration, or publication action.

## Basis

`handoff-0556` routes next to P17-T02. The v15 plan requires a public-safe
publication brief stating that negative results are valuable constraints, scoped
obstructions are not program-wide rejection claims, frozen local routes do not
prove future source-extension impossibility, and exact source artifacts remain
authority.

The active publication-process validator allows non-migrated publication brief
rows with `migration_status: deferred`. That status is the narrowest registry
state for this packet because P17-T03 owns any later explainer source spec.

## Scope

- create one publication brief under `markdown/publication-briefs/`;
- update `registries/PUBLICATION_BRIEF_REGISTRY.csv` with a deferred row;
- register the brief in `registries/MARKDOWN_SOURCE_REGISTRY.csv`;
- update task, job, role, completion, handoff, program-state, registry, and
  documentation-impact receipts;
- refresh generated memory derivatives.

Blocked:

- public explainer source spec creation;
- GitHub-facing Markdown or HTML publication;
- screenshot QA or before/after migration review as if the page existed;
- corpus migration;
- physics claim promotion;
- source-law adoption;
- future source-extension impossibility;
- program-wide rejection;
- benchmark promotion or completed derivation.
