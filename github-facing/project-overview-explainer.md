# Project Overview

AEther-Flow is easiest to enter when it is read as two linked missions under
one source-authority spine. The physics mission keeps ordinary general
relativity as the exact public benchmark at observable scale while the
first-principles derivation from an AEther or AEther-flow substrate remains an
open research burden. The AI research-agent mission builds a governed workflow
for theoretical physics work: tasks, Director decisions, bounded AgentJobs,
roles, validation, memory preflight, completions, and handoffs.

The overview page is a route map for that structure. It helps a reader decide
whether to inspect physics status, source authority, research-control
operation, role routing, memory, validators, or publication-process pages. It
does not certify a scientific result, change a role contract, broaden an
AgentJob allowlist, or make generated documentation authoritative.

The safe reading posture is therefore sequential: use this overview to choose
the correct lane, then inspect the named source file or registry row that owns
the claim. If a question touches physics claims, start from registered science
sources and claim-boundary records. If it touches workflow authority, start
from tracked research-control records. If it touches a public explainer, start
from the publication brief and source spec.
