# Ontology Sources And Derivatives

This folder contains ontology-adjacent explanatory Markdown, canonical TeX
sources, and generated PDF derivatives for the AEther-Flow research program.
It remains the live mutable ontology lane. The sibling `legacy_ontology/`
folder is a 2026-06-18 archival snapshot for comparison.

## Folder Structure

- `tex/` contains registered TeX sources. These carry scientific source
  authority for ontology and benchmark material.
- `pdfs/` contains generated human-reading PDF derivatives.
- `aether-and-aether-flow.md` is ontology-adjacent explanatory Markdown.
- `aether_flow_interpretation-lemen.md` is authored Markdown source material.

## What Belongs Here

- Ontology and benchmark source material.
- Generated PDF derivatives produced from registered TeX.
- Explanatory Markdown that is clearly separated from TeX authority.

## What Does Not Belong Here

- Task-local AgentJob outputs.
- Generated wiki notes.
- Project-control templates or validators.
- Scratch calculations.

## Authority Boundary

Registered TeX files are the scientific authority. PDFs are generated
derivatives. Markdown in this folder may explain ontology context, but it does
not supersede the registered TeX source or promote a derivation claim by
itself.

When ontology extensions are authorized, update this live `ontology/` lane
through the governed research-control path. Do not edit `legacy_ontology/` as a
substitute for a canonical ontology change.
