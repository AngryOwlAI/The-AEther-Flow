# Assets

This folder contains tracked visual assets used by human-facing project
documentation.

## Current Contents

- `images/readme-banner.png` is the current root README banner.
- `images/readme-banner-old*.png` files are retained historical banner
  variants.

## What Belongs Here

- Stable visual assets referenced by tracked documentation.
- Source images that are meant to remain in version control.

## What Does Not Belong Here

- Scratch renders, temporary screenshots, or preview exports.
- Generated HTML or wiki files.
- Scientific source material.

## Authority Boundary

Assets are presentation support. They do not carry physics authority,
project-control authority, registry authority, or claim status by themselves.
If an asset changes the meaning of a documentation surface, update the
documentation source that uses it.
