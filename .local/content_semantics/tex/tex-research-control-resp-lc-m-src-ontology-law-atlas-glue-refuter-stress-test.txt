\section{Profile Collapse}

\begin{countermodel}[Collapsed source profiles]
Let \(U_0=\{a,b\}\) and \(U_1=\{c,d\}\). Suppose the source overlap predicate
allows both \((a,c)\) and \((b,d)\), and suppose the written profile semantics
collapse the two source classes:
\[
  \Prof_0(a)=\Prof_0(b),\qquad \Prof_1(c)=\Prof_1(d).
\]
Then profile compatibility alone cannot distinguish the intended transition
from the swap transition. If the selector preorder does not include an
additional source discriminator, both transitions remain admissible or tied.
\end{countermodel}

This is a source-internal pressure. It uses no target topology, target smooth
atlas, target coordinate transition, metric scale, proper time, benchmark
behavior, validation status, role authority, registry authority, or generated
derivative.

\begin{guard}[Profile failure is fail-closed]
Under \(\MSL\), profile collapse does not authorize target repair. It returns
\(\Bot\) or routes to a narrower source discriminator. Therefore the collapse
countermodel does not refute the proposal as written; it identifies the
non-bottom source data that a later bridge attempt must supply.
\end{guard}

\section{Selector Nonuniqueness}

\begin{countermodel}[Symmetric selector tie]
Let \(\Cand_{01}=\{\tau,\sigma\}\), where both candidates satisfy the source
overlap and profile compatibility clauses. Define the source selector preorder
so that \(\tau\preceq^{\mathrm{src}}_{01}\sigma\) and
\(\sigma\preceq^{\mathrm{src}}_{01}\tau\). If \(\tau\neq\sigma\), there is no
unique source-minimal selected transition.
\end{countermodel}

The only admissible output is:
\[
  \Sel_{01}(\Cand_{01})=\Bot.
\]
Choosing \(\tau\) or \(\sigma\) by file order, visual resemblance to a target
chart, benchmark success, validation status, role identity, registry
visibility, generated-note presence, or the bare label ``source'' would
violate the claim boundary.

\section{Inverse Defect}

\begin{countermodel}[Missing inverse token]
Let \(\Tau_{01}\neq\Bot\) be selected, but suppose the reverse family has no
source token satisfying
\[
  \mathsf{inv}_{\mathrm{src}}(\Tau_{01})=\Tau_{10}.
\]
Then the source transition data do not supply direction-independent overlap
identification.
\end{countermodel}

\begin{obstruction}[Inverse compatibility is a real premise]
The inverse clause is not an automatic consequence of calling the data
``atlas glue''. It is a source-token equality that must be supplied or proved.
If it fails, the law does not produce source atlas-glue compatibility on that
overlap.
\end{obstruction}

\section{Cocycle Defect}

\begin{countermodel}[Triple-overlap defect]
Let \(\Tau_{01}\), \(\Tau_{12}\), and \(\Tau_{02}\) be selected on a triple
source overlap. Suppose
\[
  \mathsf{comp}_{\mathrm{src}}(\Tau_{12},\Tau_{01})\neq\Tau_{02}.
\]
Then two source paths through the overlap identify different tokens.
\end{countermodel}

\begin{obstruction}[Quotient support is conditional]
\(\Qsrc\) is well-defined only relative to source transition data satisfying
the inverse and cocycle clauses. The conditional quotient theorem in
\(\MSL\) cannot be read as a proof that those clauses hold for arbitrary
source covers.
\end{obstruction}

\section{Finite-Variation Fragility}

\begin{countermodel}[Fragile finite variation]
Let \(v\in\Var\) merge profile values, tie the selector preorder, delete an
inverse token, or alter one triple-overlap composition. Unless \(\Var\) and
\(\Stab\) explicitly exclude that perturbation or fail closed, the positive
branch is destroyed.
\end{countermodel}

\begin{obstruction}[Preservation theorem remains undischarged]
The audited proposal states finite-variation preservation as a source-law
obligation. It does not prove arbitrary finite-variation robustness from the
current ontology. A future bridge attempt must either construct a non-bottom
variation class with preservation proof or name the missing primitive.
\end{obstruction}

\section{Authority Laundering Screens}

\paragraph{Source-authority laundering.}
The proposal may be source-side as written, but the current ontology does not
derive \(\MSL\). A conditional law tuple is not adopted source authority. The
words ``source law'', a validation pass, a registry row, a role label, a
handoff, generated derivative visibility, or a finite witness cannot promote
the law.

\paragraph{Finite-witness overread.}
\(\Wfin\) may motivate concrete branches. It does not prove the general law,
arbitrary finite-variation robustness, \(\AtlasGlueDisc\) adoption,
\(\AtlasGlue\) adoption, or full \(\Msrc\) construction.

\paragraph{Target-atlas side-door import.}
Every stressed failure branch must remain inside source data. If a failed
profile, selector, inverse, cocycle, or variation branch is repaired by target
coordinates, target topology, target smooth atlas structure, metric scale,
proper time, empirical observer protocols, detector semantics, benchmark
behavior, validation status, role authority, registry status, or generated
derivatives, the repair violates the packet boundary.

\paragraph{Bridge-ladder collapse.}
The sequence ``proposal, smuggling audit, Refuter stress'' does not itself
become \(\Msrc\). The missing rung is a concrete non-bottom source-law witness
or theorem that supplies profile semantics, selector uniqueness, inverse
compatibility, cocycle compatibility, and finite-variation preservation under
explicit hypotheses.
