Boundaries To Preserve
Exact-GR benchmark compatibility is not a completed substrate derivation.
A generated page can be clearer than a source file without becoming authority.
A validator pass means the checked contract passed, not that a broad scientific or editorial verdict was issued.
A role or tool being available does not expand the current write allowlist.
