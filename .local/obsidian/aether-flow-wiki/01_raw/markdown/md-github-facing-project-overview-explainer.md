# Project Overview

AEther-Flow has two linked missions. One is a physics research program that
keeps exact general relativity as the benchmark while treating first-principles
derivation from an AEther or AEther-flow substrate as open. The other is a
research-agent system that routes bounded theoretical, refutation,
documentation, and validation work through tracked control records. The shared
rule is simple: source authority comes first, generated explanation comes
after.

This page is a noncanonical reader surface. Use it to choose the next source to
inspect, not as evidence that a physics claim, role permission, validator rule,
or generated-output authority has changed.

## Two Missions

## First Reading Path

Start with `README.md` for project intent, then `AGENTS.md` for authority and
agent rules. If the question concerns active research state, read
`research_control/README.md` and the relevant task record before touching
files. If the question concerns a public explainer, inspect its publication
brief and source spec before reading generated HTML or GitHub-facing Markdown
as evidence.

## Boundaries A New Reader Should Keep

- Exact-GR benchmark compatibility is not the same as a completed substrate
  derivation.
- A generated page can be clearer than a source file while still having no
  independent authority.
- A validator pass means the checked contract passed; it is not a broad
  scientific verdict.
- A role, skill, or tool being present does not expand the current AgentJob
  allowlist.
